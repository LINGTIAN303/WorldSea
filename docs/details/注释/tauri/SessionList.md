# SessionList 注释

## 职责
会话列表面板（对话视图左侧）：按「今天 / 更早」分组展示会话，支持标题搜索、相对时间、消息数；删除经父级确认框。

## 设计决策
- **分组**：以 created_at 零点切分「今天 / 更早」，组内按创建时间倒序。会话多时不至于一长串无层次。
- **搜索**：会话数 >3 时展示搜索框（低频用户不被多余控件打扰），按标题匹配，无结果给"没有匹配的会话"。
- **相对时间**：刚刚 / N 分钟前 / N 小时前 / 昨天 / 日期，避免原始时间戳的冷感。
- **删除确认**：本组件只 emit `remove`，确认框在 App.vue 层（TuiConfirm）——删除会话会级联清记忆，属危险操作。
- **hover 操作**：删除按钮（trash 图标）hover 渐入，危险色 hover 反馈。

## 约束
- 会话标题统一经 `useAgentRust().sessionTitle` 取（首条用户消息截断），勿在组件内自行截断。
