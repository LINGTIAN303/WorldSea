## 1. 边界

- 只服务产品域（工作台窗）；**不碰 dsh**。dsh 用自己的 `--dsw-*`，不加载产品域 theme.css/ui-kit。
- Token 落 `theme.css`；组件落 `packages/ui-kit`；产品域状态机 `useAsyncTask` 可从
  `@worldsea/ui-kit/composables/useAsyncTask` 深导入，避免把整个 ui-kit facade 拉进 composable。

## 3. R3 用 B 弧形航线（用户 2026-10-22 拍板）

- 视觉基准：Study 04。**4 节点上限**；弧下短标签 11px，完整阶段文案 12px 在上。
- **无卡片**：进度与文字直接落在 scrim 上；不加背景/边框/阴影/内边距。遮罩保留，负责阻断与对比度（2026-10-22 走查后调整）。
- 进度用**阶段式**（`2/4` + 当前阶段 + 星点停节点）；**不显示假的连续百分比**。
  只有能拿到真实「已处理/总数」时才传 `progress`。
- 完成：星点放大淡出、航线保留 300ms；失败：星点/当前节点转 warning，显示重试/关闭，不自动消失。
- 两种 scope：
  - `content`：只盖 `.shell-content`（标题栏保留）；项目切换用这个。
  - `panel`：遮罩落在弹窗内部；导入导出等用这个。

### 项目切换阶段映射

`useProjectSwitcher` 把 6 个实现步骤归并为 4 个用户可见阶段：

| # | 短标签 | 实际步骤 |
|---|---|---|
| 0 | 数据源 | `pm.switchProject` + 绑定存储根 |
| 1 | 实体 | 停旧监听/启新监听 + `reloadStores` |
| 2 | 芽 | `reinitializeModules`（卸载/重装 + 壳重装配） |
| 3 | 关联 | `fsProject.onProjectSwitched` + 当前项目/列表 + `project:switched` |

失败可发生在任意阶段；重试允许「目标已是当前指针」（失败可能在指针切换之后）。
关闭错误浮层会保留已完成步骤，因此只提示「可能处于部分切换状态」，不假装回滚。

## 4. Token 两层

**全局语义**（`theme.css`）：`--loading-accent/track/label`、`--loading-scrim`、`--loading-scrim-blur`、
`--loading-scrim-local`、`--loading-skeleton-base/shine`、`--loading-size-sm/md/lg`、
`--loading-orbit-duration`、`--loading-survey-duration`、`--loading-delay`、`--loading-min-visible`、`--z-loading`。

**组件内部**（scoped CSS，不进主题契约）：星头 4.5px / 光晕 7px / 尾迹 78° / 节点 9–11px /
扫描雷达 36px、2.2s / 阶段停顿 120ms。不要在全局 token 里继续加这类参数。

## 5. 状态机（useAsyncTask）

- `run()`：开始 → 超过 `delay`（200ms）才 `visible=true`；完成时至少保留 `minVisible`（400ms），
  再保留 `successHold`（300ms）；`empty` 谓词可进入空态。
- 失败：立即 `visible=true` 并保留 `error`，直到 `reset` 或重试。
- **错误态重试保持可见**，避免关闭再打开闪烁。
- 同一个任务只出现一个指示器；阻断型失败必须可重试。

## 6. 接线与可访问性

- `Shell.vue` 新增 `.shell-content`（titlebar 之外的全部区域）作为 overlay 的定位上下文；
  遮罩期间 `.shell-body` 加 `inert`，标题栏保留。
- 项目切换期间 `setSpaceSwitchBlocked(true)` 阻止「进入 Agent 空间」；标题栏按钮同步禁用；
  项目下拉自动收起，避免 teleport 菜单浮在遮罩之上。
- overlay `role="status"`、`aria-live="polite"`；错误时焦点落到「重试」。
- 减弱动态（`data-reduce-motion='on'`）：星轨 2.4s、测线 4.6s、R3 节点跳转无补间；语义不消失。

## 7. 批 2 落点（2026-10-22）

- **导入/导出**：R3-L（`scope=panel`）阶段化；overwrite 的备份阶段在 `importing` 前可见；每 serializer 上报收集/写入进度；导出 JSON/YAML 现在同时遵守勾选范围（修复旧实现只对 `.ws` 生效）。
- **存储**：扫描用 `WsScanRadar` + 真实 `scanProgress`；清理用真实 `cleanProgress`；备份/刷新统计用 R1。
- **批量编辑**：批量删除/改标签/重命名用 R3-L，进度按已处理数量；单条保存用 R1。
- **DocExport**：预览生成用 R1 覆盖层；生成期间禁用下载/打印。
- **一致性/回收站/产物**：运行检查/修复、恢复、产物创建/回滚/删除用 R1。
- **AppMenu 导出到文件夹**：R1 测线 + 文字；菜单触发后会立即收起，行内不可见，**Shell 顶部另挂 R4 测线（`projectSaving`）兜底**。
- **TemplateManager / VersionHistory**：核实无 >200ms 异步，未加加载（避免噪音）。
- 导入导出在浏览器预览里无法完整验证（world tree/serializer 未装载），需真机走查。

## 8. 坑与不做

- 不要为 <200ms 的操作显示加载；不要让快任务闪一下。
- 不要用骨架屏承载未知形状（图谱/导视/棋盘用 R3 局部遮罩）。
- 不要把遮罩盖到标题栏上（已拍板只盖内容区）。
- 不要模拟百分比；启动页的随机进度是批 4 要修的反例。
- 不要把加载 token 或组件接到 dsh；不要改 dsh 的 `--dsw-*`。
- 侧栏/菜单若 teleport 到 body，遮罩期间可能绕过 `inert`；当前只保证项目下拉会主动收起。
