## 注释块 1（原文件第 1-4 行）

# SubAgentView — 子 Agent 规格管理界面

提供子 Agent 规格的查看 / 注册 / 删除能力，使用户能在桌面端配置主 Agent
可委派的子 Agent 专长（`delegate_to_sub_agent` / `list_sub_agents`）。
通过 `useSubagentRust` 调用 Rust 命令层（`subagent_*`）。

## 布局与交互（2026-09-03 UI 改造后）

- **右侧 = 规格列表 + 实例区**：吸顶标题行「子 Agent」与工具按钮（导入 / 导出 /
  模板下拉）同行；新增入口由左侧空态中心按钮承担；规格卡片整卡可点 = 查看详情，
  **再次点击已选中项 = 取消选中回空态**（新增入口的回归路径），选中态带左缘指示条，
  操作按钮（编辑 / 复制 / 删除）位于名称行右侧、hover 浮现；
  实例区为会话级运行时状态（流式高亮 / 逐个清空 / 清空全部），位于列表下方独立分段。
- **左侧 = 三态面板**：
  1. **详情态（默认）**：选中规格的只读展示（名称 + id、元信息 chips、
     能力描述、系统提示词可复制块、白名单 chips），底部操作条
     编辑 / 复制 JSON / 删除。
  2. **表单态（新增 new / 编辑 edit）**：编辑态 id 禁改（保存按原 id 覆盖），
     ID 字段 label 与输入框同行；名称与最大迭代同行；工具白名单为 chips 输入
     （回车/逗号生成、✕ 移除、hint 常用工具点击追加）；提交按钮统一文案
     「保存规格」，保存/取消后回落详情态。
  3. **空态**：未选中规格时的引导（选择规格 / 新增 / 从模板开始）。
- 窄面板（容器 ≤720px）自动上下堆叠：详情在上、列表沉底。
- 状态机：`formMode`（'' = 详情/空态 | 'new' | 'edit'）+ `selectedId`
  （详情选中项）。新增保存成功 → 自动选中新规格；删除选中项 → 回空态。
- 数据层 `useSubagentRust` 零改动；导入导出（TuiModal）、删除/清空确认
  （TuiConfirm）、模板下拉键盘导航、规格列表 ↑↓ 焦点导航均为既有能力保留。
