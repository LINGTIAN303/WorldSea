## 前端 vs 后端的判据

本仓的「后端」有两个含义，别混：

| 含义 | 落点 | 特征 |
|---|---|---|
| **Tauri 壳**（真正的后端） | `apps/tauri/src-tauri/`（Rust） | 进程边界、文件系统、窗口、ACL |
| **前端内的后端胶水** | `apps/tauri/src/core/`（TS） | 封装 `invoke` 与 WASM 加载；是端分离的产物 |

`core/` 把「后端」抽象成 `coreBackend`，但实际全是 `invoke` + WASM——它不构成第二个后端，只是让调用点不直接写命令名。

## 写作口径

- 目录职责必须给**实测行数**，不给「大约」
- 边界判据要写「靠什么区分」，不写「约定上应该」
- 发现文档与代码冲突时以代码为准，并在文中标出
