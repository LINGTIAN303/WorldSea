## 二、两个 WASM 引擎

| | `worldsea-core` | `tactical-engine` |
|---|---|---|
| 规模 | 56 个 `.rs`，约 15k 行 | 8 个 `.rs`，1,163 行 |
| crate 形态 | `cdylib` + `rlib`；features：`wasm`（wasm-bindgen + serde-wasm-bindgen）/ `sqlite`（rusqlite bundled） | `cdylib` + `rlib`；wasm-bindgen 常开 |
| 算什么 | 模型 / 校验 / 迁移 / 诊断 · 图算法（layout 1,322 / community / pathfind / topology）· 几何（polygon 614 / boolean / bbox / line）· 地形（terrain / erosion）· 空间索引（rtree）· CRDT（LWW / ORSet / RGA）· DXF 读写 · 约束求解 · sqlite 存储 · retrofit 会话 | 战术推演：棋盘 · 单位 · 战斗结算 · 寻路（131）· 地形（127）· AI 决策 · 态势感知 |
| 怎么被调 | vite alias `@worldsea/core` → `worldsea-core/pkg/index.js`；`core/worldseaCore.ts` 懒加载单例，用 **Proxy 把 camelCase 自动转 snake_case**；重计算走 Worker 池（4 个 worker，`HEAVY_METHODS` 18 项） | vite alias `@worldsea/tactical-engine` → `tactical-engine/pkg/index.js`；`useTacticalEngine.ts` 动态 import，失败降级 `TacticalEngineJS` |
| 谁在调 | `core/api/{algo,entity,schema,retrofit}.ts` 全部经 `backendCall` / `algoCall`；`registerValidationApi` 把 `validateEntity` / `checkReferences` 注册进 entity-core | 只有 `tactical-board` 插件 |
| 失败时 | `wasmAvailable=false` + 降级值返回 + 一次 toast；`WASM_DEPENDENT_FEATURES` 10 项清单 | 静默降级 JS 引擎，控制台一条 warn |

### 关键实测：`cmd_algo_*` 字面量全是死参数

`core/api/*.ts` 里 43 个 `cmd_algo_*` 字面量**没有一个被真正调用**——`backendCall(tauriCmd, ...)` 的第一个参数只拼进日志（`runtime.ts:93,120`），实际执行走 WASM。

含义：`algo_commands.rs` 那 9 条 Rust 命令在前端没有真实调用者。这是 ACL 里 44 条 `cmd_algo_*` 死条目的直接原因（见 [Tauri命令面](Tauri命令面.md) §二）。

### `tactical-engine` 的降级对

wasm 与 `TacticalEngineJS` 是**同一接口的两个实现**（wasm 优先、JS 兜底），不是「可替换能力」。

这决定了 `tactical-board` 插件**不该拆出引擎适配器**——拆出来会得到一个只有一个消费者的适配层。详见 [粒度划分](../../架构/插件系统/粒度划分.md) §四。

## 四、文件规模红线

- 全局 **400 行**；`tests` / `.spec.` / `.test.` 覆盖 **1,200**
- 门禁计数比编辑器多 1（`split('\n').length`）
- 基线冻结 54 个文件，`arch:check` 0 违规

拆文件的判据：按**职责**拆（如 `capabilities.rs` 拆出 `capability_host_call.rs` + `capability_host_invoke.rs`），不按行数均分。

## 五、新增原生代码该放哪

| 场景 | 落点 |
|---|---|
| 新的 Tauri 命令 | 按族进现有 `*_commands.rs`；超过 400 行时按职责拆新文件 |
| 与 dsh 交互 | `dsh_*.rs`；若涉及新的传输形态，先确认方向（Rust→host 还是 host→Rust） |
| 纯计算（图 / 几何 / 地形） | `worldsea-core`，经 `wasm_export.rs` 暴露 |
| 需要 node 侧发起 | 回环端点（参考 `capability_host_call.rs`），不要试图反向用 `dsh_pipe` |

**新模块必须登记**：`architecture-policy.json` 的模块清单 + `lib.rs` 的 `mod` 声明，两处都漏不得（前者门禁报红，后者编译报错）。
