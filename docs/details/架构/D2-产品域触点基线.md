## 三、现有触点面全清单（dsh ↔ 工作台）

### 3.1 壳注入全局对象（页面侧可见的壳桥面）

| 全局对象 | 方向 | 用途 |
|---|---|---|
| `__WORLDSEA_SHELL__` | 双向 | 壳桥命令（通知/外链/日志/工作区修复/窗口动作/菜单/空间切换 7 条） |
| `__WORLDSEA_SPACE_SWITCH__` | 工作台→壳 | 空间切换（E5 `shellSwitch` 接线） |
| `__WORLDSEA_STREAM__` | 壳↔页 | 流桥（IPC 帧隧道，dsh 页传输面） |
| `__WORLDSEA_THEME__` / `__WORLDSEA_SET_THEME__` / `__WORLDSEA_DARK__` | 双向 | 主题真源读写与壳自有面取色（E2） |
| `__WORLDSEA_CAPABILITY_CALL__` | 壳→提供方窗 | 能力桥派发入口（页面伺服在 `src/shell/capabilities.ts`） |
| `__WORLDSEA_BOOT_ROOT__` | 壳→页 | 启动根注入 |
| `__WORLDSEA_WORKSPACE_NOTICE__` | 壳→页 | 工作区不可供给横幅 |

### 3.2 能力桥（dsh → 产品域的唯一受控调用通道）

机制（`src-tauri/src/capabilities.rs`）：`cmd_capability_invoke`（ACL 校验 + callId 在途登记）→ eval 派发到提供方窗口的 `__WORLDSEA_CAPABILITY_CALL__` → 页面伺服查 handler 执行 → `cmd_capability_result` 回执认领（**只有该调用的提供方窗口**能回）。命令面五件：register / unregister / list（**Agent 发现面**）/ invoke / result。

已验证语义：provider = 窗口 label 不可冒名 · 撤登记随插件卸载自动执行（树内 `capabilities.register` 声明，拆树/卸插件收口）· 错误码结构化（`CAPABILITY_UNKNOWN` / `NO_PENDING` / `UNAVAILABLE` / `BAD_ARGS` / `TIMEOUT` + ACL 拒）· `[WORLDSEA-CAP]` 审计日志（登记/调用/回执/超时全链）。

### 3.3 FS 数据路径

数据根 `%USERPROFILE%\WorldSea` = dsh 工作区 cwd（E1）→ dsh 工具（write_file 等）在沙箱内可直写创作数据。两个已知边界：**文件级直写绕过工作台数据层校验**；**工作台不自动感知外部改动**（刷新/重进视图才见）——D2 若要「改完即见」需要数据失效通知通道。

## 四、能力桥健壮性评估（D2 扩容前的已知边界）

| # | 项 | 现状 | D2 影响 |
|---|---|---|---|
| 1 | 超时 | 固定 10s（`CALL_TIMEOUT` 常量，不可按能力配置） | 长动作（整书导出/批量迁移）会误超时 → 需按能力声明超时分档 |
| 2 | 取消 | 无——调用方不能中断在途调用 | 长动作不可取消 → 需 cancel 语义 |
| 3 | 进度 | 单请求单回执，无流式/进度回执 | 长任务无法回报进度（可与通知通道一并设计） |
| 4 | 载荷 | JSON 经 eval 脚本字符串注入传输 | 大 JSON（整章正文）序列化进脚本字符串——效率与转义边界未验，大内容需分块或换通道 |
| 5 | 并发 | 多在途支持（原子序 callId），无背压上限 | 并发洪泛无闸——扩容时补 |
| 6 | 事件 | 只有 request/response，无反向事件通道 | 「Agent 改了数据 → 工作台实时刷新」做不到；需事件通知通道（与系统功能轴 #9 通知生产者同源） |
| 7 | 身份 | ACL 粒度 = 窗口 label（main/workspace） | 无法区分 dsh 内哪个会话/Agent 在调——细粒度授权留 D2 |

## 六、D2 开场讨论的输入清单

1. **项目↔会话映射**（E1 第 3 项，已拍板并入 D2 开场）——两套项目模型（dsh workspace ↔ 产品项目 `useProjectSwitcher`）怎么映射，决定能力面的主键；「同机两套写规则」归这组一并议。
2. **能力面扩容清单**——第一张稿候选：芽启停（侧栏条目控制）/ 视图与数据刷新通知 / schema 扩展 / orchestration 子 Agent 接 dsh / 长任务进度与取消。
3. **认知面**——dsh 怎么知道产品域有什么：`cmd_capability_list` 是运行时发现面，但无「产品域说明书」注入（旧 `WORLDSEA.md` 随旧面删除）；对照世界观整合线「发现路径轮」的教训（可见但提示层无指向 → 模型不会用）。
4. **直写 vs 能力调用的分工**——FS 直写（快，但绕校验、无感知）vs 能力调用（受控、可校验、可通知）的边界原则，建议 D2 定一条判定线。
