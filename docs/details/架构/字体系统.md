## 二、分层模型

| 层 | CSS 变量 | 默认值 | 消费面 |
| --- | --- | --- | --- |
| chrome 界面 | `--font-family-chrome` | `var(--font-sans)` | body 根链（全局 UI） |
| editorUi 编辑器 UI | `--font-family-editor-ui` | 同上 | 编辑器工具条/章节列表/芽工具栏 |
| content 内容 | `--font-family-content` | 同上 | manuscript 正文、notebook prose |
| preview 预览 | `--font-family-preview` | 同上 | 手机预览、DOCX 导出（prefs 直读） |
| canvas 画布 | （无变量） | — | FontRenderer canvas 图片渲染（prefs 直读） |
| ~~agent~~ | （已退役） | — | 旧 Agent 面已退场；prefs 键保留兼容旧数据 |

**生效机制**：层变量默认定义在 theme.css（单一真源）；用户指定后 fontStore 写
`documentElement` **inline 变量**（inline 优先级高于样式表），重置即移除 inline 回默认。
启动时 `useFontBootstrap().bootstrap()`（App.vue onMounted，异步不阻塞）恢复 IndexedDB 字体 +
`reapplyAll()` 重放层变量与字号档位。

**权重/样式**：每层可再选 variant（weight/style），非默认值时写 `--font-weight-<layer>` /
`--font-style-<layer>` inline。

## 三、界面字号档位（--ui-font-scale）

- theme.css 的 `--fs-3xs…--fs-xl` 与桥接 `--font-size-2xl/3xl` 全部 **calc 派生**：
  `calc(14px * var(--ui-font-scale))`；默认 scale=1 时值恒等（零变化）。
- fontStore `uiScale`（0.85–1.15，独立 localStorage 键 `worldsea_font_ui_scale`）按档位写
  inline `--ui-font-scale`；默认 1 时移除 inline。
- 设置面「字体分层」卡头部三档（紧凑 0.92 / 标准 1 / 宽松 1.08）+ 0.85–1.15 滑杆微调。
- 边界：只跟随主题令牌消费方（`var(--fs-*)`）；组件内硬编码 px 不跟随（既有口径，登记不做全局兜底）。

## 四、字体库与安装通道

- **库**：fontLibraryStore（清单 localStorage `worldsea_font_library` + 二进制 IndexedDB，
  400MB 上限；ZIP 导入按组管理；删除时联动重置引用层）。
- **四通道安装**（fontInstaller）：wsfont 包 / 裸 ttf/otf/woff / windfonts 在线 / ZIP 批量。
  安装 = 解析真实 family/weight/style（OS/2、name 表）→ FontFace 注册 → IndexedDB 持久化 → 入库清单。
- **系统字体（v2 新增）**：`font_scan.rs` 扫描 Windows 字体目录（系统级 + 用户级）解析 sfnt
  name/OS-2 表；`cmd_font_read_file` 限字体目录内读取（canonicalize 校验，防任意文件读）。
  UI = SystemFontPicker（懒扫描 + 搜索 + 点击安装入库，复用 installFromRawFont 完整链）。
- **预设字体**：FONT_PRESETS 机制保留、数据清空（原 10 个内置 wsfont 资产文件不存在，为死数据）；
  待「自托管预设字体包」拍板后重填。

## 五、启动恢复链（v2 修复的断链）

1. App.vue onMounted → `useFontBootstrap().bootstrap()`（fire-and-forget，失败仅 console.warn）
2. migratePresets（当前 no-op：FONT_PRESETS 空）
3. `restoreAllFonts()`：IndexedDB → FontFace 重注册
4. `fontStore.reapplyAll()`：重放全部层变量 + `--ui-font-scale`

## 六、视觉增强（v2 批 3）

- `.tnum` 工具类（theme.css）：`font-variant-numeric: tabular-nums`，用于统计/计数/存储量；
  已应用：写作统计面板今日字数、外观面板存储量提示。
- 正文断行：manuscript `.tiptap` 与 notebook `.ws-nb-prose` 加 `text-wrap: pretty`
  （Chromium 120+ 渐进增强，末行不成孤字；不支持则自然回退）。

## 七、关键不变量（改动勿破）

1. **层变量默认定义只存在于 theme.css**——web-tokens-bridge.css 不再重复定义（单一真源）。
2. **canvas/agent 层永不写 CSS 变量**（LAYER_CSS_VAR 空串）——fontStore.spec 锁定。
3. **--fs-\* 必须经 --ui-font-scale calc 派生**——新增字号令牌要跟进 calc 化，否则档位不生效。
4. **系统字体安装必须走完整入库链**（installFromRawFont + libraryStore.addEntry）——
   只注册 FontFace 不入库会在重启后丢失。
5. **cmd_font_read_file 的路径校验**（is_under_font_dirs）不可移除——防任意文件读。
6. 启动恢复链的调用点是 App.vue onMounted（幂等、不阻塞）；勿挪进 bootstrapShell
  （切项目重播种会重复触发）。
