# 机制入口

> 本层收**跨插件的通用机制**：多条路径都会用到、不属于某一个插件的那些。
> 只服务单个插件的内部机制留在代码里，不进本目录。

## 分组口径

判断一份文档该不该放这里，问一句：**这个机制是否只服务一个插件？**

- 否（多插件 / 平台级）→ 放这里
- 是 → 留在这个插件的代码注释与 `details/注释/` 里
