口径与维护

快照边界

  • 数据真源：芽 index.ts、Trait、Facet 源码。
  • 项目级 schema 覆盖（worlddata/.worldsea/schemas/<type>.json）与用户 customFields 不在静态快照内。
  • 关系类型是实体之间的边，不是实体字段，未纳入本表。

字段合并

  • 先按 Trait 声明顺序展开字段，再应用 fieldOverrides，最后追加 ownFields。
  • 同 key 时 ownFields 覆盖 Trait 字段。
  • title 落地为顶层 name；description / tags / coverImage 也落顶层。
