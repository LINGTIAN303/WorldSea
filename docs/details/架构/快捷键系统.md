> 用途：快捷键体系的权威说明——架构、机制、规范、键位总表、新增快捷键的维护流程。调整快捷键前必读本文。

## 0. 一页结论

- **命令层（唯一权威）**：所有「命令型快捷键」统一进 `packages/ui-kit/src/composables/useShortcuts.ts` 单例注册表（chord 组合键 + sequence 连击序列两种键型），scope 五层 `modal > editor > view > space > global` 优先级仲裁，用户自定义键位持久化 `localStorage['worldsmith_shortcuts']`。
- **组件局部层（规范约束）**：菜单 ↑↓ 导航、Tab 焦点陷阱、输入框内 Enter 等组件局部交互键保留在组件内（元素级 `@keydown` 或浮层 show 期监听），禁止与注册表抢键。
- **弹窗优先**：弹窗深度机制保证弹窗打开期间 view/space/global 层全部失效；view 层命中即消费（stopImmediatePropagation），残留监听不再重复执行。
- **展示同源**：设置面板/帮助弹窗/菜单标注全部读注册表，改键后展示自动同步。

## 1. 两层职责架构

```
┌─ 命令层 useShortcuts（唯一权威）──────────────────────┐
│ registry: Map<id, ShortcutDef>                        │
│ document 冒泡唯一全局 keydown 分发器                     │
│ 键型：chord（组合键）/ sequence（连击序列 500ms 超时）    │
│ scope：modal > editor > view > space > global          │
│ 约束：view 层需 activeViewId 非空（Agent 空间自动失效）   │
│ 约束：space 层需 Agent 空间壳激活（App 注入，两壳互斥）    │
│ 约束：弹窗深度>0 时仅 modal 层生效                       │
└───────────────────────────────────────────────┘
┌─ 组件局部层（书面规范约束）──────────────────────────┐
│ 元素级 @keydown：菜单导航/表单提交/a11y 触发             │
│ 浮层 show 期监听：Tab 焦点陷阱（焦点管理非快捷键）        │
│ 持续态键：Space 按住平移画布（keydown 置位/keyup 复位）   │
│ 终端：xterm onData 直通 PTY（无拦截）                   │
└───────────────────────────────────────────────┘
桌面壳（Tauri global-shortcut）：Ctrl+Shift+W 唤起/隐藏主窗口——OS 层注册，
不受注册表管理、不可改键，仅在帮助弹窗「系统级」分组展示。
窗口控制键（TitleBar 固定监听）：Ctrl+M 最小化 / Ctrl+Enter 最大化还原 / Ctrl+W 关闭——
同为系统级固定键（不进注册表、不可改键），弹窗/输入焦点期间照常可用（Alt+F4 同语义）。
```

## 2. 机制要点（useShortcuts 2.0）

1. **键型**：`ShortcutDef.kind: 'chord' | 'sequence'`（默认 chord）。sequence 的 `keys` 按序逐键匹配（如 `['n','c']`），500ms 超时重置，Esc 清空；进行中状态导出 `currentSequence` 供提示 UI（MindmapKeyHint）读取。
2. **IME 保护**：分发器入口 `e.isComposing || e.keyCode === 229` 直接忽略——中文输入法选词/上屏期间任何快捷键不触发。
3. **shift 归一化**：非字母可打印字符（`?` `,` `=` `-` `0` 等）的 shift 信息已体现在 `e.key`，不再叠加 shift 修饰符（否则注册 `['?']` 与实际 `['shift','?']` 永不匹配）；字母与特殊键保持叠加（Ctrl+Shift+Z 依赖）。
4. **弹窗深度**：`setShortcutModalActive(true/false)` 由四个浮层基座（TuiModal/TuiDrawer/DialogContainer/useFocusTrap）show/hide 时调用（含卸载泄漏保护）。深度>0 时仅 modal 层生效——修复「弹窗开着时按 Esc 误触发视图返回上层 / 数字键切视图」等穿透。
5. **view 层命中消费**：view 命中即 `stopImmediatePropagation`——document/window 级残留监听（如 InfoPanel 的 Delete）不再重复执行同键行为。modal/global 暂不阻断（存量浮层 window 监听渐进收编）。
6. **视图/壳上下文**：`setActiveViewId` 由 App.vue 注入（Agent 空间=null）；view 层在 Agent 空间整体失效。ViewContainer 以 `<component :is>` 单实例切换挂载，无多视图并存竞争。**space 上下文（2026-09-06）**：`setAgentSpaceActive` 由 App.vue 按 `currentShell==='space'` 注入，space 层仅在 Agent 空间壳激活时生效——AgentSpace 与 Shell 均 v-show 常驻挂载、注册不随壳切换注销，必须靠此上下文过滤防泄漏。序列键（advanceSequences）同享两上下文过滤。
7. **改键**：`setShortcut` 同 scope 冲突阻断、跨 scope 遮蔽（modal>view>global）放行但警示、modal 层拒绝；`resetShortcut` 恢复注册时默认值并清持久化。设置面板 ShortcutsPanel 录制走 document capture 阶段（录制期间不触发已注册键），Esc 取消录制。
8. **弹窗组合器 useModalShortcuts**（批7）：自挂监听弹窗的统一收编入口——Esc 关闭收编 modal 层 + 弹窗深度接入二合一；配套**收编弹窗栈**（pushModalShortcut/popModalShortcut），分发器在 modal 层只放行栈顶条目——弹窗叠层时 Esc 只关最后打开的弹窗。新弹窗一律用它，禁止手挂 Esc 监听。

## 3. 组件局部键规范（新增代码必读）

**必须收编注册表的**：一切「用户可感知的命令」（打开/关闭/删除/切换/缩放/撤销/发送命令等）。浮层临时命令用 `useScopedShortcuts(defs, activeRef)`（show 自动注册/hide 注销）。

**保留组件内实现的**（并遵守约束）：
- 元素级 `@keydown`（焦点在该元素上时的局部行为）：菜单 ↑↓ 导航、表单 Enter 提交、a11y 的 Enter/Space 触发。约束：**键不得与注册表同 scope 激活键相同**。
- 浮层 show 期 window 监听：仅限 Tab 焦点陷阱（焦点管理）。
- 持续态键（按住生效）：Space 平移画布（`packages/canvas-engine/src/core/useCanvas.ts` setupKeyboard，已注释登记）。
- **窗口控制键**（`apps/tauri/src/ui/layout/TitleBar.vue` onWindowKeydown）：Ctrl+M / Ctrl+Enter / Ctrl+W 固定监听，不进注册表（不可配置是需求本身——窗口管理独立于应用内容，弹窗/输入焦点期间照常可用）；IME 保护对齐注册表；展示走帮助弹窗「系统级」分组。
- 终端 xterm：按键流直通 PTY，不拦截。

**禁止**：
- document/window 级 `addEventListener('keydown')` 实现命令型快捷键（改走注册表）；
- capture 阶段「抢跑」Escape（存量三处——ChatInput 权限菜单/ModelSwitcher/CreationPanel——经核查语义自洽保留，新代码不得新增）；
- 在输入焦点判断上自行造轮子（注册表已统一处理 INPUT/TEXTAREA/SELECT/contentEditable）。

## 6. 已知限制与渐进项

- **浮层收编进度（批7 后）**：命令弹窗已全部收编 useModalShortcuts（实体表单/批量编辑/导入导出/颜色选择器/字体两面板/欢迎引导/帮助弹窗/导出校对/项目切换/最近修改/布局管理）；下拉类 ViewToolbar/ViewToolbarFilter 的 Esc 为 capture 局部消费（抢在 view 层之前，仅下拉打开时拦截）；仍保留组件内监听的：Agent 空间三处 capture 抢跑（语义自洽）、TuiSelect/ToolbarOverflow 下拉、InfoPanel Delete（Agent 空间也用）、终端 xterm。
- **实体视图动态条目**（`${entityType}.delete/new/close`，16 族）已进注册表但不在设置面板目录（动态 id 不便目录化）：暂不可改键，帮助弹窗动态可见。
- **editor 作用域空置**：为 tiptap 编辑器未来自定义键位保留，本期未启用。
- InfoPanel 的 Delete/Backspace 保留组件内监听（Agent 空间群聊也使用，view 层收编会改变其 Agent 空间行为）。
- 旧版 localStorage 覆盖数据按 id 惰性应用：改过键的 id（如 `global.undo`）仍生效；`timeline.*` 等新 id 首次以默认值运行。
- **浏览器降级模式观察项（2026-09-06 冒烟发现，未修）**：无后端时 WelcomeOverlay `show=true` 但视觉不可见，弹窗深度被静默占用=1，全站非 modal 快捷键失效——桌面模式欢迎窗可见可关，不受影响；后续如做浏览器模式支持需先处理其显示条件。

## 7. 新增快捷键流程（维护约束）

1. 判定层级：命令型 → 注册表；组件局部 → 按规范 §3。
2. 注册处直写默认键（**勿**读 settingsStore/getShortcut——已退役）；register 自动应用用户覆盖。
3. 选键规则：global 留给高频跨区命令；view/space 内单字母/连击序列（**序列首键不得与已有单键命令相同**）；space 层键位仅限 Agent 空间命令，id 前缀 `space.`，注册处 AgentSpace.vue（跨组件触达用 expose，左栏 v-if 条件挂载需先开后 nextTick）；不与浏览器/OS 保留键冲突（Ctrl+N/T/W 由 PREVENT_DEFAULT 表兜底）。
4. 同步三处：目录 `packages/ui-kit/src/components/settings/utils.ts` SHORTCUT_CATALOG、帮助弹窗（动态免维护）、涉及行为变更时更新本文 §4/§5。
5. 目录约束：**不允许出现注册处没有的死条目**。
