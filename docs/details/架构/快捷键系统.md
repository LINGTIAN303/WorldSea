## 0. 一页结论

- **命令层（唯一权威）**：所有「命令型快捷键」统一进 `packages/ui-kit/src/composables/useShortcuts.ts` 单例注册表（chord 组合键 + sequence 连击序列两种键型），scope 四层 `modal > editor > view > global` 优先级仲裁（space 层随旧 Agent 面退役，2026-09-30 C 批清退），用户自定义键位持久化 `localStorage['worldsea_shortcuts']`。
- **组件局部层（规范约束）**：菜单 ↑↓ 导航、Tab 焦点陷阱、输入框内 Enter 等组件局部交互键保留在组件内（元素级 `@keydown` 或浮层 show 期监听），禁止与注册表抢键。
- **弹窗优先**：弹窗深度机制保证弹窗打开期间 view/space/global 层全部失效；view 层命中即消费（stopImmediatePropagation），残留监听不再重复执行。
- **展示同源**：设置面板/帮助弹窗/菜单标注全部读注册表，改键后展示自动同步。

## 1. 两层职责架构

```
┌─ 命令层 useShortcuts（唯一权威）──────────────────────┐
│ registry: Map<id, ShortcutDef>                        │
│ document 冒泡唯一全局 keydown 分发器                     │
│ 键型：chord（组合键）/ sequence（连击序列 500ms 超时）    │
│ scope：modal > editor > view > global                  │
│ 约束：view 层需 activeViewId 非空（无视图上下文时失效）    │
│ 约束：弹窗深度>0 时仅 modal 层生效                       │
└───────────────────────────────────────────────┘
┌─ 组件局部层（书面规范约束）──────────────────────────┐
│ 元素级 @keydown：菜单导航/表单提交/a11y 触发             │
│ 浮层 show 期监听：Tab 焦点陷阱（焦点管理非快捷键）        │
│ 持续态键：Space 按住平移画布（keydown 置位/keyup 复位）   │
│ 终端：xterm onData 直通 PTY（无拦截）                   │
└───────────────────────────────────────────────┘
桌面壳（Tauri global-shortcut）：Ctrl+Shift+W 唤起/隐藏主窗口——OS 层注册，
不受注册表管理、不可改键，仅在帮助弹窗「系统级」分组展示。
窗口控制键（TitleBar 固定监听）：Ctrl+M 最小化 / F10 最大化还原 / F11 绝对全屏 / Ctrl+W 关闭——
同为系统级固定键（不进注册表、不可改键），弹窗/输入焦点期间照常可用（Alt+F4 同语义）。
Agent 空间窗（dsh 页，注入式窗口栏）：窗口控制四键齐备（G1 收尾，2026-09-30）——
Ctrl+M / F10 / F11 / Ctrl+W 由 dsh_titlebar.js 页面侧监听承接（F11 捕获相位；其余冒泡相位 +
终端区让行），并接 Ctrl+Tab 切空间（全屏下的唯一键盘通路）。
```

## 2. 机制要点（useShortcuts 2.0）

1. **键型**：`ShortcutDef.kind: 'chord' | 'sequence'`（默认 chord）。sequence 的 `keys` 按序逐键匹配（如 `['n','c']`），500ms 超时重置，Esc 清空；进行中状态导出 `currentSequence` 供提示 UI（MindmapKeyHint）读取。
2. **IME 保护**：分发器入口 `e.isComposing || e.keyCode === 229` 直接忽略——中文输入法选词/上屏期间任何快捷键不触发。
3. **shift 归一化**：非字母可打印字符（`?` `,` `=` `-` `0` 等）的 shift 信息已体现在 `e.key`，不再叠加 shift 修饰符（否则注册 `['?']` 与实际 `['shift','?']` 永不匹配）；字母与特殊键保持叠加（Ctrl+Shift+Z 依赖）。
4. **弹窗深度**：`setShortcutModalActive(true/false)` 由四个浮层基座（TuiModal/TuiDrawer/DialogContainer/useFocusTrap）show/hide 时调用（含卸载泄漏保护）。深度>0 时仅 modal 层生效——修复「弹窗开着时按 Esc 误触发视图返回上层 / 数字键切视图」等穿透。
5. **view 层命中消费**：view 命中即 `stopImmediatePropagation`——document/window 级残留监听（如 InfoPanel 的 Delete）不再重复执行同键行为。modal/global 暂不阻断（存量浮层 window 监听渐进收编）。
6. **视图上下文**：`setActiveViewId` 由 App.vue 按 `currentView` 注入（未装载视图=null）；无视图上下文时 view 层整体失效。ViewContainer 以 `<component :is>` 单实例切换挂载，无多视图并存竞争。序列键（advanceSequences）同享该过滤。（旧 space 作用域 / `setAgentSpaceActive` / `currentShell` 状态已随 E7 残留清退，2026-09-30 C 批。）
7. **改键**：`setShortcut` 同 scope 冲突阻断、跨 scope 遮蔽（modal>view>global）放行但警示、modal 层拒绝；`resetShortcut` 恢复注册时默认值并清持久化。设置面板 ShortcutsPanel 录制走 document capture 阶段（录制期间不触发已注册键），Esc 取消录制。
8. **弹窗组合器 useModalShortcuts**（批7）：自挂监听弹窗的统一收编入口——Esc 关闭收编 modal 层 + 弹窗深度接入二合一；配套**收编弹窗栈**（pushModalShortcut/popModalShortcut），分发器在 modal 层只放行栈顶条目——弹窗叠层时 Esc 只关最后打开的弹窗。新弹窗一律用它，禁止手挂 Esc 监听。

## 3. 组件局部键规范（新增代码必读）

**必须收编注册表的**：一切「用户可感知的命令」（打开/关闭/删除/切换/缩放/撤销/发送命令等）。浮层临时命令用 `useScopedShortcuts(defs, activeRef)`（show 自动注册/hide 注销）。

**保留组件内实现的**（并遵守约束）：
- 元素级 `@keydown`（焦点在该元素上时的局部行为）：菜单 ↑↓ 导航、表单 Enter 提交、a11y 的 Enter/Space 触发。约束：**键不得与注册表同 scope 激活键相同**。
- 浮层 show 期 window 监听：仅限 Tab 焦点陷阱（焦点管理）。
- 持续态键（按住生效）：Space 平移画布（`packages/canvas-engine/src/core/useCanvas.ts` setupKeyboard，已注释登记）。
- **窗口控制键**（`apps/tauri/src/ui/layout/TitleBar.vue` onWindowKeydown）：Ctrl+M / F10 / F11 / Ctrl+W 固定监听，不进注册表（不可配置是需求本身——窗口管理独立于应用内容，弹窗/输入焦点期间照常可用）；IME 保护对齐注册表；展示走帮助弹窗「系统级」分组。
- **Agent 空间窗的窗口键**（G1 2026-09-29 / G1 收尾 2026-09-30；`apps/tauri/src-tauri/src/dsh_titlebar.js`）：dsh 页不用本仓注册表（它是 dsh 自己的 React 应用），故窗口键随注入式窗口栏一起落在注入脚本里，口径照抄上一条（固定键、不进注册表、同样的 IME 保护）。F11 **刻意用捕获相位**——全屏时窗口栏已隐藏，F11 是唯一退出通路，不能被 dsh 内部某个 `stopPropagation` 掐断（下面「禁止 capture 抢跑」条目的**已登记例外**，该条目只约束 Escape）。Ctrl+M / F10 / Ctrl+W / Ctrl+Tab（G1 收尾）走**冒泡相位**并双让行：「已被上游处理（`defaultPrevented`）」与「终端区」（`.xterm` 内 Ctrl+M＝回车 / Ctrl+W＝删词 / F10 是 TUI 功能键——不抢；Ctrl+Tab 无终端语义、终端聚焦时也可切）。
- 终端 xterm：按键流直通 PTY，不拦截。

**禁止**：
- document/window 级 `addEventListener('keydown')` 实现命令型快捷键（改走注册表）；
- capture 阶段「抢跑」Escape（存量三处——ChatInput 权限菜单/ModelSwitcher/CreationPanel——经核查语义自洽保留，新代码不得新增）；**已登记例外**：`dsh_titlebar.js` 的 F11 用捕获相位（理由见上「保留」清单，非 Escape 语义）；
- 在输入焦点判断上自行造轮子（注册表已统一处理 INPUT/TEXTAREA/SELECT/contentEditable）。

**系统级行为（不进注册表）**：
- 窗口控制键：TitleBar 固定监听（见 §1）；**F11 前提=关闭 WebView2 浏览器加速键**（lib.rs setup 内 `with_webview` 调 `SetAreBrowserAcceleratorKeysEnabled(false)`——WebView2 默认把 F11/F12/Ctrl+F 等壳层吞掉不派发给页面，tauri 未透传 wry 的开关，纯前端无解；副作用=F12 快捷键失效，dev 用 open_devtools 兜底）；**同一前提也撑着 Agent 空间窗的 F11**（G1）——该窗的 F11 由注入脚本页面侧监听，若这个开关被摘掉，两个窗的全屏键会一起失效；
- 浏览器原生右键菜单：App.vue 全局 `contextmenu` preventDefault 拦截（事件仍传播，组件自定义右键菜单不受影响）；**输入元素（INPUT/TEXTAREA/contentEditable）右键由 GlobalEditMenu 弹统一编辑菜单**（撤销/重做/剪切/复制/粘贴/删除/全选，`apps/tauri/src/ui/GlobalEditMenu.vue`——命令走 execCommand，粘贴经 clipboard.readText+insertText 保留撤销栈，权限被拒时提示 Ctrl+V）；
- **Tooltip 快捷键标记约定**：拥有快捷键的按钮挂 `data-ws-tip-keys="Ctrl+N"`（展示字符串），全局 Tooltip 浮层在文字右侧渲染灰色 kbd 块（globalTooltip.ts）——新加快捷键的按钮同步挂此属性；title 内不再写括号键位文本。

## 7. 新增快捷键流程（维护约束）

1. 判定层级：命令型 → 注册表；组件局部 → 按规范 §3。
2. 注册处直写默认键（**勿**读 settingsStore/getShortcut——已退役）；register 自动应用用户覆盖。
3. 选键规则：global 留给高频跨区命令；view 内单字母/连击序列（**序列首键不得与已有单键命令相同**）；不与浏览器/OS 保留键冲突（Ctrl+N/T/W 由 PREVENT_DEFAULT 表兜底）。Agent 空间（dsh 窗）键位不属本注册表——见 §1 按窗区分。
4. 同步三处：目录 `packages/ui-kit/src/components/settings/utils.ts` SHORTCUT_CATALOG、帮助弹窗（动态免维护）、涉及行为变更时更新本文 §4/§5。
5. 目录约束：**不允许出现注册处没有的死条目**（双向）——已由 `apps/tauri/src/ui/layout/__tests__/shortcutCatalog.spec.ts` 全目录守卫自动兜底（含 space 禁回插；modal/editor 层定义与动态 id 按政策不参检）。
