# 系统总览

> 一页看清 WorldSea 的形态。数字均为 2026-11-17 实测，复现方式见文末。
> 更细的交接基线见 [现状与冻结面](系统/现状与冻结面.md)；dsh 的装构起见 [dsh 运行手册](dsh/dsh-运行手册.md)。

## 一、项目定位

WorldSea 是一个 Agent 驱动的世界构建（worldbuilding）平台，帮助用户构建丰富、互相关联的虚构世界。

## 二、三层形态

| 面 | 载体 | 页面入口 | 命令面 |
|---|---|---|---|
| **壳** | Tauri 2（`apps/tauri/src-tauri`，Rust，99 条命令注册） | — | 壳桥 + 流桥（两窗共用基座） |
| **Agent 面** | dsh（Node 子进程，IPC 管道，零 TCP） | `worldsea://localhost/`（`main` 窗） | 壳桥 + 流桥 + SSE + 能力桥 |
| **产品域** | Vue 3 前端（`workspace-dist/`，独立构建） | `worldsea://localhost/workspace/`（`workspace` 窗，懒创建） | 壳桥 + 产品域 123 条 + 能力桥 |

三面同源 `worldsea://localhost`。**命令面按窗口 ACL 互斥授权**（`permissions/` + `capabilities/`，拒绝信息点名 `allowed on: [windows: …]`）——这是面与面之间唯一的硬边界。

## 三、顶层目录

```text
WorldSea/
├── apps/
│   ├── tauri/                   # 唯一 GUI：src-tauri（壳）+ src（产品域前端）+ workspace（独立构建入口）
│   ├── installer/               # 安装/卸载向导小壳
│   ├── dsh-plugin-worldsea/     # dsh 插件：产品域工具面（23 条 world_* 工具 + preset-worldsea）
│   └── dsh-plugin-worldsea-console/  # dsh 插件：产品域管理面
├── dsh/                         # Agent 面（deepseek-harness fork）
├── packages/                    # 12 个共享子包
├── worldsea-core/               # Rust WASM 核心
├── tactical-engine/             # Rust WASM 战术引擎
├── docs/                        # 计划 / 详情 / 索引 / 其他
└── scripts/                     # 门禁与工具脚本
```

## 四、第二棵树（产品域插件树）

产品域内部还有一棵**世界语义插件树**，是本仓「一切皆插件」的落点：

| 项 | 实测 |
|---|---|
| 插件数 | **41**（31 `sprout` + 10 `utility`） |
| 插件代码 | 482 文件 / 62,903 行（ts+vue，排除 spec 与 `__tests__`） |
| 贡献位 | 6 个：view / overlay / entityType / relationType / facet / form |
| 服务目录 | 13 项（`world/services.ts`，经 `context.provide` 供插件取数） |
| 树地基 | `apps/tauri/src/world/`：`manifest.ts`（清单规范）· `loader.ts`（静态装载 + 预检）· `tree.ts`（起树/启停）· `api.ts`（作用域化插件 API） |

协议与粒度详见 [插件系统](插件系统/README.md)。

## 六、Rust 侧

| 件 | 职责 |

| `worldsea-core`（WASM） | 核心：serde、validation、migration、graph layout、geometry、terrain、CRDT、DXF、sqlite |

## 七、数据流

- **产品域**：Vue UI → pinia store → `StorageBackend` → `cmd_fs_*` → 磁盘 `worlddata/`。逐跳见 [机制/数据链路](机制/数据链路.md)。
- **Agent 面**：dsh 进程自持会话与工具循环；与壳之间走 IPC 管道帧隧道（`dsh_pipe`），页面流走 `dsh_stream`。
- **跨面**：两条通路——① 文件系统（dsh 工具直读写 `<cwd>/worlddata/`，与产品域同一目录、两套写者）② 能力桥（`cmd_capability_*`，Agent 触发产品域界面动作）。
- **世界树**：产品域内的 Cordis 树（`apps/tauri/src/world/`），41 插件按插件模型装载。

## 八、关键入口

| 想找 | 文件 |
|---|---|
| 壳启动装配 | `apps/tauri/src-tauri/src/lib.rs`（`generate_handler` + `.manage` + `.setup`） |

## 九、常用命令

```bash
pnpm tauri:dev           # 启动 Tauri 桌面端（唯一 GUI；先起 vite 5175）
pnpm test:run            # 单元测试（vitest）
pnpm typecheck:all       # 类型检查（全入口）
pnpm gate                # 六道门禁统一入口（约 7.6s）
pnpm build:wasm-all      # 构建 WASM（worldsea-core + tactical-engine）
pnpm arch:check          # 架构检查（模块登记 / 文件规模 / 依赖边 / 环）
pnpm fork:check          # dsh fork 台账门禁
node scripts/check-doc-links.mjs   # 文档链接校验（断链 0 为准）
cd apps/tauri/src-tauri && cargo test --lib --offline
```
