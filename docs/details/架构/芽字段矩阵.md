## 〇、阅读口径

- **实体字段 = 原子 Trait 字段 + 芽自有字段（ownFields）**。编译顺序：按 Trait 声明顺序展开字段 → 应用 `fieldOverrides` → 追加 `ownFields`；`ownFields` 与 Trait 同 key 时覆盖后者（`compileEntitySchema`）。
- **中文名是展示标签，英文 key 是数据键**。同一 key 在不同芽中可能有不同中文名（例如 `condition` 在道具叫「状况」、在建筑叫「现状」、在大纲节点叫「状态」）。
- **`title` 落地为实体顶层 `name`**；`description`、`tags`、`coverImage` 也落顶层，其余字段落 `properties`（见 [fieldAccessor.ts](../../../packages/plugin-sdk/src/detail/fieldAccessor.ts)）。
- **当前 21 个注册实体类型的芽均使用 `registerEntityV2`**；生成器仍兼容旧版 `registerEntityType`，供未来迁移期使用。
- 字段类型图例：`text` 单行文本 · `textarea` 多行文本 · `number` 数字 · `select` 单选 · `multi-select` 多选（归一名 `multiSelect`）· `tags` 标签 · `image` 图片 · `color` 颜色 · `boolean` 开关 · `entityRef` 实体引用。
- 字段键沿用声明原文（多为 camelCase）；中文名是展示标签。部分历史选项值仍是英文原值（如 `noteType`、`pipeline.status`、`gridType`），表中按原值列出。
- 每个芽的字段顺序 = `compileEntitySchema` 的编译顺序（先 Trait，后 ownFields；同名覆盖保持原位置）。
- 本文覆盖 **21 个注册了实体类型的芽 / 23 个实体类型 / 270 个字段实例 / 151 个唯一字段键**；只注册视图、没有实体字段的芽见 §五。
- 本表的“字段”指**实体 Schema 字段**；关系类型（实体之间的边）、芽 manifest 元数据、用户自定义字段（`customFields`）不在本表范围内。

## 八、维护与来源

- 字段声明真源：
  - 芽自有字段：`apps/tauri/src/world/plugins/<芽>/index.ts` 的 `registerEntityV2({ ownFields })` / `registerEntityType({ fields })`
  - 原子 Trait：`packages/entity-core/src/traits/index.ts`
  - Facet：`packages/entity-core/src/facets/index.ts`
  - 合并规则：`packages/entity-core/src/core/TraitRuntime.ts` 的 `compileEntitySchema`
- 项目级 schema 覆盖：`<worlddata>/.worldsea/schemas/<type>.json`，可按 `label` / `traits` / `ownFields` / `fieldOverrides` 深合并；覆盖字段与用户 `customFields` 不在本表静态快照内。见 `apps/tauri/src/world/schemas.ts`。
- 关系类型（`registerRelationV2`）描述实体之间的边，不是实体字段，未纳入本表。
- `outline` 芽正在另一条施工线推进；其字段以当前代码为准，若本表与代码不一致，以 `apps/tauri/src/world/plugins/outline/index.ts` 为准。
- 重新生成：`node scripts/generate-field-matrix.mjs`（同时更新 MD 与 HTML）。
