## 一、一句话现状

**三层结构已定型并全部落地**：壳（Tauri 2.11.5，本仓 `apps/tauri`）· Agent 面（dsh fork，仓根 `dsh/`，**界面 100% 保留**）· 产品域（旧 Vue 前端，作为**独立「工作台窗」**运行，壳协议 `/workspace` 伺服）。

## 三、命令面与 ACL（数字核实，2026-09-24）

- 壳注册应用命令 **139** 条（`lib.rs` 的 `generate_handler`）；两窗放行合计 **134** 条次，其余一律拒。
- 工作台窗 = `capabilities/workspace.json`（`windows:["workspace"]`）→ `allow-shell-bridge` + `allow-product-domain`（**116 条**，`permissions/worldsea-product.toml`）。
- dsh 窗 = `capabilities/default.json`（`windows:["main"]`）→ `allow-shell-bridge` + `allow-stream-bridge`（**无产品域权限**）。
- 反证口径（实测）：拒绝信息点名 `allowed on: [windows: "…"]`（dsh 窗调 `cmd_fs_stat` → 点名 `workspace`；工作台窗调 `cmd_stream_open` → 点名 `main`）。
- 产品域清单来源 = **产物可达性**（`grep cmd_` 于 `workspace-dist/assets/*.js`）∩ **源码归属**（`apps/tauri/src` + 仓根 `packages/*`，剔除 `packages/agent-runtime/**`）。**新增产品域命令必须先过这两道**。
