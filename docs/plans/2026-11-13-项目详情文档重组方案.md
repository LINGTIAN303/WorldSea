## 二、重组方案

### 2.1 设计原则

1. **`架构/` 按「读者要解决的问题」分组**，不按文件大小或写作时间分组
2. **`前后端/` 补成真正的一层**：前端 / 后端两个分组
3. **过时与已收口件进 `归档/`**，保留可查但不再干扰阅读
4. **不动的部分不动**：`注释/`(75) / `端分离/`(13) / `截图/`(206) / `芽生态/`(8) 结构健康
5. **新增 `README.md` 作为每层入口**（符合「专题目录须带 README」规则，层目录同样需要）
