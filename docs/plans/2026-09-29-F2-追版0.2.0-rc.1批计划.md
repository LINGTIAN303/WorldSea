## 三、上游四条与我方的关系（本批的实质内容）

1. **C6 直接受益（本轮回归重点）**：`client/ui-layout/src/client/AppFrame.module.css` 现在为 `html[data-windows-titlebar]` 正式声明 `--dsh-frame-top-clearance: var(--dsh-windows-titlebar-height)`，并新增 `--dsh-frame-overlay-top: calc(clearance + 20px)`、`--dsh-frame-chrome-top`，以及 `[data-fullscreen]` 下把 overlay-top 降回 `20px`、chrome-top 归零的两个分支；`ui-primitives/src/overlay-top-margin.ts` 相应改为 `clearance + 20`（全屏只留 20）；`Modal.module.css`/`Menu.module.css`/`ui-dockkit` 的 `FloatLayer.tsx`+`TabLayout.tsx`+`dockkit.module.css` 随之避让。→ **我方那 32px 壳级窗口栏第一次被上游当一等公民**，「弹窗/菜单/浮动面板压标题栏」会被修掉。**代价**：浮层顶部内缩从各自 min 变成 **52px（32+20）**，观感必须真机复验。
2. **D3 那个「资源管理器打开无效」上游原生修了**：根因是 `util/native-command/src/runner.ts` 的 `runNativeCommand` 一律 `windowsHide: true`，把 explorer 的**文件夹窗口**也 SW_HIDE 了（`path-opener.ts` 新注释原文：*SW_HIDE also hides Explorer's folder window, not just console windows*）。新版给 runner 加第四参 `window: 'hidden' | 'visible'`，`explorer.exe` 走 `'visible'`，其余后台命令（`defaults`/`open`/`wslpath`/`xdg-open`/PowerShell 关联查询）走 `'hidden'`。→ 我方 `da769eb` 的壳 proxy 拦截（`try_open_explorer_from_shell`，靠前台应用子进程继承前台权）**可能就此冗余** → 决策 ②：实测后退役。
3. **C4 有了官方对照物**：`sandbox/sandbox-windows-acl` 新增 `src/acl-skill.ts`（SkillProvider 注册，私有资源副本以便 ASAR/SEA 下外部 PowerShell 可执行）+ `assets/diagnose-windows-sandbox-acl/{SKILL.md,scripts/*.ps1}` + 4 个测试。取向是 **Agent 面**（技能，失败即停、带备份可回滚、限定目录），与我方 C4 的**壳 UI 面**（`workspace_probe.rs` 无副作用 WRITE_OWNER 探针 + 横幅 + 菜单一键 `icacls`）不冲突、不重叠 → 本批仅在 fork 台账/运行手册登记「上游对照」。
4. **自动化任务改可选 bundle**：`time-context`/`schedule`/`ui-schedule` 三行从 `bundle/web-app/cordis.patch.yml` 删除（rc.2 里它们本就 `disabled: true`，我方从未开启），改由新包 `packages/experimental/schedule-bundle` 提供并加入 `boot/app-boot/src/profile.ts` 的 `OPTIONAL_BUNDLES`（「由插件管理提供、默认关」）；同时删除 `apps/cli/tests/profiles/web/tests/fixtures/schedule.patch.yml`。→ **功能无损失**；插件管理页会多一个关着的可选条目（走查时确认它不干扰 D3 console 标签页）。

**同轮顺带取证的两条**：
