## 五、行为等价性核对（无测试覆盖的部分）

`RegionMap.vue` 与 `FilePickerHost.vue` 没有专属 spec，靠人工逐项核对：

**RegionMap**
- 命中容差未变：顶点 `< 64`（8px）、边 `< 36`（6px）、面用射线法
- 命中优先级未变：顶点 → 边 → 面（`vertexIdx` 语义 `>=0` / `-2` / `-1`）
- 缩放限位未变：`zoomIn` 上限 5、`zoomOut` 下限 0.1、`wheel` 因子 0.9/1.1 且夹在 [0.1, 5]
- 双击加点未变：偏移模式下边中点距离 `< 30` 才插入，且 `eraseBorderFixedIndices` 后续索引 +1
- 边界键语义未变：keydown 置位 / keyup 复位，键值读注册表 `region.borderline`，keyup 走别名归一
- 拖拽分支顺序未变：draw 三态（offset / redraw / 普通）→ edit 邻接 → edit 命中 → edit 空击 → pan
- `fitAll` 未变：跳过 (0,0) 原点、`+100` 边距、`*0.85` 留白、平移 `+50`
- 光标态未变：edit 命中 `pointer` / draw `crosshair` / 其余 `grab`
- tooltip 偏移未变：`clientX + 12` / `clientY + 12`

**FilePickerHost**
- 列表行结构与属性未变：`fp-row` 类名、`role=option`、`aria-selected`、`aria-disabled`、`title` 取 `limit || path`
- 单元格内容未变：目录图标 / 缩略图（`loading=lazy` + `decoding=async`）/ 文件图标、名称 / 时间 / 类型 / 大小
- 事件语义未变：单击带 `shiftKey`、双击进入、hover 进预览、leave 收预览
- spacer 总高未变：`visibleEntries.length * rowHeight`
- 导航行未变：后退/前进的 disabled 边界、上级、路径输入 Enter 提交 / Esc 复位、刷新
- 视图切换未变：`aria-pressed` 标注、`list` / `grid` 两态

## 六、顺带修掉的两处既有缺陷

1. **`ListRow` 与 `PickerRow` 类型分叉**：抽 `FilePickerList` 时曾自建 `ListRow`（`limit?: string`），与 `useFilePickerBrowse` 的 `PickerRow`（`limit: string | null`）不兼容 → 改为直接复用 `PickerRow`，不再新增重复类型。
2. **`BackgroundScopePicker` 的条件 emit 类型收窄失败**：`emit(isProjectCustom ? 'followGlobal' : 'makeCustom')` 在联合签名下无法收窄 → 改为分支调用。
