## 二、manuscript bridge：核心 6 项（拍板）

- `create_chapter`：真建 manuscript 实体（title/content/volumeName/status；英文状态枚举 draft/writing/review/done → 中文映射；bookId = 当前选中书、sortOrder = 书内序、wordCount 去标签计数）。
- `update_chapter`：chapterId 定位；content 更新带 wordCount 重算；status/volumeName 可选更新。
- `list_chapters` / `get_chapter_content`：**emitPluginQuery 无返回通路**（架构级共性缺陷）→ window 变通回传（`__worldsea_manuscript_chapters__` / `__worldsea_manuscript_chapter_content__`，notebook 同款惯例）。
- `export_document`：触发导出对话框（格式/范围由用户确认，Agent 不越权直接下载）。
- `reorder_chapters`：chapterIds 数组依序写 sortOrder。
- **留挂账**：`insert_mention`（按字符偏移插入 @实体——插入位置语义需设计）、`split_chapter`（按拆分点数组拆正文为多章——需新拆分逻辑）。
- **共性缺陷另账**：bridge 依赖视图挂载，未挂载仍假成功（架构级，notebook 同病）。

## 三、outline：对齐 + 补 4 项（拍板）

- **留挂账**：`get_structure`（query 无返回通路）、`link_entity`（建关系语义待拍板）；视图侧孤立的 `navigate` case 保留（无害）。

## 六、侧栏形态优化（2026-09-15 晨，用户授权项落地）

### 可用性修复（形态优化中发现）

- **列表无滚动容器**：`.chapter-list` 为 `height:100% + overflow:hidden` 而分组列表**没有滚动区**——章节多时内容被裁剪且不可滚动（多轮迭代遗留）。新增 `.cl-list`（`flex:1; min-height:0; overflow-y:auto`），空态一并入内。父链滚动职责：`.ms-chapter-wrap`（flex:1/min-height:0）→ ChapterList(100%) → `.cl-list`。
- **空态文案不符**：preset 默认描述提「点击下方按钮」但新建入口在顶部工具条 → 改自定义「点击上方「新建章节」开始创作」；无结果态改用 `preset="no-result"`（默认文案即「尝试调整筛选条件或搜索关键词」）。

### 形态优化（呈现层，操作路径零变化）

- **状态呈现改「色点体系」**：整块彩底 chip（`--warning-soft` 等）→ 6px 色点 + 文字（行内与统计条共用 `.cl-dot`/`.cl-dot--draft|revising|final`）——克制化，彩色只留信息点；`statusClass` 旧色块函数删除。
- **当前章节定位感**：左侧 2px 主色竖条（`::before`）+ 名称主色（原仅背景色块）。
- **章节行两栏化**：名称一行 + meta 行（左：状态点/标签；右：字数 `margin-left:auto` 右对齐）；标签 chip 加 `max-width:64px` 省略（防长标签挤压）。
- **分组头信息增密 + 吸顶**：右侧「N 章 · X 字」（原仅数字，`groupWords()` 汇总）；`position:sticky; top:0`（长列表滚动时组头常驻）。
- **节奏统一**：行 padding 7px/左内缩 22px、组头 padding 12px（与行对齐）、组头字号降为 xs。
- **空态紧凑化**：侧栏窄区覆盖 `.ws-empty`（图标 28px、间距 8px、文案宽度 180px）——原 `size="xl"` 图标 + md 字号在 260px 侧栏里臃肿。
- **折叠热区**（ManuscriptView）：28px 窄条 → 32px，图标包 24px 圆角块 + hover 背景（原仅图标变色，点按区窄）；返回条去横向 margin 改 padding（hover 满宽更规整）。
