# 三模式移除计划（深度思考 / 知识探索 / 任务执行）

> 立项（2026-08-31 用户拍板）：**深度思考、知识探索、任务执行三个模式将被移除，不再区分**。
> 归属：UI/会话语义收敛——普通会话统一为「无模式」，不做模式区分；`group-chat`（群聊类型标记）独立保留。
> 关联：R6 第四部分已按通用路径修复路由决策泄漏（不围绕模式做 patch）；本计划为后续模式概念的清理。

## 一、三模式是什么（现状语义）

| 值 | 标签 | 现状作用 |
|---|---|---|
| `deep` | 深度思考 | 默认模式；DeepPhase 五阶段判定 + DeepPhaseChanged 事件 + 前端 deepSegments 阶段展示 |
| `explore` | 知识探索 | 知识库→联网→项目数据→模型知识 的检索式回答（无独立后端逻辑，仅前端标签） |
| `task` | 任务执行 | 自主规划+连续执行（无独立后端逻辑，仅前端标签） |
| `normal` | （旧值） | core-types 中仍定义，非默认，历史代码兼容 |
| `group-chat` | 群聊 | **保留**——群聊会话类型标记（与三模式无关） |
