## 关键设计决策（走查重点）

1. **三态视图**（编辑 / 分栏 / 预览）替代原「编辑⇄预览」二态：分栏为新增主力形态，**纯预览保留**（沉浸阅读，批 4 不能丢「阅读」本身）；分段控件在工具栏右侧。
2. **修复「预览陈旧」隐藏 bug**：旧 `previewHtml` computed 无文档级响应依赖（`getHTML()` 非响应式）→ 预览内容只在首次求值/编辑器重建时生成。现由 `previewTick` 驱动（切模式立即刷、编辑中 250ms 防抖刷、切笔记立即刷）。
3. **滚动同步 = 标题锚点映射**：两侧内容同源（同一 HTML 的编辑/渲染），以标题锚点分段 + 段内线性插值，无标题退化整段比例；双向（编辑→预览 / 预览→编辑）+ 150ms 回声窗防环 + 差值跳过防抖。纯函数 `mapScrollTop` 可测。
4. **按状态严格隔离（走查修正）**：**预览 = v-if 按状态挂载**——编辑态预览完全不渲染（DOM 不存在、`previewHtml` 不求值、防抖计时器切回编辑即取消）；**编辑器 = v-show 有意常驻**——卸载编辑器 DOM 会销毁 TipTap 视图（丢光标/选区/撤销上下文），技术硬约束，display:none 不绘制。滚动容器 = 各 pane（.nb-split-pane）。
5. **条目组件化**：侧栏 5 处条目模板（搜索/置顶/未分类/文件夹/最近）统一为 `NoteTreeItem.vue`；摘要两态——搜索=命中高亮（迁自 FolderTree.snippetOf）、常态=前 42 字。
6. **类型色单源**：`notebookConfig.NOTE_TYPES.color`（markdown=accent / code=info / canvas=warning / reference=success，基础层 token 双主题），侧栏图标与看板色条共用。
7. **封面口径与书籍同源**：真源 = visual trait 顶层 `coverImage`（notebook 已有该 trait，无需改 schema）；旧数据 `properties.cover` 回退；无封面卡片不显示头图区。
