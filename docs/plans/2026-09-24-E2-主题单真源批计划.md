## 三、★ 关键发现：dsh 的 HTTP API 是 **RPC 信封**

实测（错三次才成，口径留给后续所有壳侧 dsh 调用）：

- 路由 = `/api/<ns>/<method>`（如 `/api/settings/describe`），但 body 必须是信封：
  `{"type":"client-request","rpcId":"…","method":"<路由名>","payload":{"args":{…}}}`；
- 缺 body → `400 body is not JSON`；`method` 与路由不一致 → `gateway/bad-request: method "…" does not match endpoint "…"`；
- `payload` 必须**恰好一个对象字段 `args`**；字段名按端点 schema：`settings/update` 要 `patch`（不是 `input`）；
- **读主题别解析 `settings/describe`**：多个命名空间/schema 都有 `preference` 同名键（实测误读成相邻键 `fontSize`）→ 改读 **index 的 boot-theme 行**（`const preference = "…"`，形状固定）。
