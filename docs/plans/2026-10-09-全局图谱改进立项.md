## 一、现状盘点（2026-10-09 探查）

**栈**：sigma 3.0.3 + graphology 0.26 + `graphology-layout-forceatlas2` 0.10.1（无 `@sigma/*` 附包）。
数据管线 = `canvas-engine/useGraphData`（实体→节点含 degree/类型元数据；关系→去重边**含完整视觉元数据**）；
渲染 = `graph/GlobalGraph.vue`（588 行，arch 冻结 594）+ 6 个 composable；布局 ≥200 节点走 worker +
sessionStorage 缓存；WASM 算法（Dijkstra/社区检测）经 worker 池，失败降级 JS。

**已具备（超出截图所现）**：三种布局（FA2/圆圈/随机）、类型筛选、社区聚类检测、路径搜索+粒子动画、
时间轴过滤、节点详情面板、悬浮提示、双击邻居聚焦。

**「简陋」病灶清单（代码级定位）**：

| # | 病灶 | 位置 |
|---|---|---|
| A | **边不可见且元数据全丢**：一律 `rgba(255,255,255,0.12)` 1px；数据层 `GraphEdge` 的 `coolColor/noArrow/bidirectional/dashed/curveStyle/relLabel` 在渲染层全部未用；无方向箭头 | `GlobalGraph.vue:206` |
| B | **标签策略弱**：`labelRenderedSizeThreshold: 8` 恒档，小节点永不显名；路径搜索建议行把 icon 名当文本渲染 | `useSigmaRenderer.ts:24`、`PathSearchPanel.vue:13` |
| C | **布局与适应画面**：FA2 参数偏弱（scalingRatio 1/slowDown 1.5）＋随机初值 → 散沙；`fitToGraph` 不解边界，固定飞 (0.5,0.5)/ratio 1.1；布局缓存只校验节点集合（边变化仍复用旧位） | `useGraphLayout.ts:234` |
| D | **交互缺陷**：tooltip 钉死左上角（x/y 恒 0）；双击聚焦无显式退出；无搜索高亮；节点不可拖拽 | `GlobalGraph.vue:317` |

**外部依据**：sigma 3.0.3 **内置** `edge-arrow`/`arrow-head`/`double-arrow` 等边程序（本仓 node_modules
已验；0 新依赖）；曲线边需 `@sigma/edge-curve`；Obsidian 图谱范式（搜索高亮/箭头开关/文字阈值/受力/
拖拽）为交互对标（[帮助页](https://obsidian.md/zh/help/plugins/graph)）。

## 二、四裁定（用户 2026-10-09 拍板，AskUserQuestion）

1. **边语言＝全上**：按关系类型着色（27 色）+ 方向箭头（`noArrow`→无；双向→双箭头；其余→单箭头）+
   线宽分级 + 选中/聚焦时显关系标签。
2. **画布底色＝双档可切**：设置面「图谱底色：深色 / 跟随主题」，两种都保留。
3. **交互补齐＝全取**：悬浮信息跟随鼠标（修钉角缺陷）+ 聚焦模式+显式退出 + 搜索高亮 + 节点拖拽。
4. **聚类＝着色上画布 + 命名语义化**（与类型色互切；命名「主导类型·Top 成员名 (N)」）。

## 三、批分解（每批：实现 → 门禁四件套 → 变异 → 提交 → 文档 → 用户真机走查）

- **批 A：工程底座减压 + 边语言全上 + 标签策略**——`GlobalGraph.vue` 先外移
  `buildGraphology/syncGraphColors/applyTypeFilter/onTimelineFilter/onTimelineReset/incrementalUpdate`
  至新 `composables/useGraphModel.ts`（减压后视图只留接线）；新纯函数件 `edgeStyle.ts`（程序选择/颜色/
  线宽）；节点标签按缩放两档（`labelThresholdFor(ratio)`）；选中与路径上边写 `label` 显关系名。
- **批 B：交互补齐 + 缺陷修复**——tooltip 重写（跟随/节点与边两态）；聚焦模式（淡化+「返回全图」
  芯片，芯片/Esc/点空白三通道退出）；搜索高亮（收束条搜索框+计数+飞至命中）；`useNodeDrag` 节点拖拽；
  WASM 提示初态修正；符号图标换 `WsIcon`（含 PathSearchPanel 建议行）。
- **批 C：布局质量**——`layoutParams.ts` 按规模重调 FA2；**真·适应画面**（`computeFitCamera(bbox, viewport)`
  替换写死相机）；缓存键带边数防陈旧；孤立节点聚拢。
- **批 D：底色双档 + 面板皮肤**——设置·外观加「图谱底色」；浅色档画布/图例/浮层换主题令牌皮肤。
- **批 E：聚类升级**——「按社区着色」开关（社区色上画布）+ `clusterLabel` 语义命名 + 簇项悬停高亮社区。

## 四、工程约束与风险

1. `GlobalGraph.vue` arch 冻结 **594**（现 588，余 6）——**批 A 先减压**（外移 ≈180 行）再改；
   后续批新逻辑一律入新件，视图不涨行。
2. 冻结纪律：不改 `architecture-baseline.json`；新 spec 进 vitest include 白名单内路径。
3. 渲染层无自动化手段（WebGL 画布）——纯函数抽到 `edgeStyle/layoutParams/…` 直测 + 变异；
   视觉终审走用户真机走查（每批给预期与测法）。
4. 需真机验证项：WASM 图算法真实健康度（提示条修复后复核；若真降级另立项）。

## 五、登记项（本轮不做）

- 曲线边（需新增依赖 `@sigma/edge-curve`）；虚线边与节点形状（cytoscape 形状词汇，需自绘边/点程序）。
- 500 节点截断（`truncatedNodes`）本视图未启用——现规模无碍，规模上来再议。
- 边权重语义（现全体 weight=1，路径即无权最短路）。
- **UI 批（视觉优化与改进）**：用户同日另行登记的独立线，不属本立项范围。
