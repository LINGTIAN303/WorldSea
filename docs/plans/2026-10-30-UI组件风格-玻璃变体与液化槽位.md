# UI 组件风格 · 玻璃变体与液化槽位（P2）

> 质感轮的后续四项：性能模式修复、clear 变体配置化、磨砂巧克改名、液化玻璃槽位。

## 一、范围

1. **性能模式修复**：clear 灯箱的模糊改为 `--sf-clear-filter`，性能模式置 `none`；其余模糊已在令牌层生效（浏览器探针实测）。
2. **clear 变体配置化**：`useStyle` 增加 `glassVariant`（`regular | clear`），持久化 `worldsea_ui_style_glass`，写入 `<html data-glass>`；磨砂巧克下出现「玻璃变体：常规 / 清透」配置；防闪脚本同步。
3. **改名**：`soft-glass` 的展示名改为「磨砂巧克」，id 不变，保留既有用户设置。
4. **液化玻璃槽位**：`StylePack` 增加 `status: ready | planned`；新增 `liquid-glass` 计划中槽位，外观面板展示为「研究中」且不可选；选择器与持久化只接受 ready。
5. **研究**：另立 [液化玻璃研究](2026-10-30-液化玻璃研究.md)。路线已从 SVG 位移 / WebGL 折射转为**纯 CSS 分层**；当前候选 C（遮罩边带 + 锥形镜面），待产品内验证。

## 二、实现

- `packs.ts`：`StyleStatus`、`READY_STYLE_IDS`、`liquid-glass` 槽位。
- `useStyle.ts`：`glassVariant` + `setGlassVariant`；`setStyle` 与持久化读取只接受 ready。
- `soft-glass.css`：`[data-glass='clear']` 亮暗两套低透明 + 更强模糊配方。
- `base.css` / `perf.css`：`--sf-clear-filter` / `--sf-clear-bg`，性能模式置 `none`。
- `ImageLightbox.vue`：改用 clear 令牌。
- `AppearancePanel.vue`：计划中卡片禁用 + 徽标；磨砂巧克下显示玻璃变体分段器。
- `workspace/index.html`：防闪写入 `data-glass`。
- 测试：计划中不可选、玻璃变体持久化、clear 配方与性能开关、灯箱令牌化。
