## 二、本批改动

### 2.1 浮层层级

- `theme.css` 新增 `--z-popover: 400`：**高于视图工具条 300、低于 modal 1000**。
- 四个组件（manuscript / notebook × MentionPopover / SlashCommandMenu）的 `z-index: 200`
  改为 `z-index: var(--z-popover, 400)`；`position: fixed` 与定位逻辑不动。
- 语义：提及 / 斜杠菜单属于「编辑器内浮层」，不参与 modal 层；弹窗打开时仍由 modal 遮罩优先。

- 不改行为、不删函数；仅：
