# R3-c · 五形态调整与改进

> 定位：R3-a（1–4 单侧栏）与 R3-b（5/6 双栏）之后的**打磨批**，不新增导航架构；输入 = 用户真机走查问题 + 既有边界项。
> 触发：R3-b 走查通过后启动。R3-b 未收官前只登记候选池，不施工。

## 一、范围

对五种形态（平铺 / 域弹出层 / 域图标栏 / 域-芽 Tab / 双栏导航组）做视觉、交互、可访问性与细节一致性调整。

不做：R4 设置页按域分组、R6 数据模型、新的导航模式。

## 二、候选池（R3-b 后按用户优先级取）

| 类别 | 候选 | 来源 |
|---|---|---|
| 信息 | 将实体数量徽标带入 2–4 与双栏（当前只显示可见芽数） | R3-a 边界 |
| 排序 | 形态 2–4 / 双栏的域内拖拽重排（跨域不重排） | R3-a 边界 |
| 工具域 | 工具域默认折叠 / 单独分组 | 研究 05 / 用户暂缓 |
| 高频入口 | 收藏 / 最近使用 | 研究 05 / 用户暂缓 |
| 发现性 | 管理 / 添加入口（完整域树） | 研究 05 / 用户暂缓 |
| 空态 | 域内无可见芽、外部 unclassified 的显式提示 | 研究 05.8 / R5 前置 |
| 布局 | 双栏宽度、收起方式、左右侧栏、窄窗降级 | R3-b 走查 |
| 交互 | 浮层定位/焦点/键盘导航、Tab 切换动效、形态切换动效 | R3-a 走查 |
| 可访问性 | 域/芽列表的焦点环、aria-current、键盘可达 | R3-a 走查 |
| 一致性 | 三种形态的间距、字号、激活色、空态文案对齐 | R3-a 走查 |

## 三、流程

1. R3-b 真机走查通过，收集用户问题与本表候选。
2. 用 AskUserQuestion 让用户选本批范围与优先级（P0/P1/P2）。
3. 按批施工；每项含预期效果与走查方法。
4. 走查通过后归档，索引/ARCHIVE 同步。

## 四、边界

- 不改 `SidebarV2` 的物理轮盘与既有平铺行为（除非用户明确要求）。
- 不把 R3-c 与 R4/R6 混做；域分组设置页、数据模型另立。
- 先解决“看得见/点得到”的问题，再做装饰性动效。
