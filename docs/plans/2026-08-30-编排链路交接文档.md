## 三、缺陷修复记录

| # | 缺陷 | 根因 | 修复 |
|---|---|---|---|
| R14 | 回源命令段全部误标「执行失败」 | Rust `MessageRole` serde lowercase 实际值 `"toolresult"` 未被匹配 → action_end 全不触发 → settle 兜底置 failed | 角色三态兼容 + 类型/映射同步 + 真实值回归用例 |
| exit_code | shell 失败显示 ✓+exit 1 矛盾 | 后端 shell 结果以 exit_code 表达成败（顶层无 error 键） | parseToolResult 补 `__meta.exit_code≠0 → failed` |
| 执行器·取消 | with_cancel 注入失效（无限循环） | run() 内新建 CancelToken | `with_cancel()` 注入，与节点共享 |
| 执行器·嵌套回接 | 子图终止回接只查最外层父图 | 嵌套组合场景漏查中间作用域 | 从剩余作用域由内向外查 |
| 执行器·fan-out | route 单目标丢失分支 | M1 route 返回首条 | `route_all` 多目标 + Branch 谓词组互斥 |
