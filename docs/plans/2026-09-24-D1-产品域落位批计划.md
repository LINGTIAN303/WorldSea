## 一、载体决定（独立窗口 + 壳管理互斥切换）

**决定：独立 Tauri 窗口（label=`workspace`）+ 窗口栏「工作台」切换控件做互斥切换。**

理由：
1. **ACL 按窗口隔离**：Tauri capability 的 `windows` 项可按窗口授权——dsh 窗口只留壳桥/流桥命令，工作台窗口单独授权产品域命令族；**同窗口覆盖层 / iframe 均不行**（ACL 按窗口不按页面，会迫使产品域命令对 dsh 页面开放 = C3 安全面退步）。
2. **迁移干净**：工作台是完整 Vue 应用，独立窗口独立跑——无注入冲突、无样式污染。
3. **切换体验可做到位**：点「工作台」→ 壳 `hide()` dsh 窗口 + `show()` 工作台窗口（反向亦然），两窗口位置/尺寸同步——观感等同「同窗口切换」。

## 七、完成记录（2026-09-24）

### D1-a 落实

- **构建入口** `apps/tauri/workspace/`（`index.html` + `main.ts` + `vite.config.ts`）；**构建命令**（从 `apps/tauri`）：
  `node node_modules/vite/bin/vite.js build --config workspace/vite.config.ts` → 产物 `apps/tauri/workspace-dist/`（**已 gitignore**；本次 12,963 模块 / 22MB / 219 个 js）。
- **★ 实测补正：首版 stub 规则多数静默不命中**。根因 = `resolve.alias` 在插件 `resolveId` **之前**生效 → 同一模块到本插件有两种写法（裸包名 / alias 后**绝对路径**），按裸名写的规则全不中；后果是**真** `agent-runtime` 注册表与模型/技能/MCP 代码仍在产物内，且 `main.ts` 把桩 descriptor `{}` 交给真注册表 → 启动即抛 `TypeError: e.capabilities is not iterable`。修法 = 加 `canonical()` 归一（`…/packages/agent-runtime/src(/)` → `@worldsea/agent-runtime` / `@agent/…`；`…/apps/tauri/src/` → `@/`），规则一律按归一体写。
- **★ 桩的取舍（桩掉 agent-runtime 根会连锁缺导出）**：`@worldsea/agent-runtime` 根与 `@agent/index` **有意不桩**（真注册表 + 真 descriptor 自洽，mindmap 硬绑点传的就是真 descriptor）；只桩**叶级**：`@/agent/**/*.vue`（旧 Agent 设置面板 → 空渲染组件）、`AgentSpace.vue`、`useAgent` / `useAgentRust` / `useOrchestrator` / `useAgentPluginBridge` / `preloadModels` / `useModelFetchWatcher` / `useActivityLog` / `useMcpConnections` / `agentDataBridges`、`worldRulesInjector`（只留产品域要用的**阈值读写**，与真实现逐字对齐）。**Agent 内核留在产物属 R2 已知边界**——对工作台窗不可达、命令面由 ACL 兜底。
- **壳协议 `/workspace` 前缀伺服**（新模块 `workspace_dist.rs`，~200 行）：产物**运行时读盘**（`WORLDSEA_WORKSPACE_DIST` 可覆盖；缺省 `<crate>/../workspace-dist`；目录缺失给可辨认错误页 + 构建命令）；闸门 = 只 GET/HEAD（405 带 `allow`）+ 段级越界拒（`.`/`..`/`\`/盘符/NUL）+ `canonicalize` 包含性复核；缓存 = `assets/`（内容哈希名）`immutable`、index 与其余 `no-store`；index 注入 = 「不白屏」安全网（**root=#app**，与 dsh 页的 `#root` 区分——watchdog 加 `__WORLDSEA_BOOT_ROOT__` 参数）+ 空间切换桥 `__WORLDSEA_SPACE_SWITCH__`；CSP 与 dsh 页同口径（`dsh_proxy::CSP_INDEX` 单点）。
- 路由：`lib.rs` 协议闭包先判前缀 → `/workspace` 走 `workspace_dist`（**不依赖 dsh 桥**，宿主未就绪也能开工作台）；其余仍走 `dsh_bridge`。
