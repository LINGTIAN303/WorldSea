# A2UI 画布回源 / 持久化

> status: **已完成**（实现 2026-09-17 + 真机走查 3 项通过：建卡片→切会话→恢复 / 删实体→刷新→不复活 / LLM 建画布→刷新→恢复）
> 立项理由：画布是**交互载体**（按钮动作经 `[A2UI Action]` steer 回传 Agent）——刷新/切会话即失会导致交互链断裂。A2UI 接线（2026-09-17）后画布成为日常产物，回源缺口从"挂账"变为"可见缺陷"。
> 关联：[04-施工准备 §八 候选 1 后续](2026-09-16-deepseek-harness-方向探究/04-施工准备.md)（A2UI 接线的姊妹项）、[R6 动作段持久化计划](2026-08-30-R6动作段持久化计划.md)（其表格 a2ui 一栏"仅存前端内存，回源即失"，本文闭合该缺口）。

## 一、现状链路与缺口（2026-09-17 取证）

| 环节 | 现状 | 证据 |
|---|---|---|
| 发射 | ✅ 桥工具 → `cmd_agent_emit_a2ui` → 会话总线 `A2UIEvent` → `agent:event:a2ui:{sid}` → `handleA2UIEvent` | [commands.rs](../../apps/tauri/src-tauri/src/commands.rs)、[useAgentRust.ts](../../apps/tauri/src/agent/composables/useAgentRust.ts) |
| 持久化 | ❌ emitter 的 `action_event_payload` 未覆盖 `A2UIEvent` → 不入 `meta.action_events`（虽 doc 注释已列 a2ui 为六类之一） | [commands.rs:54-103](../../apps/tauri/src-tauri/src/commands.rs) |
| 回源 | ❌ `switchSession` 清空 `a2uiSurfaces` 后不重建（轮次树有 `rebuildTurnsFromMessages`，画布无对应物） | `useAgentRust.ts:2341`（清空）/ `:2384`（轮次重建） |

> 现状语义：**刷新即失、切会话即失**；`turnModel` 的 `ActionKind.a2ui` 注记"暂不可回源"即此缺口。

## 二、方案（复用 R6 动作段通道，不新建第二条通道）

> 选型说明：R6 动作段通道已具备"缓冲 → AgentEnd 收口 → `meta.action_events` 持久化 → 回源重建"全链语义；a2ui 复用即为**双轨防护**纪律下的自然落点（独立新表/新通道属过度设计）。

| # | 落点 | 内容 |
|---|---|---|
| 1 | **Rust（1 处）** | `TauriAgentEventEmitter::action_event_payload` 增 a2ui 臂：`("a2ui", { surfaceId, message })`（message 为 camelCase `A2UIMessage`）→ 自动进入 缓冲（seq/action 合并）→ AgentEnd `flush_buffered_action_events` → `merge_last_assistant_meta("action_events")` 落库（**零持久化改动**） |
| 2 | **前端（1 处）** | `switchSession` 在轮次重建处旁路重放：纯函数 `collectA2UIActionEvents(rustMsgs)`（置于 turnModel，附单测）→ 按消息序逐条 `handleA2UIEvent(surfaceId, message)` 重建 `a2uiSurfaces`；天然幂等（createSurface 覆盖 / updateComponents 合并 / deleteSurface 删除） |
| 3 | 注释同步 | turnModel `ActionKind.a2ui` 注记「暂不可回源」→「可回源（meta.action_events 重放）」；后端 `action_event_payload` doc 六类 → 七类（附"a2ui 是否建段见 D1"） |

## 三、决策点

| # | 决策 | 选项 | 状态 |
|---|---|---|---|
| D1 | a2ui 是否进过程层（turn 行） | (a) **不进（最小）**——画布本身即可见产物，action_event 流消息无行（default → []），零 UI 变化；(b) 进——过程层显示"界面：xxx"行（实时+回源一致，需在 `actionEventToTurnEvents` 加 case） | ✅ **已裁定 (a) 不进过程层**（2026-09-17 用户拍板） |

## 四、已知边界（登记不处理）

1. **体积**：a2ui 消息（实体列表类画布可达数 KB～十余 KB）会增大 `meta.action_events`；暂不设上限，观察后再定（项目暂无在用用户，数据量可控）。
2. **中断**：缓冲在 AgentEnd 收口——轮次中途崩溃丢当轮 a2ui 记录（与 R6 其余动作段同语义，不单独加固）。
3. **回源范围**：画布按会话隔离，仅 `switchSession` 重建；新建会话/草稿态路径本就无历史（已清空，不重建）。
4. **多轮累积**：`merge_last_assistant_meta` 为**追加**语义——同一 assistant 消息跨多轮追加，回源按消息序重放取最终态。

## 五、验收

- **契约测试**：Rust 侧新增 a2ui 臂映射断言（`A2UIEvent → ("a2ui", {surfaceId, message})`）；前端 `collectA2UIActionEvents` 单测（含 `deleteSurface` 序、非 a2ui 动作过滤）。
- **基线**：src-tauri `cargo check` + `cargo test --no-run`（口径升级后）；vue-tsc 0；turnModel 既有用例全绿；commands/kernel 不受影响。
- **真机走查**：① 建实体卡片 → 切会话再切回 → 画布恢复；② 删除实体（关画布）→ 刷新 → 画布**不复活**（deleteSurface 重放正确）；③ LLM `ui_*` 建画布 → 刷新 → 组件与数据恢复。
