## 一、审查结论：半成品——两条整层未接线 + 若干活异常

### A. 整层失效（宣称有、实际从不工作）

1. **策略引擎层恒空**：`registerDefaultStrategies()` **全仓零调用**（`AutoLinkEngine.ts:85` 定义 +
   `core/index.ts:165` / `src/index.ts:68` re-export 为全部命中）；`autoLinkStrategyRegistry` 亦无任何
   register 调用点 ⇒ `getByHint` 恒 `[]`。
   - 引擎 semanticHint 路径（origin / creator / date / material…）永不产出建议；
   - SmartFieldAdder（映射 UI）"语义标签推断"分支半死（`SmartFieldAdder.vue:211` / `:238`）；
   - 实际能产建议的只剩：显式 `autoLink` 字段（仅 characters `race` / `affiliation`）+
     盲匹配（阈值 0.8）+ 用户映射 direct 分支。
2. **设置桥零装配 → 保存时"智能建链"整条链死**：`registerSettingsApi` **全仓零调用**（serviceProvider 桥
   无装配）→ `getSettingsApi()` 恒 noop（`autoCreateEntityEnabled` 恒 false）→ GEV 保存链
   `processAutoLinks`（`GenericEntityView.vue:619-631`）恒 no-op、`useAutoCreateEntity` 永不弹窗。
   - git 史（`git log -S registerSettingsApi`：`2a2ff119` 等）指向旧 web 端退役（Phase G 端分离迁移）时
     接线丢失、未在新端补回；
   - 同根已登记：`useHighlight` 死面（`highlight_dimmingEnabled` 恒 false）。

### B. 活异常（活着但会错）

3. **建议"复活"＋可重复建关系**：确认/忽略仅改内存态；引擎每 pass clear + 重建、**不查既有关系、不记
   dismissed** ⇒ 已忽略的切走再回复活（"全部忽略"仅当次）；已确认过的建议也会再现、再点确认会**新建重复
   关系**（`putRelation` 新 UUID、无去重；`relationDirection` 被忽略 ⇒ 确认为单向，而 smart-link 路径是双向）。
4. **删除实体不清索引**：`potentialLinkIndex.clearBySource` 零调用（删除链未接）；`refreshLinksForTarget`
   零调用（死导出——目标实体改名/变更不会更新他方建议）。
5. **陈旧目标**：`FIELD_KEY_TARGET_MAP` 有 `mount → 'creature'`（仓内无此类型）；`characterConfig.ts` 有
   `race → 'race'`（V2 已统一 `species`，该文件正被 `CharacterList.vue:133` 使用）——目前被"设置桥死"掩盖，
   **补接线后会去创建未注册类型的实体**。

### C. 覆盖面与规划

6. 建议面板仅挂 GEV 详情（16 芽）；映射 UI（SmartFieldAdder）仅 TimelineView「事件自定义字段」入口可达；
   **全家族零测试**（引擎/面板/智能链）。
7. ROADMAP §四 任务 6/8（AutoLink 丰富与字段自更新 / 关系预览窗）本就列"待启动"——现状与其"早期存量"
   定位吻合。
