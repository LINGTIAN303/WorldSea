# 表格式虚拟滚动（§十三 最后一项）

> 立项（2026-10-25）：13-D 走查通过后，§十三 只剩「表格式无虚拟滚动」。
> 用户已拍板**单独立项**（共享 `DataTable`，需单独设计）。本批只做**可选虚拟模式**，默认关闭，既有消费者零影响。

## 一、现状取证

- `DataTable` 消费方仅 3 处：大纲白板表格式（`outline/board/forms/TableForm.vue`）、`XlsxPreview.vue`、`plugin-sdk` 的详情表单。
- 当前 `DataTable` 把 `rows` 全量渲染进 `<tbody>`，无行高约束、无视口高度；行数上千时 DOM 与布局成本线性增长。
- 大纲表格式的行 = 节点的**直接子节点**（不递归），通常几十行；极端结构（如 500 个子节点）才会触发性能问题。

## 二、方案

### 2.1 DataTable 可选虚拟模式（默认关）

新增 props：

| prop | 默认 | 说明 |
| --- | --- | --- |
| `virtual` | `false` | 开启后只渲染视口内行 + overscan |
| `maxHeight` | `360` | 虚拟视口高度（px） |
| `rowHeight` | `30` | 固定行高（px），必须与实际行高一致 |
| `overscan` | `4` | 视口上下额外渲染行数 |

实现：

- 新增纯函数 `computeVirtualWindow(total, scrollTop, viewportHeight, rowHeight, overscan)`：
  返回 `{ start, end }`，负责边界钳制与 overscan；可单测。
- `<tbody>` 渲染：顶部 spacer 行（`start × rowHeight`）+ 可见行 + 底部 spacer 行；
  可见行保留**原始行号**，`resolveCell` / `edit` / `row-click` 的 `rowIndex` 语义不变。
- 虚拟模式样式：滚动容器 `overflow: auto` + `max-height`；表头 `position: sticky`；
  `table-layout: fixed` + 可选 `colgroup` 列宽，避免滚动时列宽跳动；单元格单行省略。
- 非虚拟模式：模板与行为完全不变（`v-if` 分支 + 默认 CSS）。

### 2.2 大纲表格式启用

- 行数 > **80** 时启用虚拟模式（阈值内保持现有全量渲染，避免小表引入滚动容器）。
- 视口高度 = 表单 `maxHeight` 预留「管理行」按钮高度（约 26px）。
- 行高按密度：compact 28px / standard 32px。
- 列宽按列 key 固定（标题自适应、序号/状态/字数/类型定宽、线索百分比），
  仅在虚拟模式生效；非虚拟模式仍走原自动列宽。

### 2.3 不做

- 不改造 `XlsxPreview` / `plugin-sdk` 表单为虚拟模式（可选能力，后续按需开启）。
- 不支持动态行高（表格单元格是单行文本/输入框，固定行高成立）。
- 不重写为 div-grid（保留 `<table>` 语义与现有样式）。

## 四、真机走查

1. 建一个含 200+ 直接子节点的节点，打开表格式 → 只渲染视口附近的行（可用开发者工具确认 `<tbody>` 行数远小于总行数）。
2. 上下滚动 → 行连续、无白屏、无列宽跳动；表头保持可见。
3. 滚到中部点行 → 打开对应节点详情（行号映射正确，不偏行）。
4. 列配置切换（标题/序号/状态/字数/节点类型/线索）→ 虚拟模式下列宽稳定、内容不溢出。
5. 行数 < 80 的普通表 → 与改动前完全一致（无内部滚动条）。
6. `XlsxPreview` / `plugin-sdk` 表单 → 未开启虚拟，行为不变。
