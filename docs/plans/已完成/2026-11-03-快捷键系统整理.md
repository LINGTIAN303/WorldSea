- 监听审计：30 处 document/window keydown，29 处合规（Tab 陷阱 / 浮层 Esc / 持续态键 / 系统固定键 / capture 录制 / 注册表本体），1 处违规。
- data-ws-tip-keys：11 文件覆盖，五处抽查全过；导图重建版零注册键位（仅搜索框元素级局部键，合规），旧 tip 随退役消失属合理。

- editor 作用域空置 / sequence 无消费方 / 动态条目目录豁免——§6 三项均仍成立。

## 二、整理项

### 1. MatrixToolbar `/` 键收编（唯一违规）
field-matrix 工具条 `/` 聚焦搜索（命令型 view 快捷键，有 title 提示）常驻 document 直听 →
收编注册表 `fm.focus-search`（view scope，preventDefault）+ SHORTCUT_CATALOG 补条目（守卫 spec 自动验证）；
Esc-on-focus（聚焦态清空筛选）属元素聚焦态行为，保留组件内。收益：可改键、进帮助弹窗与设置目录、参与冲突检测。

### 2. RegionMap Alt 双路径归一（边缘）
`region.borderline` 注册表登记（keys:['alt']）与本地 keydown/keyup 持续态监听并存，改键对本地路径无效。
处置：本地持续态监听改读**注册表当前键值**（normalizeKeys 匹配 getRegisteredKeys），改键后按住键跟随；
注册表 handler 保留（单发置位，幂等）。§3 持续态键条目补该口径说明。

### 3. 三处浮层 Esc 监听随 open 挂/卸（风格修正）
ToolbarOverflow / QuickAccess / DomainPopover 的 Esc 监听从 onMounted 常驻改为 watch(open) 挂/卸
（对齐 TuiSelect 守卫式/EventMenu 随挂载式两种既有范式）。行为零变化，消除空转监听。

### 4. 文档 §4 键位总表对齐（A 类 18 条）
- 实体视图行补 4 键：Ctrl+←/→ 翻页、Alt+←/→ 切页签（2026-10-08 Tab 优化批带入）；
- 时间轴行补 12 键：Esc 关闭 / Ctrl+←→ 翻页 / Alt+←→ 切页签 / ←→↑↓ 焦点 / + - 缩放 / Home 适配；
- 大纲白板行补 2 键：Ctrl+= / Ctrl+- 缩放。

### 5. 文档笔误修正（C 类 4 条）
- `characters.undo` → `character.undo`（id 笔误）；
- 画板重做为 **Ctrl+Shift+Z**（原文误写并入 Ctrl+Y 行）；
- 实体视图 Esc 语义补「退出批量选择」；
- 大纲白板 Delete 语义改「删除选中节点（含容器与关系）」。
