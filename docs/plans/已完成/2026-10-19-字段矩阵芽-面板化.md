# 字段矩阵芽 · 面板化（2026-10-19）

## 目标

把字段矩阵从「一整份长文档 + 滚动」改为「单面板 + 右栏切换」，同时消除右栏收起/展开时整份长文档逐帧重排造成的卡顿。

**Why**：浏览器预览实测动画期间 50–200ms/帧、每帧布局 27–69ms；LoAF 51–105ms 且 style/layout 占满、脚本 0。单面板预览最大单帧布局 58.2→13.4ms。用户 2026-10-19 拍板采用面板化，并要求借设置页「单激活面板」结构、不照搬 3D 翻牌。

## 关键裁定（用户 2026-10-19 确认）

- 只渲染当前面板；右栏点击切换；滚动不换面板；面板内超高时内部滚动。
- 搜索/筛选：过滤右栏 + 自动选中首个匹配；无匹配时面板与目录都显示空态。
- 面板使用 App 壳原生面板；**视图内容本身即面板框**（不嵌套卡中卡），只保留一层 18/20 内容内边距；面板框固定、内容在框内滚动。
- 切换动效：**重叠交叉淡入 + 6px 上浮**（150ms），移除 `out-in`；舞台底色锁视图表面色，避免切面板白闪；不做 3D 翻牌。
- 移除工具条「展开/收起」；保留「目录」收起/展开与「清空」。
- 切换面板回顶（不记忆各面板滚动位置）。

## 实现

- `FieldMatrixView.vue`：`activePanelId` 单面板渲染；`navGroups` 同时驱动目录、快速跳转与可用面板；可用面板变化时自动选中首个匹配；`selectPanel` 切换；面板内滚动与切换回顶；移除 scrollSpy / 滚动侦听 / 展开收起。
- 切换过渡：`.fm-panel-stage` 同网格重叠新旧面板，交叉淡入 + 6px 上浮；舞台底色 = `--region-bg`；保留 `prefers-reduced-motion`。
- `MatrixSidebar.vue`：`fixed` 分组语义（总览固定、其余独立滚动 + 组标题吸顶）；过滤后空固定块/空分组隐藏；目录空态「没有匹配的条目」。
- `MatrixToolbar.vue`：动作区保留统计 / 清空 / 目录；快速跳转在窄窗兜底。
- `model/nav.ts`：`MatrixNavGroup.fixed`。
- 删除 `model/scrollSpy.ts` 与其测试（面板模式不再需要滚动高亮）。
