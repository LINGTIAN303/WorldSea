# 字段矩阵芽（Field Matrix Bud）设计

> 设计确认：2026-10-18｜施工状态：已完成（2026-10-18 真机走查通过）｜用途：把现有 [芽字段矩阵 HTML](../../details/架构/芽字段矩阵.html) 落成世界树内的一个芽，并扩展为消费其他芽运行时数据的观测面。
> 本文是设计与验收口径；施工批计划见 [2026-10-18-字段矩阵芽-批计划.md](./2026-10-18-字段矩阵芽-批计划.md)。

## 0. 一句话定位

新增视图型芽 **`official.field-matrix`（字段矩阵）**：以当前 HTML 为视觉基线，**完整页面 1:1** 呈现在芽视图内；数据从运行时注册表读取，扩展关系类型、视图声明与 AutoLink 运转观测。

## 1. 目标与边界

**首版做**

- 完整页面 1:1：保留 HTML 自带的顶栏 + 内部侧栏，放进芽视图内容区。
- 运行时字段面：全部实体 Schema、Trait、Facet、字段覆盖、项目级 schema 覆盖、用户自定义字段。
- 运行时关系面：关系类型全表（source/target、逆关系、对称性、domain、属性）。
- 运行时视图面：全部已注册视图（id、中文名、所属芽、关联实体类型、toolbar 形态）。
- AutoLink 运转观测：**事件流 + 当前态**（策略、语义标签、潜在链接、决策、阶段开关）。
- 现有复制字段键/整表保留；不新增导出与 Agent 接口。

**不在首版**

- 导出 Markdown/JSON、Agent 查询接口、AutoLink 完整轨迹（耗时/错误/阶段详情）。
- 隐藏 App 全局侧栏的沉浸式融合；首版接受临时重复导航。
- AutoLink 作用于字段矩阵本身（矩阵只是观测者）。

**1:1 契约**

- 契约对象 = **芽视图内部页面**（含其内部顶栏与侧栏），不含 App 窗口栏与全局侧栏。
- 视觉基线 = 当前 `docs/details/架构/芽字段矩阵.html`（2026-10-18 快照）；先冻结基线截图，再抽共享 CSS；抽完先复测静态 HTML 仍 1:1，再对照芽视图。
- 新分区（关系/视图/AutoLink）只做**增量**：默认打开「总览」，原有总览、Trait 矩阵、实体字段表、Facet、系统字段、无实体芽、口径区不改变布局与交互。

## 2. 视觉与共享 CSS

- 把当前模板内联 CSS 抽为共享视觉源 `apps/tauri/src/world/plugins/field-matrix/styles/matrix.css`（页面级样式另放 `styles/standalone.css`）：
  - 静态 HTML 生成器读取该文件并内联；Vue 芽直接 import；单一视觉源，避免两套样式漂移。
  - 所有选择器收敛到 `.fm-root` 下，保留现有类名（如 `.topbar` / `.sidebar` / `.table-wrap`）；如与 App 全局类名冲突，再统一加 `fm-` 前缀。App 全局样式不得泄漏进矩阵，矩阵样式也不得泄漏出去。
  - 响应式从视口媒体查询改为**容器查询**（`.fm-root { container-type: inline-size; container-name: fm }`），使静态页面与芽内容区都按自身宽度响应；芽声明 `toolbar: 'none'`，并由 `ViewContainer` 对 `field-matrix` 加临时全幅特例（去 padding/border/圆角），让内部完整页面铺满视图区、自己管理滚动。
- 明暗：静态 HTML 保留 `prefers-color-scheme`；芽内由 App 主题映射为 `data-theme="light|dark"`，颜色变量与静态基线相同。
- 类名、DOM 层级、间距、字号、badge、source pill、空态、粘性表头、复制按钮、搜索/筛选/折叠行为全部沿用；交互用 Vue 重写，视觉不重设计。

## 3. 芽形态与外壳

- 插件：`apps/tauri/src/world/plugins/field-matrix/index.ts`
  - `manifest.id = 'official.field-matrix'`，`name = '字段矩阵'`，`version = '1.0.0'`。
  - `api.registerView({ id: 'field-matrix', label: '字段矩阵', icon: 'grid', component, toolbar: 'none' })`。
  - 视图型芽，不注册实体类型；进入芽清单启停，侧栏新入口由现有 view 注册链自动出现。
- 首版外壳：App 全局侧栏/窗口栏仍在；芽内部完整页面自带顶栏+侧栏，形成临时“页面套页面”。后续锚点再做沉浸式融合（隐藏全局侧栏或合并导航）。
- 内部侧栏新增一组「运行时」：**关系类型 / 视图 / AutoLink 运转**；原有分组、默认选中「总览」不动。

## 4. 运行时数据面

### 4.1 字段 / Trait / Facet

- 数据源：
  - `entitySchemaRegistryV2.getAll()`：实体类型、Trait 引用、ownFields、编译字段。
  - `traitRegistry.getAll()`：Trait 定义与字段。
  - `facetRegistry.getAll()`：Facet 定义与宿主。
  - `fieldRegistry.getFields(type)`：builtin + user（`source === 'user'`）字段，补齐自定义字段。
- 复算规则与 `compileEntitySchema` 一致：Trait 顺序展开 → `fieldOverrides` → ownFields 同 key 覆盖 → 追加 user 字段。
- 刷新触发：`watch(fieldRegistry.version)`；schema 覆盖热重填、插件启停、自定义字段增删都会 bump 版本。
- 运行时差异：项目级覆盖、用户自定义字段、外部插件 Schema 会出现在矩阵中，并标注来源；这是与静态文档快照的预期差异，不做回退。

### 4.2 关系类型

- `relationshipRegistry.getAll()`；按 `domain` 分组展示：type / label / sourceTypes / targetTypes / inverseType / symmetric / properties。
- source/target 实体类型链接到对应字段区；无对应实体类型时显示代码原文。
- 关系类型当前在装配期注册；首版在进入视图时读取，并在视图重组/刷新时重读。若后续需要运行时自定义关系的实时刷新，再给 registry 加版本。

### 4.3 视图

- `pluginAPI.getViews()`；订阅 `pluginAPI.onViewChange` 增删重算。
- 展示 view id / label / icon / pluginId / toolbar；按 `schema.pluginId === view.pluginId` 关联该芽注册的实体类型。
- views 变更（插件启停、树重装）即时反映。

## 5. AutoLink 运转观测

### 5.1 首版（事件流 + 当前态）

新增轻量观测件 `packages/entity-core/src/core/AutoLinkRuntime.ts`：

- `AutoLinkRuntimeEvent = { id, kind, at, summary, payload }`，环形缓冲默认 200 条；`version` 为 Vue ref，供视图 watch。
- 首版事件：`index:start`、`index:end`、`link:add`、`link:resolve`、`decision:record`、`refresh:target`。
- 埋点位置：
  - `AutoLinkEngine.indexPotentialLinks`：开始/结束各一条（不记录耗时）。
  - `PotentialLinkIndex.add / resolve`：链接新增/处理事件。
  - `AutoLinkDecisions.record`：决策写入事件。
  - `refreshLinksForTarget`：目标刷新事件。
- 事件结构预留 `phase? / durationMs? / error?`，首版不填；后续升级为完整轨迹时只扩展字段，不改事件主键。
- `AutoLinkDecisionStore` 增加 `getAll()` 只读方法，供当前态表读取。

面板三块：

1. **当前态**：策略注册表、语义标签、潜在链接（未处理/已处理计数 + 明细）、决策记录、阶段开关（读取 settings store 的 `autoCreateEntityEnabled` / `autoCreateEntityRefEnabled` / `autoCreateSelectorEnabled`）。
2. **事件流**：时间、类型 badge、摘要；支持暂停/继续与清空（只清视图缓冲，不清数据）。
3. **索引/决策表**：按 source/target/hint/relation/status 筛选；不写回、不触发确认。

### 5.2 后续完整轨迹锚点

- 记录索引阶段、每次保存触发、自动创建结果、耗时与错误；对应事件增加 `phase/durationMs/error`，面板增加时间线与阶段统计。
- 仍保持只读观测，不改变 AutoLink 行为。

## 7. 刷新、状态与错误

- 进入视图：读全部注册表 → 组装模型 → 渲染。
- 订阅：
  - `fieldRegistry.version`：字段/Trait/Facet/Schema 变更。
  - `pluginAPI.onViewChange`：视图增删。
  - `autoLinkRuntime.version`：事件与当前态重读。
- 退出视图：清订阅、清事件轮询/定时器；不反注册任何全局数据。
- 错误隔离：单个 Schema/关系/视图异常只降级该行或该区，整页不白屏；缺 registry 时显示空态。
- 项目切换/树重装：视图重新挂载或触发版本刷新；不持有跨项目缓存。

## 8. 测试与验收

**单测**

- 数据适配器：Trait + ownFields 覆盖、fieldOverrides、customFields、schema overlay、外部插件来源。
- 关系/视图映射：pluginId → entity types；视图增删；关系分组。
- AutoLink 事件环：环形截断、事件顺序、`getAll()` 决策、暂停/清空只影响视图。
- 过滤/搜索：字段键、中文名、类型、来源、选项；空组隐藏。

**视觉**

- 先冻结当前静态 HTML 在 1600 / 390、light / dark 的基线截图。
- 抽 CSS 后复测静态 HTML 与基线一致；再截芽视图（相同内容宽度）对照。
- 对照点：顶栏高度、侧栏宽度、表格列宽/表头粘性、badge/pill、字体、间距、空态、明暗变量。
- 允许差异：运行时多出的自定义/外部字段行；页面顶部“快照日期/运行时”标识；App 全局侧栏在契约之外。

**集成/门禁**

- 芽出现在侧栏与芽清单，可启停；`toolbar: 'overlay'` 下无双重工具条。
- 项目切换、schema 覆盖热重载、插件启停后数据刷新。
- AutoLink 新增链接/确认/忽略时事件流即时出现。
- `vue-tsc`、全量 vitest、`arch:check`、`check-doc-links`、产物构建。
- 用户真机走查：1:1 四组截图 + 搜索/筛选/折叠/复制 + AutoLink 事件。

## 9. 风险与待决

| 风险 | 处置 |
|---|---|
| 抽共享 CSS 导致静态 HTML 视觉漂移 | 先冻结截图基线；抽完先复测静态 HTML，再对照芽视图 |
| 芽内完整页面与 App 全局侧栏重复 | 首版接受；沉浸式融合挂后续锚点 |
| AutoLink 埋点触碰核心 | 观测件独立小文件；引擎只加首尾两条；单测覆盖 |
| 运行时数据比静态快照多（覆盖/自定义/外部插件） | 明确标注运行时来源；视觉对照用无额外数据的项目 |
| 关系类型/自定义关系刷新不完整 | 首版进入时读取 + 视图变更重读；需要实时再给 registry 加版本 |
| 全页滚动/粘性表头在 App 内容区内失效 | 根节点自管滚动；容器查询；真机走查四组 |
| 新芽自身没有实体字段 | 补进静态文档的「无实体字段芽」清单并重跑生成器 |
