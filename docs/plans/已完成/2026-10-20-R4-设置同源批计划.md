# R4 · 设置同源

> 定位：把芽管理从旧 6 类 `category` 迁到 8 语义域，与侧栏共享同一份域定义；拆出激活分组；统一状态词；补一个从侧栏快捷区进入芽管理的入口。
> 依据：研究 05 §5.2–5.5；R2 已把 `SPROUT_DOMAINS` 定为域层单一真源，旧 `category` 标记待退役。

## 一、范围

### A. 芽管理按域分组

- 用 `SPROUT_DOMAINS` + `未分类` 分组展示 27 芽；组头显示图标、域名、已启用/总数。
- 旧 6 类筛选条退役，改为 8 域筛选（「全部」+ 域）；搜索保留。
- **工具域默认折叠**；折叠状态持久化（`worldsea_sprout_domain_collapsed`）。
- 域内拖拽排序保留：每组独立拖拽，写回全局 `uiStore.sidebarOrder` 时只替换该域芽的相对位置，不改变其它域芽的位置。
- 搜索或域筛选激活时禁用拖拽（避免子集排序歧义），并自动展开匹配组。
- 外部缺域芽归「未分类」组。

### B. 激活分组独立小节

- 从芽管理标题旁的下拉拆出独立卡片「激活分组」：命名输入 + 保存、已存分组应用/删除、当前激活集高亮。
- `PluginsPanel` 由 3 卡变 4 卡：外部插件 / 内置插件 / 芽管理 / 激活分组。
- 语义保持：保存的是**当前启用集**快照；应用后只启用组内芽，组外停用；至少保留人物志兜底。

### C. 状态词统一

- 芽：**已启用 / 未启用**；组头计数用「已启用 x / 共 y」。
- 外部插件：`loaded` → **已启用**，`skipped` → **未启用**，`rejected` → **被拒**。
- 内置 utility：**常驻装载**。
- 不再在芽管理出现「激活 / 停用」混用；「激活分组」作为专名保留。

### D. 管理入口

- 快捷区底部由纯提示改为「管理芽」按钮：打开设置 → 插件 → 芽管理卡。
- 通过 `uiStore.settingsTarget = { section: 'plugins', card: 2 }` + `ws-open-settings` 事件；`SettingsDialog` 打开时消费目标并翻到对应卡，然后清空。
- 排序提示保留为「排序：设置 → 芽管理」。

## 二、非目标

- 不改侧栏六形态与轮盘/快捷区行为。
- 不做侧栏内拖拽排序；排序继续只在设置芽管理（域内）。
- 不做 R5 的依赖/装载态详情、R6 数据模型。

## 三、架构

- `SproutsCardContent.vue`：域分组渲染 + 域筛选 + 折叠 + 组内拖拽；样式外置 `sprouts-card.css`，避免 file-size。
- 新增 `sproutDomainGroups.ts`：纯函数 `groupSproutsByDomain` + `mergeDomainOrder`，便于单测。
- 新增 `SproutGroupsCardContent.vue`：激活分组卡内容。
- `PluginsPanel.vue`：4 卡、域映射 `domainOf`、状态词、暴露 `goToCard(2)` 给管理入口。
- `uiStore.settingsTarget` + `SettingsDialog` 目标消费。
- `QuickAccess.vue` 底部管理芽按钮。
- `SproutToggle.category` 仍保留 `@deprecated` 定义，但芽管理不再消费。

## 四、验收

- 芽管理显示 8 域 + 未分类；工具域默认折叠，展开/收起后刷新保留。
- 域筛选与搜索只显示匹配芽；旧 6 类筛选不再出现。
- 组内拖拽后侧栏顺序变化只发生在该域芽之间；刷新保留。
- 激活分组卡可保存/应用/删除；应用后芽启停与组内一致。
- 状态词统一为已启用/未启用/被拒/常驻装载。
- 快捷区「管理芽」打开设置并直接落在芽管理卡。
- 门禁：专项 + 全量 vitest、vue-tsc、arch、workspace 构建、断链全绿。

### 风险

1. 管理入口依赖 `PluginsPanel` 卡顺序 2；后续增删卡需同步 `QuickAccess` 的目标索引。
2. 域内拖拽仅在未搜索/未筛选时可用；筛选态下隐藏拖拽手柄（与旧规则一致）。
3. 域 Tab 在 604px 卡宽下需横向滚动；左右箭头随滚动位置出现，滚轮可横向滚动。窄窗仍可用，但部分域需滚动才可见。
4. 折叠状态是全局 localStorage；新域默认展开，工具域仅在无记录时默认折叠。
5. 未分类组包含外部插件自造域；域筛选「未分类」与组归属已统一口径。
6. `SproutToggle.category` 定义仍保留但 UI 不再消费；R4 未删 store 字段，避免影响兼容层。
