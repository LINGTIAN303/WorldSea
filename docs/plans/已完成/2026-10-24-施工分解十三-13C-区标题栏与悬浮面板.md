# 施工分解 §十三 · 13-C：区标题栏避让与悬浮面板钳位

> 立项（2026-10-24）：13-B 走查通过后继续 §十三 剩余 B 类。
> 本批只做两项边界修复：区标题栏被容器遮挡、悬浮面板在窄窗溢出。
> 纵向区实时重排（需先定义交互）与表格式虚拟滚动（共享 DataTable，影响面大）留 13-D。

## 一、范围

| 项 | 现状 | 目标 |
| --- | --- | --- |
| 区标题栏被容器遮挡 | 容器可落在区标题栏上方，遮住改名/拖动热区 | 归属区的容器在**拖动结束**时，顶部不得高于「区顶 + 26px 标题栏」 |
| 悬浮面板窄窗溢出 | `useFloatingPanel` 已钳制 left/top，但面板宽/高可能大于视口 | 面板最大宽/高不超过视口（CSS 边界 + 内部滚动） |

## 二、技术方案

### 2.1 区标题栏避让

- `sectionArrange.ts` 新增纯函数 `clampContainerTop(rect, sectionRect, header?)`：
  - 无归属区 → 原样返回；
  - 有归属区 → `max(rect.y, sectionRect.y + SECTION_HEADER)`。
- `useBoardLayout.settleContainerSection`（拖动结束重算归属）改为**一次 mutate 同时写** `sectionId` 与 `pos.y`：
  - 先按中心点解析归属区；
  - 归属区存在时用 `clampContainerTop` 校正顶部；
  - 不改变 `x`，不改变容器尺寸。
- 只在**拖动结束**钳制，不在拖动过程中强行吸顶——避免与自由拖动/脱离区的手感冲突；拖出区（中心点不在任何区）仍可脱离。

### 2.2 悬浮面板视口钳位

- `FloatingPanel.vue` 的 `.fp-panel` 增加：
  - `max-width: calc(100vw - 16px)`；
  - `max-height: calc(100vh - 16px)`。
- `.fp-body` 已有 `overflow-y: auto` + `flex: 1`，加上 `max-height` 后内容在面板内部滚动，不再溢出视口。
- **边界说明**：本项解决「面板大于视口」的溢出；**不解决**多个浮层同时打开时的相互重叠（需要全局浮层管理器，单独立项）。

1. 把容器拖到区标题栏上方松手 → 容器顶部吸附到标题栏下沿，标题栏可见可点。
2. 把容器从区里向左右/下方拖出 → 仍能正常脱离区，不被钳制卡住。
3. 缩小窗口到较窄尺寸 → 打开表格式「管理行」或进度式钻取浮层 → 面板完整落在视口内，内容内部滚动。
4. 现有浮层（容器编辑面板、导出弹层等）在正常窗口尺寸下位置与尺寸不变。

## 五、本批不做（13-D）
