# 图标库二期 · 语义域 / 详情页 / 区域类型槽位

> 在一期「芽 + 实体类型」覆盖层上扩展三类语义槽位，存储与优先级模型不变。
> 一期依据：[2026-10-27-图标库与图标槽位-批计划](2026-10-27-图标库与图标槽位-批计划.md)。

## 一、已拍板

| 决策 | 结论 |
|---|---|
| 详情页范围 | 通用 4 页共享（信息 / 形象 / 视频 / 关联）+ 芽自定义页（character 6 / organization 4 / region 4 / event 1） |
| 语义域范围 | 只 8 个语义域；「全部」是筛选聚合、「未分类」是外部插件兜底，不可改 |
| 区域类型范围 | `typeIconMap` 已知类型全集 18 个 |
| 持久化 | 沿用一期：项目覆盖 > 全局覆盖（跟随开启）> 默认 |
| 入口 | 设置「图标」中心新增三张卡；不改其它操作路径 |

## 二、槽位模型

| kind | key | 数量 | 默认来源 |
|---|---|---|---|
| `domain` | `domain:<id>` | 8 | `SPROUT_DOMAINS[].icon` |
| `detailTab`（通用） | `detailTab:*:<tabId>` | 4 | `SHARED_DETAIL_TABS` |
| `detailTab`（芽自定义） | `detailTab:<entityType>:<tabId>` | 15 | `DETAIL_TAB_DECLARATIONS` |
| `regionType` | `regionType:<value>` | 18 | `regionConfig.typeIconMap`，缺省 `region` |

详情页解析优先级：`detailTab:<type>:<tabId>` → `detailTab:*:<tabId>` → 声明图标。自定义页只认精确键，不继承通配键。

## 三、解析收口

| 收口点 | 影响面 |
|---|---|
| `buildSproutNavigation` | 侧栏轮盘 / 列表 / 双栏 / 页签形态的域图标 |
| `groupSproutsByDomain` | 设置芽管理按域分组头图标 |
| `groupSproutSlots` | 图标中心芽图标的域分组头图标 |
| `buildHomeData` | 首页资产地图 8 域图标 |
| `resolveDetailTabs` | 抽屉 / 栏式 / 浮层 / 沉浸 / 弹窗五种载体的页签图标；设置 Tab 管理行图标 |
| `regionConfig.regionTypeIcon` | 区域树、卡片、子区域、飞地 |

## 四、UI

设置「图标」扩为 6 卡：

0. 芽图标
1. 实体类型图标
2. 语义域图标（8 行，单组）
3. 详情页签图标（通用页签一组 + 按实体类型分组）
4. 区域类型图标（18 行，单组）
5. 作用范围

`IconPicker` 标题按 kind 显示「芽 / 实体类型 / 语义域 / 详情页签 / 区域类型」；同步实体类型控件仅芽槽位出现。
