# 字段矩阵芽 · 表宽稳定（2026-10-20 · 四刀）

## 现象与根因（实测）

- **表宽不统一**：纵向滚动条出现/消失使 `.fm-scroll` 内容宽度在 **1189 / 1180** 间切换，表宽随之差 **9px**（概念 1148、角色 1140）。
- **选项展开后重排**：字段表 `table-layout: auto`，`<details>` 展开后说明列内容变宽，自动列宽重新分配——首列 **245→155**、中文列 **173→109**、说明列 **415→570**；展开瞬间表格列边界整体跳动。

## 实现

- `.fm-scroll` 加 `scrollbar-gutter: stable`：无论是否出现纵向滚动条，内容宽度固定。
- 字段表 `table-layout: fixed; min-width: 800px` + 固定列宽：字段 160px / 中文 112px / 类型 142px / 必填 54px / 来源 148px / 说明吃余量。展开选项只在说明列内换行，不再重排全表。
- `.fm-panel-inner` 右内边距 20→11px，与 9px 稳定滚动条槽位相加后左右留白一致。
- 类型 / 必填 / 来源仍 nowrap；静态 HTML 不受影响。

## 门禁

- 预览：概念（无纵向溢出）与角色（有纵向溢出）表宽均为 **1147**；展开 11 个选项前后列宽均为 **160/112/142/54/148/531**，不再重排。
- 右侧留白平衡：`scrollbar-gutter: stable` 槽位 9px + 右内边距 11px = 左内边距 20px + 边框 1px。
- 专项：10 文件 / 25 测试通过；全量：167 文件 / 1386 通过 / 1 跳过；`vue-tsc` 0；架构检查 0；`workspace-dist` 构建成功；文档链接 0（327 文件）。
