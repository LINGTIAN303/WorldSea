# 施工分解 §十三 · 13-D：纵向/非 free 区松手后重排

> 立项（2026-10-25）：13-C 走查通过后继续 §十三 最后一项可施工的 B 类欠账。
> 用户拍板：纵向区采用**松手后重排**（不做拖动中实时抖动）；表格式虚拟滚动**单独立项**（共享 `DataTable`，需单独设计）。

## 一、范围

| 项 | 行为 |
| --- | --- |
| 纵向区拖动 | 拖动时容器自由移动；**松手后**按落点 y 重排整列（内容原点 + gap） |
| 其它非 free 区 | `horizontal` / `grid` 同口径：松手后按当前落点重排 |
| free 区 | 保持自由摆放，不重排 |
| 跨区拖动 | 旧区与新区各重排一次（同一次变更） |

**不做**：拖动过程中其他容器实时让位（会与自由拖动抢手感）；表格式虚拟滚动（另立项）；A5 快捷键多实例（当前 `ViewContainer` 单实例，无触发路径）。

## 二、技术方案

- 把 `useBoardLayout.applyArrange` 的纯计算抽到 `board/sectionLayout.ts` 的 `arrangeSectionInLayout`：
  - 只重算指定区内容器坐标，不改区/容器其它字段；
  - 可单测，且让 `useBoardLayout` 不因新逻辑增长（冻结 444 行）。
- `useBoardLayout.settleContainerSection` 在原有「归属区 + 标题栏钳顶」之后：
  - 收集旧区 id 与新区 id（`Set` 去重）；
  - 对其中 `arrange !== 'free'` 的区依次 `applyArrange`；
  - 全部合入**一次 `mutate`**，避免「已归属但未排」的中间态入库或产生两条撤销记录。
- 顺序语义：`arrangeSection` 按容器当前 `y` 排序（同日 y 用 x 兜底），因此落点 y 直接决定插入位置。

## 四、真机走查

1. 建一个 `vertical` 区，放 3 个容器；把第 3 个拖到第 1 个上方松手 → 它排到首位，其余顺次下移，间距一致。
2. 把中间容器拖出区 → 松手后区内剩余容器收拢，空出的间距消失。
3. 从一个 `vertical` 区拖到另一个 `vertical` 区 → 两个区都重排，无重叠。
4. `free` 区拖动 → 位置保持落点，不重排。
5. `horizontal` / `grid` 区拖动 → 松手后按各自排布方式重排（同口径）。
6. 拖动过程中不出现其他容器实时跳动；松手后才重排。

## 五、本批不做

- 表格式虚拟滚动：共享 `DataTable`，需设计可编辑行 / 行高 / 选中态，单独立项。
- A5 同视图双实例快捷键：当前无并发实例路径，保持框架注意事项。
- 多浮层相互重叠：需全局浮层管理器，另立项。
