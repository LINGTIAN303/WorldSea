# 启动双窗缺陷修复批计划

> 起因：用户走查发现「启动一个软件 = 两个窗口」（2026-11-03）。
> 性质：**显隐时序缺陷**——配置写了 `visible: false`，但被窗口状态插件的存档恢复覆盖。
> 本批只改可见性裁决与文件拆分，不动切换交互与页面内容。

## 一、根因（每一环都有实证）

**现象**：启动后 dsh 主窗与工作台窗同时出现。

**因果链**：

1. 上次退出时主窗可见 → `tauri-plugin-window-state` 保存存档。**实测存档**（`%APPDATA%/com.worldsea.desktop/.window-state.json`）：
   ```json
   "main":      { "visible": true  }
   "workspace": { "visible": false }
   ```
2. 插件默认 `StateFlags::all()` **包含 `VISIBLE`**（`tauri-plugin-window-state-2.4.1/src/lib.rs:52-56`）。
3. 启动时插件在 `on_window_ready` 回调里执行 `should_show = state.visible`（`lib.rs:227`），主窗存档为 `true` → 调 `self.show()`（`lib.rs:263`）。
4. **这一步覆盖了 `tauri.conf.json` 的 `visible: false`**——插件恢复发生在窗口创建之后，优先级更高。
5. 而 `workspace_window::startup_visibility()` 的注释写着「主窗保持隐藏」，但代码里**从未主动 `hide()` 主窗**——它只是「不调用 show」，假设主窗天然隐藏（错误假设）。
6. 结果：插件把主窗顶出来 + 工作台窗按首绘门正常显示 = **两窗同现**。主窗在后台照常跑 dsh 就绪链并完成导航，所以两窗都有内容。

**为什么此前没暴露**：依赖「上次退出时主窗可见」这一存档状态。若从工作台退出则存档 `main.visible = false`，缺陷不复现。**属存档相关的隐藏缺陷。**

## 二、修复

### 2.1 显式隐藏主窗

`workspace_window.rs` 的 `startup_visibility()` 开头：

```rust
if let Some(main) = app.get_webview_window("main") {
    let _ = main.hide();
}
```

**时序安全性**：插件在 `on_window_ready`（窗口就绪事件）里恢复，早于 `setup` 里的本函数，故此处 `hide` 生效。

### 2.2 工作台窗建窗后补 hide

`create()` 里的 `.visible(false)` 只是**建窗初值**，插件同样会按存档再恢复一次。故 `build()` 之后补：

```rust
let _ = workspace.hide();
```

当前存档 `workspace.visible = false` 所以未暴露，但存档一旦为 `true` 就会以同样方式触发——一并兜住。

> **未采纳**的备选：给插件配 `with_state_flags(all() & !VISIBLE)` 从根上不存/不恢复可见性。它更彻底，但会改变现有存档语义（用户已保存的几何/最大化恢复策略），且本次已有显式 hide 足够。留作将来若再现同类问题的升级选项。

## 五、待真机确认

**关键：需先制造复现条件**——上次退出时主窗必须是可见的（当前存档 `main.visible = true`，可直接测）。

1. 正常启动 → **只出现一个窗口**（工作台/启动页），不应再有第二个窗；
2. 界面标题/内容正常（主窗后台仍在跑 dsh 就绪链，切换过去应已是完整界面）；
3. 切换「Agent 空间 ⇄ 工作台」正常（两窗互斥、几何对齐、遮罩连续）；
4. 关闭再启动一次 → 仍单窗（验证存档被正确覆盖）。

> 若仍双窗：说明 `hide()` 被插件恢复覆盖（时序假设不成立），此时应改用 §2.2 末的备选方案（关 `VISIBLE` 标志）。

## 六、风险与边界

| # | 项 | 说明 |
|---|---|---|
| R1 | 显式 hide 是否影响「上次停在工作台」的用户 | 不影响：两形态都是工作台为默认落地，主窗本就该隐藏 |
| R2 | 插件存档语义 | 本批**不改**存档策略，仍保留几何/最大化恢复能力 |
| R3 | 开机自启（`--autostart`） | 该分支本就不显示任何窗，`hide` 只是幂等兜底 |
| R4 | 拆分后测试搬迁 | 5 例几何用例随源码迁入新文件，断言内容未放宽（源码路径改指 `workspace_geometry.rs`） |
