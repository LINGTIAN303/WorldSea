# UI 组件风格 · 质感打磨轮（P1）

> 在已归档的三批 + 优化轮之上，专门打磨「液态玻璃」与「新拟态」的材质质感。
> 已定：玻璃标准强度（30px 模糊 + saturate 1.8 + 噪点 + 镜面高光）；新拟态用强调色环境光晕；仅图片灯箱做 clear 变体；交互高光只做静态 + hover。

## 一、目标

- **液态玻璃**：接近 iOS 26 regular 变体——模糊、亮度调整、镜面高光、细微颗粒、染色渐变；功能层使用，内容层保持伪玻璃。
- **新拟态**：表面微渐变 + 四层阴影 + 强调色发散光晕；亮暗各一套光照方向与阴影强度。
- **约束**：控件边界对比度仍 ≥3:1；性能模式可关模糊；不新增依赖。

## 二、令牌

- `--sf-noise`：SVG 噪声（12% 透明度，140×140 平铺），仅玻璃与新拟态使用。
- `--sf-ambient`：强调色环境光晕，默认透明，`neu` 下为 `0 0 42px color-mix(accent 12%)`。
- 玻璃 `--sf-overlay-filter / nav / chrome` 升级为 `blur(30/26/24px) saturate(1.8) brightness(1.04) contrast(1.02)`。
- 背景令牌改为「噪声 + 渐变」多层值（`background` 简写消费，组件无需改）。

## 三、任务

### P1-1 基础令牌与玻璃配方

**Files:** `packages/style-kit/src/presets/base.css`、`soft-glass.css`

- base 增加 `--sf-noise`、`--sf-ambient` 默认值。
- soft-glass 重写背景、边缘、阴影、高光与过滤器；亮暗各一套。
- 玻璃内容层（卡片）保留 0.6 左右染色，不叠 blur。

**验收**：`presets.spec.ts`、`contrast.spec.ts` 通过；浏览器探针确认 `backdrop-filter` 计算值含 saturate。

### P1-2 玻璃应用与交互高光

**Files:** `EntityCard.vue`、`home.css`、`AppearancePanel.vue`、`TuiButton.vue`

- 悬停/聚焦时在阴影末尾追加 `var(--sf-ambient)`。
- 保持 150–180ms 阴影过渡。

### P1-3 新拟态配方

**Files:** `packages/style-kit/src/presets/neu.css`

- 表面改为 145° 微渐变（亮暗各一套）。
- 阴影升级为近/远 × 亮/暗四层，长度乘 `--sf-depth-scale`。
- 增加 `--sf-ambient`，强调色 12%（深色 14%）。
- 控件底色/边界保持对比度达标值。

### P1-4 clear 灯箱

**Files:** `packages/plugin-sdk/src/components/ImageLightbox.vue`

- 背景改为 `color-mix(#000 35%, transparent)` + `blur(30px) saturate(1.2)`（Apple clear 变体：亮背景加 35% 暗化层）。
- 控制按钮保持原有白色可读样式。

### P1-5 测试与验收

**Files:** `packages/style-kit/src/__tests__/material.spec.ts`

- 断言玻璃含噪声、saturate 1.8；新拟态含 145° 渐变与 ambient；灯箱含 clear 配方。
- 全量测试、门禁、构建、真机走查。

## 四、风险
