- Cargo.toml crate 名与 path 引用(`worldsmith-tauri-app`、`worldsmith_tauri_lib`、`worldsmith-core`、`worldsmith-skills-store`)

## 五、风险点与对策

| 风险 | 对策 |
|---|---|
| Rust crate 名变更 → Cargo.lock(8 个已跟踪)刷新 | cargo check 全量验证,依赖树错误在此暴露 |
| `link:` 依赖路径随目录改名,pnpm install 失败 | 走 npm fallback(.npmrc 已配 hoisted) |
| TS 文件名改名后 import 路径断 | 阶段 2 替换覆盖 import 字符串;typecheck 兜底 |
| identifier 变更 → 旧 API Key 不可见 | 用户已决策:不迁移,重配 |
| wasm pkg 内嵌包名与 `--scope` 不一致 | 阶段 4 重新 build:wasm-all 产物对齐 |
| docs 变更未同步索引 | 收口阶段统一同步 docs/index/README.md |
