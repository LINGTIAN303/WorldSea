## 二、三芽形态

### 1. 生物图鉴（`official.creatures`，life 域）

- 新实体类型 `creature`（label 生物，icon `paw`），traits：identifiable / taggable / visual / rateable / physical（字段标签覆写：外观/平均体高/平均体重）。
- ownFields：类别（走兽/飞禽/水族/虫豸/魔兽/异种/元素生物/不死生物/机械造物/其他）、危险度（无害→灾厄）、食性、体型、性情、栖息环境、能力、弱点、产出物。
- 视图 = SchemaRenderer 标准模式（plants 同款），详情关系 Tab：栖息区域 / 产出物品 / 猎人（逆向）/ 契约者（逆向）。
- 关系注册表新增（`packages/entity-core/src/relations/index.ts` §17）：
  - `inhabits`（栖息于，creature→region）↔ `habitat_of`（栖息地），域 geography
  - `drops`（产出，creature→item）↔ `dropped_by`（产出来源），域 item
  - `hunts`（猎杀，character→creature）↔ `hunted_by`（被猎杀），域 combat
  - `tames`（驯服/契约，character→creature）↔ `tamed_by`（被驯服），域 person
  - `belongs_to`（属于）sourceTypes 扩展 `+ creature`（生物→种族/组织）

### 2. 图库（`official.gallery`，tool 域，纯视图）

- 聚合三源：实体封面（coverImage / coverSource 路径）、形象图（entity.portrait，coverSource 已是 portrait 的不重复出卡）、画板作品（`drawing` 实体 `properties.thumbnail`）。
- 卡片复用 `EntityCardCover`（视频/动态形象/静态图三态全兜住），`:deep` 抬高图高；点卡 `ws-navigate { entityType, entityId }` 跳源实体。
- 工具条：来源筛选 + 实体类型筛选 + 名称搜索（R3 Teleport 口径）。

### 3. 设定集（`official.codex`，tool 域，纯视图）

- 按 8 域分章（类型→域映射取各芽 manifest.entityTypes），域内按实体类型分组列条目：缩略图 + 名称 + 描述摘录（stripMarkdownSyntax）+ 标签；点条目 `ws-navigate` 跳详情。
- 全文搜索（名称/描述/标签）；导出 md / HTML（含每条目 ownFields 非空值清单），Blob 下载，纯函数出 `codexExport.ts` 供测试。
