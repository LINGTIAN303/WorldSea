# 图标库 · 多风格内置库与分类

## 一、范围

- 首批 25 个包：Phosphor 6 权重、Streamline Freehand / Plump（Line/Remix/Solid）/ Sharp（Line/Remix/Solid）/ Cyber / Pixel、Game-icons、IconPark Multi-color/TwoTone、Solar 6 风格、Pixelarticons。
- 每包精选 15–25 个语义图标，沿用现有中文名/关键词/语义域；缺项跳过。
- 不引入运行时 Iconify 依赖：精选数据在构建期生成 TS 文件并入库。
- 自定义图标仍独立为「我的图标」。

## 二、命名与数据

- 图标全名：`<packId>:<localName>`，如 `ph:house`、`sl-freehand:home`、`gi:dragon-head`。
- 裸名保持现状（世界精选 / Lucide / Tabler），不迁移存量覆盖值。
- 包元数据：id / label / style / license / source / colorMode。
- 生成器：`node scripts/icon-packs/generate.mjs`；清单 `scripts/icon-packs/manifest.mjs`。
- 生成物：
  - `packages/ui-kit/src/assets/iconPacks/generated/*.ts`
  - 每个包文件 < 400 行（图标一行一条）。
- SVG body 生成时：拒绝 script / foreignObject / 事件属性；ID 加包名前缀，避免同页多个图标 mask 冲突。

## 三、渲染

- `WsIcon` 解析顺序：自定义资产 → 内置包 → Lucide → 自定义路径。
- 单色包统一 `currentColor`；IconPark 彩色包保留原色（`colorMode: 'color'`）。
- `hasIcon` 纳入包解析。

## 四、选择器

- 第一行：图标库/风格（世界精选、各内置包、全部图标、我的图标）。
- 第二行：语义域（全部 + 8 域 + 通用）；「我的图标」不显示域行。
- 切换图标库时域重置为「全部」，避免新库被旧域过滤成空。
- 搜索覆盖中文名 / 英文名 / 关键词 / 包全名。
- 底部「图标来源与许可」打开弹层，列出每个包的许可与来源。
