# 批 1 · 外部插件运行时装载全链路（双 Cordis「一切皆插件」v1）

> **来源**：2026-10-13 用户拍板「一切皆插件」方向（愿景/决策记录见 project_memory「双 Cordis『一切皆插件』方向」节）。
> 本批 = L3 运行时外部插件全链路：**Agent 写插件 → 落盘 → 热装载 → 管理界面可控**。
> 后续批次（L2 存量迁移：files → theme-editor → data → entity-tools → 全局件 → 设置页）不在本批。

## 一、现状与缺口

**已立底座（不重建）**：
- 第二棵树：[tree.ts](../../details/注释/README.md)（`apps/tauri/src/world/tree.ts`）——真启停 `setPluginEnabled` / 卸载 `unloadPlugin` / 失败隔离；清单校验 [manifest.ts](../../../apps/tauri/src/world/manifest.ts)；作用域 API [api.ts](../../../apps/tauri/src/world/api.ts)。
- 装载器 [loader.ts](../../../apps/tauri/src/world/loader.ts)：`import.meta.glob('./plugins/*/index.ts')` **构建期静态**——运行时无外部来源（核心缺口）。
- 壳文件命令现成：`cmd_fs_read / cmd_fs_write / cmd_fs_list / cmd_fs_delete`（[FileStorageBackend.ts](../../../packages/entity-core/src/core/FileStorageBackend.ts#L26-L53) 封装）。
- FsWatcher（[useFsWatcher.ts](../../../packages/entity-core/src/composables/useFsWatcher.ts#L143-L211)）：`fs:change` → 防抖 1s → 按目录分类刷新 store；**`.worldsea/` 只显式跳过 kv_store/files_meta 两个文件**——插件子目录变更天然可达分类层，只需新增分类与分发面。
- 芽启停：`settingsStore.sprouts`（localStorage + 项目 DB 双写，[settingsStore.ts](../../../packages/entity-core/src/stores/settingsStore.ts#L110-L158)）→ `installWorldTree` watch → `setPluginEnabled`（[index.ts](../../../apps/tauri/src/world/index.ts#L43-L49)）——外部插件挂进 sprouts 即自动获得启停语义。
- dsh 工具先例：[dsh-plugin-worldsea/lib/index.js](../../../apps/dsh-plugin-worldsea/lib/index.js)（ToolDefinition 手写 + `worlddataDir` 解析 L106-118 + 原子写先例 mutateRelations）。

**缺口（本批四件）**：① 外部装载器 ② 管理界面 ③ dsh 侧 `world_plugin_*` 工具 ④ 热重载链路。

## 二、口径（施工约定）

| 项 | 定稿 |
|---|---|
| 插件目录 | `<项目根>/worlddata/.worldsea/plugins/`（`fsb.projectDir` 即 worlddata 根；与 schema 快照同域，属「内部目录」语义） |
| 文件形态 | **单文件** `<id>.js`，内容 = 箭头函数表达式 `(require) => ({ manifest, apply })`（对齐 dsh-plugin-worldsea-console 闭包工厂先例，零构建链） |
| 模块种子表 | 产品域自持（对齐 dsh `PLATFORM_MODULES`）：v1 注册 `vue` / `@worldsea/entity-core` / `@worldsea/shared-ui`；可扩展登记面 |
| id 域 | 外部插件强制 `ws.` 前缀（内置 `official.*` 不可冒名；装载器双重校验：前缀 + assemblePlugins 重复拒） |
| 生效通道 | **watcher 热装载**：`.worldsea/plugins/` 变更 → 新分类分发 → `reloadExternalPlugins()`；Agent 写完自动生效（防抖 1s），零新增跨进程通道 |
| 启停真源 | `settingsStore.sprouts`（外部条目 `source: 'external'`，运行时同步进清单；既有 watch 链自动覆盖启停） |
| 求值方式 | `new Function`（主上下文执行，无沙箱——项目暂无外部用户，风险接受并文档注明；**施工第一步先验证 WebView CSP 允许 eval**） |
| 失败隔离 | 单文件语法错误/清单非法/求值异常 → `rejected` 记录（console.warn + 管理界面可见），其余照常 |

## 三、施工面（文件级）

### 3.1 模块种子表 `apps/tauri/src/world/modules.ts`（新增）

- `registerModule(name, exports)` 登记面 + 默认表（vue / entity-core / shared-ui 实例导出）。
- `createRequire()`：返回 `require(name)`，未登记 → 可读错误 `MODULE_UNKNOWN: <name>（可用：…）`。

### 3.2 外部装载器 `apps/tauri/src/world/external.ts`（新增）

- `evaluatePluginFile(code, require)`：`new Function` 求 factory → `factory(require)` → `{manifest, apply}`；纯函数可测（code 注入）。
- `collectExternalPlugins(dir)`：`cmd_fs_list` 列 `*.js` → 逐文件 `cmd_fs_read` → 求值 → 过 `validateManifest` + `ws.` 前缀检查；失败进 rejected（附文件名+原因）。复用 [loader.ts](../../../apps/tauri/src/world/loader.ts) 的 `assemblePlugins` 做合并校验（外部候选与内置候选分批过，或单独过同一纯函数）。
- 内容指纹：`Map<id, code>`，重对账 diff 用（新增装载 / 消失卸载 / 变更重装）。

### 3.3 树接线 `apps/tauri/src/world/tree.ts` + `index.ts`

- `startWorldTree`：起树时 `collectExternalPlugins` 结果并入 `available`（启用者 `loadPlugin`）。
- 新导出 `reloadExternalPlugins(): Promise<ExternalReloadReport>`：diff 对账——新增装载、消失卸载（`unloadPlugin`）、变更重装（卸+装）；报告 `{added, removed, updated, rejected}`。
- [index.ts](../../../apps/tauri/src/world/index.ts)：`installWorldTree` 注册 watcher handler（3.4）→ 防抖后 `reloadExternalPlugins`；外部插件装载成功 → `settingsStore.syncExternalSprouts`（3.5）。

### 3.4 watcher 分类与分发 `packages/entity-core/src/composables/useFsWatcher.ts`

- `processChanges` 新增分类：`normalizedPath.startsWith(`${dir}/.worldsea/plugins/`)` → `pluginsChanged`。
- 新导出 `onPluginDirChange(handler): () => void`（模块级回调注册面，返回退订；多 handler 逐个 try/catch 隔离）——entity-core 不依赖 world 模块，方向反转由 world 侧订阅。
- 注意：`isInSelfWriteWindow` 静默期跳过逻辑保持不变（Agent 写属外部写入，天然触发）。

### 3.5 sprouts 外部条目 `packages/entity-core/src/stores/settingsStore.ts`

- 新导出 `syncExternalSprouts(list: SproutToggle[])`：按 `source === 'external'` 合并进 sprouts state（新增/更新 label、移除已消失的），走既有 `saveSprouts` 持久化；active 首次默认 true、之后尊重用户开关。
- **风险核对**：`sproutPersistence` 归一若以 `KNOWN_SPROUT_IDS`（静态清单）滤条目，需放行 external 来源（施工时核对，必要处改归一口径）。

### 3.6 管理界面 `apps/tauri/src/ui/settings/panels/ExternalPluginsPanel.vue`（新增）+ `SettingsDialog.vue` 接入

- 落点：`plugins` 分区（现名「芽」）内、SproutsPanel 上方；分区 label「芽」→「插件」。
- 外部插件卡片列表：id/名称/版本/状态（已装载·被跳过·被拒·错误）/启停开关（复用 `toggleSprout`）/重载/删除（`cmd_fs_delete` + reload）/查看源码（只读 Modal）。
- 空态引导：展示插件文件路径 + 最小模板（与 3.7 的 template 工具同源文案）。
- 状态数据源：世界树新导出 `externalPluginStates()`（快照：装载态 + rejected 报告 + 指纹时间）。

### 3.7 dsh 侧工具 `apps/dsh-plugin-worldsea/lib/index.js`

- 五件（ToolDefinition 手写，对齐 world_entity_list 先例；目录 = `worlddataDir()/.worldsea/plugins/`）：
  - `world_plugin_list`：文件清单（id/大小/mtime）；
  - `world_plugin_read`：按 id 读源码；
  - `world_plugin_write`：按 id 写/覆盖（轻校验：code 含 `manifest` 且 id 与文件名一致；**原子写**——临时文件 + 同卷 rename，对齐 mutateRelations 先例）；返回提示「~1s 内自动热装载」；
  - `world_plugin_delete`：按 id 删文件；
  - `world_plugin_template`：返回最小插件模板（与管理界面空态同源）。
- 错误码沿用三段式：`WORLDSEA_NO_SESSION` / `PLUGIN_ID_INVALID`（须 `ws.` 前缀）/ `PLUGIN_UNKNOWN` / `BAD_ARGS`。
- 预设：随 lib/index.js 自动进「产品域模式」花名册，无 patch 改动；`__tests__/patch.spec.ts` 花名册用例应不报警（工具注册面无变化）。

### 3.8 示例插件 `.devtmp/sample-plugin/ws.example.js`（开发样例，不入 worlddata）

- 最小视图插件：`h()` 渲染 + `useEntityStore` 读实体计数，作走查素材与模板母本。

  1. 管理界面出现「外部插件」区块（空态含路径与模板指引）；
  2. Agent 执行 `world_plugin_write` 写入示例插件 → 侧栏 ~1s 内出现视图；

  8. 重启应用 → 外部插件自动重装载。
