## 四、非冲突但必须适配的接缝

1. **`TypertGatewayWireStream.open` 的 `peer` 变为必填 `PeerScope`**：我方 pipe 当前传 `undefined`，新版会编译失败。处置：`installPipeMode` 注入 `connection`，按上游 `webworker-runtime/worker-host.ts` 先例使用 `connection.browserPeer`（同一 shell 页面即 browser Peer）。
2. **`trustedHosts` 迁移**：新版由连接层直接读 `webStartup.trustedHosts`，web-app Config 不再持有；删除我方对应配置项，避免重复/无效配置。
3. **`webServer.port` getter**：保留上游 `number | undefined`；external 模式在 init 写入 `listenedPort`，读取时得到声明端口（现有逻辑满足），需复核测试与类型。
4. **新增 `WebApp`/`publicUrl`**：就绪行仍由 web-app 打印 `dsh web: <url>`，格式未变；壳的就绪探测无需改协议。`publicUrl` 默认未设置，走 listener origin。
5. **壳协议白名单复核**：`apps/tauri/src-tauri/src/dsh_proxy.rs` 的 `ALLOWED_PREFIXES` 按新版宿主路由逐条复核；新增路由若落在 `/api`、`/plugins`、`/assets` 等既有前缀外，补表并补 `allowlist_covers_enumerated_host_routes` 用例。
6. **安装包 payload 重新生成**：`apps/tauri/src-tauri/payload/dsh-runtime` 与其 zip 是生成物（不入库）；换树后按打包脚本重新生成，不在源码合并中手工修改。
7. **凭据优先级**：headless 改为 env/.env 优先，web/desktop 优先已保存凭据。我方壳走 env 注入，需真机确认实际使用的 key 与设置页显示一致。
