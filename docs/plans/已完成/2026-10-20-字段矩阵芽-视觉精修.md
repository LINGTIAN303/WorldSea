# 字段矩阵芽 · 视觉精修（2026-10-20）

## 目标

只调呈现，不新增功能：修正面板化后暴露的断点误伤，把内层视觉统一到 App 设计令牌，并收紧表格密度与实体头层级。用户已确认全套 P0–P3、实体头去折叠、实体链接接通切面板。

## 关键发现（浏览器预览实测）

窗口 1600px、右栏 260px 时，字段矩阵内容区只有 **896px**，触发 `matrix.css` 的 `@container fm (max-width: 900px)`：

- **表头吸顶失效**：该断点给 `.table-wrap` 设 `overflow-x: auto`，计算后 `overflow-y` 也变成 auto，表格容器成为滚动容器。滚动 260px 后表头在视口 **-18.7px**，面板顶在 **100.9px**；改为 `overflow: visible` 后表头回到 **101px**。
- **总览列被隐藏**：Traits / 特例两列 `display: none`，只剩 3 列，实体类型列被撑到 **351px**。
- 内层仍是矩阵自有青绿 + 冷灰（`#0f766e / #1f2937 / #dfe5ea`），与壳的靛蓝 + 暖灰（`#4f46e5 / #1f2328 / #ececec`）不一致。
- 字段行高 **58px**（类型中文名单独一行）；关系表中文名列仅 **58px**，四字名称换行。

## 实现

- **P0 断点修正**：`@container fm (min-width: 860px)` 下恢复 `.table-wrap { overflow: visible }`；`min-width: 760px` 下恢复总览 Traits / 特例列。静态 HTML 不受影响。
- **P1 令牌桥接**：`FieldMatrixView` 根节点加 `fm-shell`；`matrix.css` 末尾用 `html .fm-root.fm-shell` 把矩阵变量映射到 App 令牌（`--fm-accent` / `--fm-accent-soft` 中转，避免 `--accent` 自引用）。
- **P2 表格密度**：实体 / Facet 字段表加 `field-table`；类型 / 必填 / 来源列 `width: 1% + nowrap`，中文类型行内；关系表中文名列 nowrap；表头改 `--bg-muted`，去斑马纹留 hover + 细分隔线。
- **P3 实体头与降噪**：`EntityFieldTable` 去掉 `<details>` 折叠与箭头，改静态 `entity-head`；渐变底改透明 + 底部分隔线；删除重复的「芽 · Trait」行，复制按钮移入头部；统计数字 23→20px；AutoLink 0 值 muted；必填、来源、类型圆点、AutoLink 开启态对齐壳语义令牌。
- **实体链接**：`.fm-panel-inner` 捕获 `a[href^="#entity-"]` 点击，`preventDefault` 后 `selectPanel`，覆盖总览 / Trait 矩阵 / 关系表。
