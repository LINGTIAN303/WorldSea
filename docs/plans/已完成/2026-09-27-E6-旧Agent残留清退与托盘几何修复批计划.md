## 一、托盘「打开 Agent 对话」→ 界面不可见：真因与修

**真因（真机复现 + 状态文件取证）**：空间切换的几何快照 `snapshot()` **不识别「来源窗最小化」**——最小化窗的 `outer_position`/`inner_size` 是平台占位值（Windows ≈ `-32000,-32000` 与标题栏尺寸），被 `apply_geometry` 照搬到目标窗 → 目标窗 `show()` 在屏外且极小（复现：托盘切回后主窗 `159×27 @ -25600,-25600`）。而 **`tauri_plugin_window_state`** 又把这个几何持久化（`.window-state.json` 实测 `main: 181×24 @ -32000,-32000`）→ 此后**每次启动都还原成不可见窗**——即用户看到的「打不开程序界面」。

**修法三件**：
1. `snapshot` 记录 `minimized`；`apply_geometry` 遇最小化来源**跳过几何转移**（目标窗保持自身几何；调用方随后照常 show/unminimize/focus）。
2. **启动自检** `sanitize_restored_geometry`：还原几何离屏（< -10000）或尺寸小于下限（320×240）→ 复位 1280×800 并居中——覆盖「退出时最小化 → 下次启动不可见」这一插件固有陷阱。
3. 修复用户机器上已损坏的 `.window-state.json`（已备份至 `.workbuddy/e6-window-state-broken.json`）。

**门禁**：新增 2 例 Rust 单测（快照/守卫源码约定 + `restored_geometry_is_usable` 判据）。
