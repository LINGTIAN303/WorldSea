## 一、目标与非目标

**目标**：
1. **命令面收窄**：把「页面可达的应用命令」从 **202 条收成 7 条白名单**（应用级 ACL 通道），旧 Agent 面全族（195 条）从「页面可调」降为「ACL 拒」；
2. **导航/新窗双栅栏**：主框架导航与 `window.open` 在**壳级**（WebView2 事件）设防——补上 C1-c′ 登记的「程序化 `location` 赋值」缺口（JS 守卫之外的第二道，壳级不可绕过）；
3. **CSP 最小子集**：`object-src 'none'` / `base-uri 'self'` / `form-action 'none'`（协议处理器给 index 加头），其余面（script/style/connect/frame/img）出**取证清单**再拍板。

**非目标**：
- 不动冻结的旧 Agent 面本体（**不删命令、不改其行为**；只是页面不再可达）；
- 不做 OS 级沙箱（进程沙箱/AppContainer）与打包相关（第 1 项批）；
- 不做完整 CSP（按裁定 ③ 先最小子集 + 清单）。

## 三、形态与做法（三裁定）

**裁定 ①（命令面）＝ 只放当前在用 7 条**：
- 新 `apps/tauri/src-tauri/permissions/worldsea-shell.toml`：两条 permission——`allow-shell-bridge`（`cmd_notify` / `cmd_shell_open_external` / `cmd_shell_bridge_report`）与 `allow-stream-bridge`（`cmd_stream_open` / `cmd_stream_send` / `cmd_stream_end` / `cmd_stream_cancel`）；
- `capabilities/default.json` 增引这两条 → app manifest 生效 → 其余 195 条一律 ACL 拒；
- 将来要用某条旧命令：**逐条加**（每次都是可审计动作）。

**裁定 ②（栅栏）＝ 导航 + 新窗双栅栏，走 WebView2 原生化**（不动窗口创建）：
- `with_webview` 上挂 `add_NavigationStarting`（主框架）：只放行自家源（`http://worldsea.localhost` 与 `worldsea://localhost`）、`data:`（壳错误页）、`about:blank`；其余 cancel（http(s) 交系统浏览器，与 JS 守卫同语义）；
- 同处挂 `add_NewWindowRequested`：一律 `SetHandled(true)`（不出应用内新窗），http(s)/mailto 交系统浏览器；
- **不挂** `FrameNavigationStarting` → iframe（内置浏览器/预览）不受影响；
- macOS/Linux 的等价路线（builder 迁移或 wry 层）**登记不做**（本仓现役仅 Windows；跨平台进打包批）。

**裁定 ③（CSP）＝ 最小子集 + 取证清单**：
- `dsh_proxy.rs` 对 index 响应加 `content-security-policy: object-src 'none'; base-uri 'self'; form-action 'none'`；
- 其余面（script/style/connect/frame/img/font）出一份**取证清单**（逐项：现状依赖 → 若收紧的风险 → 建议值），归档进本计划 §八，另行动议。

## 五、批次划分（每批含实现 / 验收 / 反证 / 文档）

### C3-a · 应用命令能力面（ACL）——**已完成（2026-09-24）**
- 实现：`permissions/worldsea-shell.toml` + `capabilities/default.json`。
- 验收：页面探针——壳桥 `report` 可用（`ipc=ok`）· 流桥 5 条真实流照常 · **旧命令（如 `cmd_agent_tool_names`）调用被拒**（探针取回 ACL 拒绝文本）。
- **结果（真机证据）**：壳桥 boot `ipc=ok` · 5 条真实流照常 · 探针调旧命令 `cmd_agent_tool_names` → **`cmd_agent_tool_names not allowed. Command not found`**（源码级确证为 ACL 拒：`tauri/authority.rs:432/1138`；命令本身仍注册在 `lib.rs:196`）。
- **反证**：摘掉 `allow-shell-bridge` 一条 → 壳桥**全哑**（`bridge(page)` 行 = 0，连 boot 上报都被拒）而流桥照常（5 条流仍开）→ 复原复绿。

### C3-b · 导航/新窗双栅栏——**已完成（2026-09-24）**
- 实现：新 `nav_fence.rs`（**纯函数策略** + 单测：`navigation_allowed(url)` / `new_window_action(url)`）+ `lib.rs` setup 挂 WebView2 事件。
- 验收：页面探针 `location.href='https://example.com'` → **导航不发生**（壳级拦；C1-c′ 缺口转正）· 内置浏览器面板 iframe 载外站**不受影响** · 现有导航（重载/回退）正常。
- **结果（真机证据）**：栅栏挂载行 `主框架导航 + 新窗栅栏已挂（WebView2 事件层）` · 探针 `location.href='https://blocked.invalid/'` → **`拦下主框架导航 https://blocked.invalid/`** 且页面留驻自家源（before=after）· iframe `window.open` → **`拦下新窗请求 about:blank`**。**过程中逮到一处误伤并修**：`frontendDist = shell-loading`（B3 兜底页）走 `tauri.localhost`，初始策略把它拦了（会得到空窗口）→ 策略补放行 `tauri://localhost` / `http(s)://tauri.localhost` 并加单测。
- **反证**：`WORLDSEA_NO_NAV_FENCE=1` 起壳（同一探针）→ `已按 WORLDSEA_NO_NAV_FENCE 关闭` + **零拦下行** + 探针在导航提交处随页面一起消失（`after` 不达、活动停止）→ 复原复绿。

### C3-c · CSP 最小子集 + 取证清单——**已完成（2026-09-24）**
- 实现：`dsh_proxy.rs` index 响应加 CSP 头（三指令）。
- **结果（真机证据）**：探针 `fetch('/')` → `index csp=[object-src 'none'; base-uri 'self'; form-action 'none']`；子资源 `asset csp=[null]`（只 index 带，判别项）· 页面零回归（body 渲染 ✓、5 条流 ✓、零 4xx/5xx）。
- **反证**：把常量改成 `object-src 'self'` 标记值 → 探针读到的头随之变化（证明头由壳常量控制、非宿主遗留/非 Tauri 注入）→ 复原复绿。
- 取证清单见 §八（六面 + 下批候选三条 + `worker-src blob:` 一条）。

## 六、风险

| # | 风险 | 缓解 |
|---|---|---|
| R1 | app ACL 误伤内部调用（某启动链命令被拒） | 验收含 boot 链（壳桥 ipc=ok + 流桥 5 条流 + 全 api 200 零 4xx）；误伤即加白（逐条可审计） |
| R2 | 栅栏误伤既有功能（内置浏览器 iframe / 错误页 data: / 重载 / 回退） | 事件面选 `NavigationStarting`（主框架）不挂 frame 事件；白名单含 `data:`/`about:blank`；验收逐项走查 |
| R3 | `with_webview` 回调线程/生命周期（COM 事件在 WebView2 线程） | 策略为纯函数 + 回调只读；先例 = 既有加速键设置块（同一 `with_webview` 用法） |
| R4 | CSP 三指令误伤（理论上不碰脚本/样式/连接） | 最小集选的是「页面根本不用」的指令（无 object 嵌入、无表单提交、无 `<base>` 改写） |

## 七、本批不做

- 旧 Agent 面的退役与命令删除（冻结期结束另行立项）；
- OS 级沙箱 / AppContainer / 进程隔离；
- 完整 CSP（六面清单出报告，另行动议）；
- 跨平台（macOS/Linux）栅栏实现（打包批）。

## 八、CSP 取证清单（C3-c 产出，2026-09-24）

> 现状：CSP 由壳在 **index 响应头**上加（`dsh_proxy.rs` 的 `CSP_INDEX`，最小子集三条）；下列六面逐项给出「现状依赖 → 若收紧的风险 → 建议值」。**未收紧的指令一律保持不设**（浏览器默认放行），不误伤为第一优先。

| 面 | 现状依赖（证据） | 收紧风险 | 建议值 |
|---|---|---|---|
| `script-src` | 宿主注入行（`__DSH_BOOT__` 等）与壳注入脚本均为**内联 `<script>`**，且宿主行**每进程变化**（插件图） | 静态 hash 不可行；nonce 需改宿主注入面（dsh fork） | 暂 `'unsafe-inline'`（= 现状不设）；后续可在 fork 内做 nonce 通道 |
| `style-src` | dsh 前端样式由 bundle 出 CSS 文件；内联样式（布局变量/`style=`）存在与否未逐处盘 | 需实测逐屏，回归面宽 | 暂不设（`'unsafe-inline'` 等价） |
| `connect-src` | 页面 fetch 只走自家源（壳协议 → 管道）；Tauri IPC 不走 fetch；blob: 仅作资源 URL 非连接 | 低——**可收紧为 `'self'`**（需实测附件下载/预览链） | 候选 `'self'`（列入下批待办） |
| `frame-src` | **内置浏览器面板 = 外站 iframe**（`ui-sidebar-browser`）；文档预览可能 blob/data | 收紧即破「内置浏览器」（C1 走查项） | 必须放开（`*` 或 `https: blob: data:`） |
| `img-src` | 聊天正文可含远程图片；附件/历史图片用 `blob:` URL（`historical-images.ts:117`、`service.ts:78`） | 收紧需逐档实测（远程图 / blob / data） | 候选 `'self' data: blob: https:`（列入下批待办） |
| `font-src` | 前端自带字体（bundle 内） | 低 | 候选 `'self' data:`（列入下批待办） |

**下批候选**：`connect-src 'self'` + `img-src 'self' data: blob: https:` + `font-src 'self' data:` 三条（各自需一次逐屏实测；连同 `worker-src blob:`——`file-upload/runtime.ts:246`、`documentpreview/excel/parse.ts:20` 用 blob: 载 worker）。
