# 字段矩阵芽 · 表内排版（2026-10-20 · 三刀）

## 目标

只调矩阵表内排版，不新增功能。用户选定 1+2+3 与舒适密度：统一字号阶梯与表头、数字/布尔列对齐、行高 7px / 1.5。列宽比例与 Trait 矩阵最小宽本轮不动。

## 实现

- **字号阶梯**：壳内普通表格正文 12px、行高 1.5；元信息（类型 / 来源 / 必填 / 选项 / 注释）11px；字段键 12px mono/600。
- **表头**：10px/700/0.03em → 11px/600/0.02em；普通表头 padding 8px 10px，底线 `--border-strong`。
- **数字列**：总览字段数、关系属性数、Trait 使用数、AutoLink 分数右对齐 + `tabular-nums`；必填 / 对称列居中。
- **密度**：普通表行 8px→7px 纵向内边距、line-height 1.6→1.5；Trait 矩阵保持 7px/8px 与 980 最小宽。
- 静态 HTML 仍不受影响（全部收在 `.fm-shell` 下）。
