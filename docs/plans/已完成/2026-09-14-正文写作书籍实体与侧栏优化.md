> status: 已完成

## 一、书籍实体（书 → 章节 → 编辑器）

### 需求与形态

用户需求：「加入书籍实体，可创建单独的书籍，点击书籍后才能进入到章节编辑器」。落成 **两层导航**：

- **层1 书籍列表**：卡片网格（书名 / 简介 / 章节数 / 总字数），hover 出删除按钮；「未归书章节」虚拟卡片（仅当存在无 bookId 章节时显示）；工具条「新建书籍」。
- **层2 书籍工作区**：即原正文写作界面——侧边栏章节列表 + 章节编辑器；侧栏顶部加「← 书名」返回条；工具条切「新建章节」；大纲筛选与「共 N 章」仅本层显示。

### 数据模型与设计决策

- **新实体 `type='book'`**：`manuscript/index.ts` 注册（icon `book`，traits identifiable+visual，ownFields 空——简介复用顶层 `description`）。id 前缀 `book-`。
- **归属 = `manuscript.properties.bookId`**（登记 ownField「所属书籍ID」）：与 notebook folderId 同型的外键式归属，通用实体面板/关系体系零特殊化。**不内嵌章节列表到 book 实体**（实体更新是 properties 整体替换，内嵌列表并发写易互相覆盖）。
- **旧数据零迁移兼容**：无 bookId 的既有章节天然落「未归书」虚拟组（`selectedBookId === ''` 哨兵，与 `null`=列表层区分）。
- **删书不删章**（useConfirm 确认）：书内章节 `bookId` 置空回到未归书，内容不丢；提示文案带章节数。
- **sortOrder 语义收窄为书内序**：新建章节排序基线 = `viewChapters.length`（当前书内章节数）；导出对话框「全部章节」= 当前书章节（`viewChapters`）。
- **离开书籍/切书前 `flushSave()`**：防止 400ms 防抖窗口内改动滞留（复用 NotebookView 同款纪律）。

### 落地文件

- `manuscript/index.ts`：注册 book + manuscript 加 `bookId` ownField。
- `ManuscriptView.vue`（重写）：`selectedBookId` 三态导航；`books`/`selectedBook`/`viewChapters`/`unfiledChapters` computed；`openBook`/`backToBooks`/`newBook`/`deleteBook`；书籍卡片网格样式（`.ms-book-*`）；侧栏返回条（`.ms-back-btn`）；工具条 Teleport 按层切换。既有快照/AI/预览/导出/编辑器功能全保留。

## 五、书籍功能迭代（2026-09-14 第四轮，三项拍板全落地）

用户拍板：①图片封面 ②「全部章节」升级为整书导出 ③网格拖拽排序。

### ① 图片封面 + 简介编辑（BookInfoDialog.vue 新组件）

- **封面 = `book.properties.cover` 存 asset URL**：上传走 `writeImageAsset` 全套复用（类型/2MB 校验、落盘 `{entityDataDir}/assets/`、convertFileSrc）——封面图进素材面板视野、**孤儿清理按 book.properties JSON 识别不会误删**（引用扫描覆盖全实体 properties）。
- 弹层字段：书名 / 简介（description）/ 封面上传 + 移除；`pendingCover` 三态（undefined 未动 / null 移除 / string 新封面），保存时统一写入。**实体更新 = properties 整体替换，弹层带全量 properties**（entity_commands.rs:338 教训）。
- **双入口**：层1 卡片 hover 操作组（编辑/删除并排）+ 层2 侧栏返回条旁编辑按钮。卡片封面区 150px 高负 margin 出血（无图显示图标占位，object-fit cover）。

### ② 整书合并导出（升级「全部章节」，不新增范围按钮）

- `useManuscriptExport` 新增 `exportBook(book, chapters, format)`：文件名与文档标题 = **书名**（替代固定「全部章节.docx」）；md 为**书级 frontmatter**（书名/简介/章节数/总字数/导出时间），章节只留 `# 标题` 不再逐章塞 frontmatter；txt 首行书名。docx 复用 `htmlToDocx`（title=书名 → buildDocxBlob 文档标题），章节结构同旧逻辑（h1+hr），图片资产预处理在 htmlToDocx 内统一做。
- `ExportDialog` 加 `book?: Entity | null` prop：**有 book 时 scope=all 走 exportBook**，无 book（笔记本芽复用/未归书视图）走旧 `exportMultiple`——向后兼容零破坏。

### ③ 书籍排序（网格拖拽）

- vuedraggable（ChapterList 同款依赖零新增）：卡片网格 `:list="books"` + `@end="onBooksReorder"`；**未归书虚拟卡片放 `#footer` slot**（不参与排序）。拖拽落 `book.properties.sortOrder`（ChapterList onDragEnd 同款模式：draggable mutate 的临时数组在 @end 时即最终顺序）。
- `books` computed 按 sortOrder 升序，旧书籍无字段排最后（`?? Number.MAX_SAFE_INTEGER`），首次拖拽后自然收敛；新建书初始化 `sortOrder: books.length`。

## 六、跨书移动 + 创建走弹窗（2026-09-14 第五轮，风险点收口 + 拍板项）

### ① 章节跨书移动（§五风险点清账）

- `ChapterList` 右键菜单新增「移动到书籍」→ 选择弹层（复用大纲选择器同款结构）：列出全部书籍 + 「未归书」选项；**当前所属书禁选**（`.disabled` 态，选了无变化）。
- 确认后 `properties.bookId` 更新（整体替换带全量）；移出当前书后章节自然从侧栏过滤消失（viewChapters 按书过滤）。
- **已知无害行为**：移走的章节若正被编辑，编辑器仍开着它（current 独立于列表过滤）——内容不丢，返回列表后恢复正常，不处理。

### ② 新建书籍改走信息弹窗（用户拍板：不再直接落地「未命名书籍」）

- `BookInfoDialog` 支持双模式：`book` prop 传实体 = 编辑模式（原行为）；null/缺省 = **创建模式**——标题「新建书籍」、按钮「创建」，保存（es.add）前不落地任何实体。
- **封面上传时机后移**：选文件仅本地预览（objectURL + 与 writeImageAsset 同口径的本地预校验），**保存/创建时才 writeImageAsset 落盘**——取消/关闭不残留无引用图片文件（此前选文件即落盘，取消会产生 24h 才能回收的孤儿）；objectURL 在弹层卸载时 revoke。
- `newBook()` 函数删除，`startCreateBook()` 仅开弹层（`editingBook=null` 哨兵区分模式）；`nextSortOrder` prop 由父层传 `books.length`（创建模式写入 sortOrder；编辑模式忽略）。
- 编辑模式改动保持兼容：pendingCover 三态重构为 coverFile/coverRemoved/原值不动 三路判定，保存时统一组装 properties。
