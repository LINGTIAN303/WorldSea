# R3-d · 收藏/最近与排序收口

> 定位：R3-c 之后的导航高频入口批。用户 2026-10-20 拍板：
> - 首批做**收藏/最近**；域内拖拽排序改为复用**设置 → 芽管理**已有的拖拽排序，不在侧栏另做。
> - **全部六形态**共享快捷区；快捷区以**悬浮层**呈现，不占用侧栏布局，鼠标进入热区时浮现。
> - 工具域折叠 / 管理入口仍归 R4。

## 一、交互定义

### 热区与浮层

- 芽侧栏头部左侧增加一个星标热区（24×24，绝对定位，不占头部布局）；平铺/左右侧栏的芽侧栏、2–5 形态共用。
- 鼠标进入热区 → 浮层出现；移出后 180ms 关闭；移入浮层取消关闭。
- 点击热区 → 固定打开；再次点击 / Esc / 点击外部关闭。
- 浮层锚定在热区下方；侧栏在右时右对齐，并夹在视口内。
- 浮层 `role="dialog"`，触发按钮带 `aria-expanded` / `aria-haspopup`。

### 内容

- 头部：星标 + 「快捷访问」+ 「收藏当前」星标按钮（当前芽已收藏时为实星）。
- **收藏**：按收藏顺序展示；跨域；行尾实星可取消收藏。
- **最近**：最近打开的 5 个芽，自动记录、去重、移到最前；已在收藏中的不重复显示；行尾空心星可收藏。
- 行点击 → 打开该芽；未固定时关闭浮层。
- 空态：两节都为空时提示「浏览芽后会自动出现在最近；用星标收藏常用芽」。
- 底部提示：「排序：设置 → 芽管理」（只提示，不在侧栏另做拖拽）。

### 数据

- localStorage 全局键：
  - `worldsea_sprout_favorites`：`string[]`，新收藏插到最前。
  - `worldsea_sprout_recent`：`string[]`，最多 5，去重、最新在前。
- 快捷区只展示当前可见芽；已停用/卸载的芽自动隐藏，但保留 id 记录，重新启用后恢复。
- 当前视图变化时自动写入最近。

## 二、复用与边界

- 拖拽排序：沿用 `SproutsCardContent.vue` 的 `vue-draggable` + `uiStore.sidebarOrder`（设置 → 芽管理，未搜索/未筛选时可拖）；R3-d 不新增侧栏拖拽，不改其规则。
- R3-c 的轮盘/轮播、域过滤、左右侧栏独立收起不变。
- 不改 `settingsStore`；快捷区 id 全局稳定，无旧数据迁移。
