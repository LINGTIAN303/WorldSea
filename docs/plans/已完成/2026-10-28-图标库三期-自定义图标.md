## 二、数据模型

**图标资产登记**

```ts
interface IconAsset {
  id: string          // UUID，文件名 <id>.<ext>
  name: string        // 展示名（原文件名去扩展名，限长）
  ext: 'svg' | 'png' | 'webp'
  bytes: number
  createdAt: number
}
```

- 项目：`project_settings.icon_assets` + `localStorage['worldsea_icon_assets_project:<projectId>']` 回退，带 `updatedAt`。
- 全局：`localStorage['worldsea_icon_assets_global']`。
- 文件：
  - 项目：`{entityDataDir}/.worldsea/icons/<id>.<ext>`
  - 全局：`<home>/WorldSea/icons/<id>.<ext>`

**覆盖值**：`custom:<id>`，与现有槽位覆盖层共用。解析顺序：项目资产 → 全局资产。

## 三、渲染

- `WsIcon` 新增自定义解析器注册位（ui-kit 模块级，无 Pinia 依赖）。
- `custom:` 图标用 `<span>` + CSS `mask-image` 渲染，`background-color: currentColor`，单色跟随主题。
- SVG 不内联，统一经图片/蒙版加载，避免脚本执行。
- `hasIcon` 同步纳入自定义解析，保持「可解析 = 有图标」。

## 四、界面

- 设置 → 图标新增第 7 卡「自定义图标」：上传、项目/全局来源徽标、使用次数、删除。
- 上传时可选「同时保存到全局」；选择器「应用到全局」对自定义图标会复制文件到全局并改写为全局资产 id。
- 图标选择器新增「我的图标」分类与上传入口。
- 删除前扫描当前项目 + 全部项目覆盖；被引用时阻止并列出项目/槽位。

## 五、导出/导入

- 项目文件夹：导出 `icons/` + `settings/icon-assets.json`；导入写回 `.worldsea/icons/` 与项目登记。
- WorldSeaPack：新增 `icon-assets` 分区，资产 base64 内嵌；导出集合 = 项目全部资产 + 被项目覆盖引用的全局资产，导入后落为项目本地。
- `.ws` 包走同一 WorldSeaPack 数据（base64 在 JSON 内），不额外复制媒体。
