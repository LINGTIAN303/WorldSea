# R3-c · 六形态调整与改进

> 定位：R3-a（单侧栏 2–4）、R3-b（双栏平铺）与 R3-b2（左右侧栏）之后的**打磨批**，不新增导航模式。
> 输入：用户 2026-10-20 真机走查后的 10 条意见 + 候选池裁定。
> 分批：**R3-c1 形态校正（1–8）** → **R3-c2 偏好开关（9–10）**。

## 一、形态更名（仅 UI 文案，模式 id 不变）

| id | 旧名 | 新名 |
|---|---|---|
| `flat` | 平铺 | **默认** |
| `popover` | 域弹出层 | **级联菜单** |
| `rail` | 域图标栏 | **条式平铺** |
| `tabs` | 域-芽 Tab | **标签切换** |
| `dual` | 双栏导航 | **双栏平铺** |
| `split` | 双栏分离式 | **左右侧栏** |

## 二、R3-c1 范围（用户 1–8）

1. 「当前」不再硬编码在默认项；哪个形态被选中，哪个选项追加「（当前）」。
2. 六形态按上表更名，设置搜索关键词同步。
3. 级联菜单浮层增加指向小三角；浮层与当前选中域**同水平线居中**（箭头对准该域行），左右侧栏自适应镜像。
4. 双栏平铺缩宽：整体 330 → **300px**，域列 140 → **124px**；芽列仍自适应。
5. 左右侧栏改为**独立收起/展开**：芽栏用 `sidebarCollapsed`，域栏用新增 `domainSidebarCollapsed`；新增设置「左右侧栏同步收起」，默认**关**。开启后任一侧收起/展开，另一侧跟随；Ctrl+B 仍只控制芽栏。
6. 左右侧栏默认改为**域左、芽右**；新增设置「双栏顺序」（域左芽右 / 芽左域右），默认域左芽右。split 时隐藏「芽侧边栏位置」行，避免两个方向控件冲突。
7. 级联菜单 / 条式平铺 / 标签切换 / 双栏平铺 / 左右侧栏的收起按钮统一为平铺样式（40px 头部、整行按钮、28px 高、同一 chevron 方向与 Ctrl+B 提示、不触发列表拖拽）。
8. 「推演与工具」缺图标：域注册表 `tactical` → `tactical-board`（图标表实际键名）。

### 附带收口（不改变操作路径）

- 芽/域列表按钮补 `aria-current="page"`（当前视图）。
- 左右侧栏的收起状态参与 `ViewContainer` 左右让位，主区不再依赖两栏同收。
- `SidebarV2` 仅加 `forceSide` 可选项（split 强制芽栏侧），其余行为零变化。

## 三、R3-c2 范围（用户 9–10）

9. **轮盘效果开关**（默认开）：关闭后所有形态回退静态滚动列表。
   - 默认：`SidebarV2`（平铺芽栏）、左右侧栏的域轮盘，保持现状。
   - 用户 2026-10-20 走查后调整：**级联菜单改为域列表轮盘、芽列表静态**；**标签切换与双栏平铺的域列表、芽列表都轮盘**；条式平铺仍只有芽列表轮盘。
   - **所有轮盘的选中项固定在列表垂直中线**（与平铺形态一致），绝对定位实现，不依赖列表剩余空间。
   - 关闭时：平铺 / 左右侧栏 / 其余形态全部静态；split 的芽栏改用同壳静态列表。
10. **实体数徽章开关**（默认开）：所有形态的芽行尾显示实体数；关闭后全部隐藏。数量口径沿用 `SidebarV2` 的 `pluginId → schema.typeKey → allTypeCounts`，抽成共享模块，避免两套映射。

## 四、候选池裁定（用户授权自定）

| 候选 | 裁定 | 理由 |
|---|---|---|
| 域内芽拖拽排序 | **移交 R3-d** | 轮盘开启时拖拽已用于滚动，重排需另设手柄/模式；先让轮盘开关落地再定。 |
| 收藏 / 最近使用 | **移交 R3-d** | 新增持久状态与固定入口区，属于导航 IA，不属于本轮打磨。 |
| 工具域折叠 / 单独分组 | **移交 R4** | 与设置页按域分组同源，避免两处各做一套折叠。 |
| 管理 / 添加入口 | **移交 R4** | 设置页芽管理已可达；侧栏加入口需先定域树入口位置。 |
| 空态 / 窄窗 / 键盘 | 空态已在列；窄窗记录走查；键盘不扩 scope | 先解决看得见/点得到。 |

### 风险

1. 轮盘关闭后平铺改用静态 `SproutNav`，自定义视窗的 HTML5 拖拽重排（原 `SidebarV2` 专属）暂不可用——已移交「域内拖拽排序」R3-d 一并评估。
2. 轮盘作用域（走查后定稿）：级联菜单 = 域轮盘 + 芽静态；标签切换 / 双栏平铺 = 双轮盘；条式平铺 = 芽轮盘；平铺 / 左右侧栏 = 各自现有轮盘；域内拖拽重排留 R3-d。
3. 级联菜单「全部」有 27 芽，芽列表静态时需滚动；域轮盘只负责选域，不再轮播芽列表。
