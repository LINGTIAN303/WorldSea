## 三、技术方案

### 3.1 A1 · docx 链下沉

- 迁移：`manuscript/composables/{htmlToDocxBlocks,blocksToDocx,imageData}.ts` → `apps/tauri/src/composables/docx/`；
  测试 `manuscript/__tests__/htmlToDocxBlocks.spec.ts` → `composables/docx/__tests__/`。
- 引用改点：`useManuscriptExport.ts`（2 处动态导入）、`exportRunner.ts`（2 处动态导入）、测试内 3 处相对导入。
- 依赖关系：`blocksToDocx` 依赖同目录 `htmlToDocxBlocks` + `imageData`，一起迁移后相对路径不变。
- 三文件均 < 400 行，且不在 `architecture-baseline.json` 中，无基线迁移。

### 3.2 B-IME · Enter 守卫

- 新增 `forms/enterGuard.ts`：
  - `guardEnter(ev, run, opts?)`：`isComposing || keyCode === 229` 直接返回（不提交、不 `preventDefault`）；
    可选 `ctrl`（仅 Ctrl+Enter）与 `noShift`（Shift+Enter 换行不提交）。
- 覆盖 9 个入口：7 个表现形式 + `BoardListView`（打开/改名）+ `BoardSectionView`（区改名）。
- 模板去掉 `.prevent` 修饰，改由守卫在**非组合态**下调用 `preventDefault`——组合态必须放行默认行为，否则候选词上不了屏。
- 单测 `enterGuard.spec.ts`：组合态 / 229 / 正常提交 / Ctrl 要求 / Shift 放行。

### 3.3 B-缩放

- `BOARD_SHORTCUT_META` 增 `outline-board.zoom-in`（`ctrl` + `=`）与 `zoom-out`（`ctrl` + `-`），`preventDefault: true`。
- `BoardView` handler 调 `canvasRef.zoomStep(-1 / 1)`（与滚轮同一套 1.1/0.9 步进）。
- `SHORTCUT_CATALOG` 同步两行（`boardShortcuts.spec` 守卫会比对）。

### 3.4 A4 · 规格对齐

- `编辑器交互规格` §二：`双击节点项` → `单击或双击节点项`；`拖拽与双击` → `拖拽、单击或双击`。
- 代码零改动。
