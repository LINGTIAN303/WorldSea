## 三、现状事实基线

### 3.1 dsh 侧（`D:\WorldSea\.独立项\deepseek-harness`，2026-09-23 快照）

- 体量：**312 个 workspace 包**；`packages/*/src` **2,304 文件 / 393,043 行**（client 60 包 936 文件 123,575 行，其中 `.tsx` 278 文件 47,608 行；core 45/14,646；session 98/17,845；host 25/4,077）。apps：cli（src 8/909，bin=`lib/bin.js`）、web（src 4/66 + vite 产物）、desktop（Electron，src 58/6,332）、desktop-host（纯 Node，8/628）。测试 1,802 个 `.spec`；外部运行时依赖 67 名；lock 1,678 条 resolution。
- 仓库 138 MB（packages 61 MB）；**未安装、未构建**（无 `node_modules`、无 `lib/`、无 `dist/`）。
- 许可 MIT；版本 `0.1.7-alpha.2`（developer preview，官方声明将有破坏性变更）。
- 运行要求：Node `^22.19 || >=24`（本机 v24.10.0 ✓）；pnpm 钉 `11.7.0`（本机 11.5.1，调用时需按版本）。
- 构建链：`pnpm install` → `pnpm run build`（`build:lib:host` = tsc -b + tsdown；`build:lib:client` = tsdown client face；`build:web` = vite → `apps/web/dist`）。

| # | 接缝 | dsh 侧现状 | Tauri 侧做法 |
|---|---|---|---|
| 1 | 子进程启动 | Electron RunAsNode + `--expose-internals` + 内置 pnpm | Rust 侧 spawn `node <dsh>/apps/cli/lib/bin.js --profile <p> --no-open --port <p>` |
| 2 | 传输 | 特权协议 `dsh-app://app/` + `protocol.handle` 伺服 dist + `/api` 转发 + WS 凭据注入 | **A（推荐）**：WebView 直指 `http://127.0.0.1:<port>/?token=…`，零协议重写；**B**：Tauri 自定义协议复刻 Electron 姿态 |
| 3 | 壳桥（preload 全局） | 8 个全局；client 真正读取只有 3 处且**全部可选**（`!('dshDesktop' in globalThis)` 时整页 return；`dshPlatform` 缺失即省略；`__DSH_HOST_PATHS__` 走 `?.`） | 按需注入（Tauri initialization script）；不注入也不坏主界面 |
| 4 | 宿主能力 | 原生目录选择 / 更新准入 / 平台凭据 / Office 运行时 / `load_workspace_dependencies` | 目录选择：dsh 在 Windows 走 koffi（非 Electron），**可能零改动**；其余按需 |
| 5 | 壳功能 | 原生菜单 / 强制更新 / 崩溃报告 / 单实例锁 / 麦克风权限 / DevTools 快捷键 | Tauri 侧按需（首期最小集：单实例 + DevTools + 退出清理） |
| 6 | 打包 | Electron 安装包 + electron-updater | 后置裁定（§十 R1） |

## 五、迁入方案（dsh 落点与形态）

**已拍板（D5/D6）**：仓根新建 `dsh/`，整仓原样迁入（`packages/`、`apps/`、`vendor/`、`scripts/`、`snapshots/`、`docs/`、`website/`、`python/`、`benchmarks/`），保留 dsh 自身 pnpm workspace 与 lockfile，**不并入本仓根 workspace**（`pnpm-workspace.yaml` 不收录 `dsh/`）。重构完成后再议是否调整形态。

理由：① dsh 的构建链、bundle purity 门、client 构建预设都假设其仓根结构，混入会破坏可复现性；② 「直接迁文件」的最小改动路径；③ **更新通道 = fork**（D10 改判）：**不追随上游**；需要上游改动时按台账「先 diff → 定位冲突面 → 单独立批」摘取。

**基线来源**：初版取上游 tag `dsh-v0.1.7-alpha.2` 的干净克隆（D9）；2026-09-24 **追版至 `dsh-v0.1.7-rc.1`**（B5，见 §九）。不使用用户侧 `.独立项/deepseek-harness`（理由见 §九 B0 结果）。

配套：
- **`dsh/` 是我方 fork**（D10）：可以改，但每一处改动必须**逐文件登记**进 [dsh fork 台账](../details/架构/dsh-fork台账.md)（门禁 `pnpm fork:check`，未登记即报红）；新行为优先走 dsh 扩展点（profile / `cordis.patch.yml` / 插件），非必要不动核心。
- 依赖安装：dsh 无 `.npmrc` → 统一以**命令行/环境变量**覆盖 registry（`--registry=https://registry.npmmirror.com`，CN 稳定性手段；官方源实测可达），不改 dsh 内任何文件；口径写进运行手册。
- 入库策略：`dsh/node_modules`、构建产物（`lib/`、`apps/web/dist`）、`~/.dsh` 均不入库；其余原样入库（§十 R7 / 待拍板 ②）。

## 六、壳替换方案（Tauri 替 Electron）

首期链路：Tauri 启动 → Rust 侧 spawn dsh CLI（`--no-open --port <空闲端口>`）→ 解析 stdout 的 `?token=` → WebView 指向 `http://127.0.0.1:<port>/?token=…` → Cookie 建立会话 → 退出时 kill 子进程（含异常路径）。壳桥按 3 处读取点按需注入。

- 窗口：现 `tauri.conf.json` 为无边框 + `dragDropEnabled:false`；dsh 界面自带布局，窗口形态（原生边框 / 无边框 + 自绘标题栏）属 UX 决策 → 首期取**原生边框**，后续按需。
- dev：`beforeDevCommand` 改指向 dsh 构建产物 + 起服务；`frontendDist` 让位（不再加载本仓 Vue 前端）。
- 本仓 Vue 前端在壳内不再加载——产品域部分（sprouts 等）落位另行立项（待拍板 ④）。

**现役实现（2026-09-23，B2/B3 落地）**：新增 `apps/tauri/src-tauri/src/dsh_shell.rs`（空闲端口 → spawn `node dsh/apps/cli/lib/bin.js web --no-open --port <p>` → 解析带 token URL → `WebviewWindow::navigate` → 子进程守护 → `RunEvent::Exit` 回收 → 可辨认失败页）；`lib.rs` 三处接线；窗口 `decorations: true`，`frontendDist` 指向壳兜底页 `apps/tauri/shell-loading/`，`beforeDevCommand`/`devUrl` 已删。dev 起壳：`cd apps/tauri/src-tauri && cargo run --offline`。环境变量：`WORLDSEA_DSH_ROOT`（覆盖 dsh 树位置）、`WORLDSEA_DSH_HOME`（覆盖 DSH_HOME；**默认已隔离到应用数据目录** `<app_data>/dsh-home`）、`WORLDSEA_NODE`（覆盖 node 可执行名）、`WORLDSEA_FRAMELESS=1`（回退无边框）。

**B4-a（2026-09-23）：打开 web 下默认禁用的右栏内置浏览器**——`ui-sidebar-browser` 条目随 bundle 发布，但 `disabled` 是按 profile 名判定的表达式（仅 `desktop` 启用；`desktop` profile 由 Electron 壳独占，CLI 拒绝管理），故用**用户补丁层** overlay 打开：新增 [`apps/tauri/dsh-overlay.yml`](../../apps/tauri/dsh-overlay.yml)，壳 spawn 加 `--patch <仓根>/apps/tauri/dsh-overlay.yml`（官方同款通道，先例 `dsh/apps/web/tests/pin-browse-picker.overlay.yml`）。验证：index 客户端插件图内出现 `ui-sidebar-browser/client.js`。**壳桥三项的实证结论**（不做或不需要，逐条给理由）：`ui-settings-general` 的 `dshDesktop` 只喂 Electron 更新徽标（缺失即惰性）；`ui-settings-models` 的凭证引导**恰恰只在无 `dshDesktop` 时显示**；目录选择走 `directory-picker-auto` → loopback 下已自动解析到**原生对话框**（koffi，非 Electron）；唯一做不了的是 `__DSH_HOST_PATHS__`（拖入文件真实路径）——WebView2 不暴露 `File` 路径，且开原生拖放会吃掉 HTML5 拖放（反而更差），缺省走内容上传兜底。

**C1 批更新（2026-09-24，取代上面「首期链路」的直连形态）**：壳把 **UI origin 与传输面分离**——UI 走壳注册的 `worldsea` 协议（Windows 落形 `http://worldsea.localhost/`），`/api` 与 mux WS 仍回 loopback（刻意保留）；壳在导航前对带 token URL 做 **303 换 cookie**（token 不进 WebView URL），`/api` 由协议处理器带 cookie 转发，mux WS 走**壳内 Rust 中转**（改写 `Host`/`Origin`/`Cookie`/`Sec-Fetch-Site` 四项后透传）；另落地**原生菜单**（文件/编辑/视图/设置）、**壳桥** `__WORLDSEA_SHELL__`（通知/外链/设置入口/日志，靠自定义协议页在 Tauri `is_local_url` 白名单内、IPC 直达应用命令）与**外链守卫**（镜像 Electron 的 `setWindowOpenHandler`/`will-navigate` 语义）。细节与全部排障开关见 [C1 批计划](2026-09-24-C1-Tauri原生desktop载体批计划.md) 与 [运行手册 §五](../details/架构/dsh-运行手册.md)。

**C2 批更新（2026-09-24，真·无端口）**：在 C1 之上把**传输面**也收进壳——宿主经 **IPC 管道**服务（`--ipc-pipe`，Windows 命名管道 / POSIX 套接字），**宿主进程零 TCP 监听**；壳侧以**帧隧道**（`u32be 长 + kind`）多路复用请求与 mux 流，页面用 **`openStream` 钩子**（`__DSH_TRANSPORT__` 只合并不覆盖，取代 `streamBaseUrl`）经 Tauri IPC 走管道；宿主侧改动落在 webserver 外置载体模式 + web-app `pipe-transport`（fork 台账 11 文件）。C1 的 loopback 形态转为 **legacy 对照口**（`WORLDSEA_TCP_HOST=1`）。三裁定与全部事实见 [C2 批计划](2026-09-24-C2-真无端口传输批计划.md) 与 [运行手册 §五](../details/架构/dsh-运行手册.md)。

## 九、批次计划

> 反证式验收沿用既往口径：注入一次它声称会拦的错误 → 必须报红 → 还原 → 转绿，两次输出留档。

### B0 · 起跑线（不动本仓）

- 任务：在 dsh 副本上 `pnpm install`（registry 覆盖）→ `pnpm run build` → 起 `--profile web --no-open --port <p>` → 记录协议面（`/api`、`remote.mux`、cookie、`__DSH_BOOT__`）。
- 验收：真机走查——浏览器里跑通一次真实会话（含工具调用），界面与官方一致。
- 反证：registry 覆盖失效 / 端口占用 / token 缺失 三类失败留档（表现与判别）。
- 前置风险：Node 原生件（node-pty ConPTY、koffi）在本机 Windows 的构建结果必须在此批确认。

**结果（2026-09-23，通过）**

- **快照取舍**：`.独立项/deepseek-harness` 实测**不自洽**——相对上游 `master`（= tag `dsh-v0.1.7-alpha.2`，`00102833`，09-22 23:25）为 **+197 项新增 / 0 项缺失 / 仅 `pnpm-lock.yaml` 内容不同**，属「新源文件已加、清单与类型未同步」的中间状态（如 `boot/app-boot/src/watch-config.ts` 引 `chokidar` 而该包未声明）→ `pnpm run build`（`tsc -b tsconfig.host.json`）报 **487 个类型错误**，`pnpm run clean` 后重建仍 487。故改取上游 tag 干净克隆（D9）。
