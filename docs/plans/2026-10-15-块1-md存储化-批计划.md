## 一、技术选型（2026-10-15 调研定案）

**选 `@tiptap/markdown`（官方扩展）**：

| 依据 | 说明 |
|---|---|
| 渲染引擎＝marked | 与现有渲染链（`contentNormalize` 的 `renderMarkdownForEditor` / 预览 `sanitizeMarkdownHtml`）**同源**，词法语义天然一致 |
| 官方包处理器内建 | TableKit / TaskList / TaskItem **已内置 md 处理器**（表格 / 任务零自研）；StarterKit 节点（标题 / 列表 / 引用 / 代码块）同理 |
| 自定义节点机制明确 | `parseMarkdown` / `renderMarkdown` handler + `createBlockMarkdownSpec` / `createInlineMarkdownSpec` 辅助 |
| 内嵌 HTML 支持 | 官方明示「Raw HTML inside Markdown is parsed too」——**B 裁决（内嵌 HTML）落地有桥** |
| `contentType: 'markdown'` | 编辑器装载直吃 md，取代现「md→HTML→setContent」两跳 |

**备选与弃因**：prosemirror-markdown（GitLab 模式）——需自写每节点规则、无编辑器集成，工作量大；社区 tiptap-markdown——作者已退役并建议迁移官方。

**新增依赖（待拍板）**：`@tiptap/markdown@3.29.x`（与 @tiptap/* 对齐，安装时核实 npmmirror 可达版本）。
**安装纪律**：装 apps/tauri 侧；`--registry=https://registry.npmmirror.com`；装前备份 lock；装后核对（vue-tsc / vitest / 已知手工变通存活）+ lock diff 逐项解释。

**风险与核实项**：版本匹配（装时核实）；Mention 官方是否带 md 处理器（无则自写，列入阶段 1）；成熟度以 roundtrip 冒烟立即验证。

### 阶段 3 · 链路切换（代码变更，回归面）

| 链路 | 现状 | 改为 | 落点 |
|---|---|---|---|
| 装载 | contentNormalize 三态判定 → HTML → setContent | `contentType:'markdown'` 直装；**三态判定退役** → 收敛为「解析前容错预处理」（空行断表格修复保留，不改写存储） | `useNoteEditor` / `contentNormalize` |
| 保存 | `getHTML()` | `getMarkdown()` | `useNoteEditor.persistContent` |
| 预览 | `sanitizeMarkdownHtml(getHTML())` | marked 渲染 md（`renderMarkdownForEditor` 管道复用） | `NotebookTipTapEditor.previewHtml` |
| 检索 | `plainText` 剥 HTML 标签 | 剥 md 标记 | `NotebookView.plainText` |
| MD 导出 | HTML→md 有损转换 | **原文直出** | 导出链 |
| DOCX 导出 | HTML→IR | md→HTML→IR（现链复用）+ **图片宽度扩展**（`htmlToDocxBlocks` 读 width → IR → `blocksToDocx`；顺带修复存量缺口） | `htmlToDocxBlocks` / `blocksToDocx` |
| 测试翻修 | notebook 12 文件 / 130 例（HTML 假设） | 全翻修 | `__tests__/*` |

- **【已完成 2026-10-15】**：① 装载＝md 直装（`setContent(md, { contentType:'markdown' })`）；contentNormalize 重写为「解析前容错」（表格空行修复 + 围栏安全；三态判定全退）；notebook/index.ts 归一器注册退役。② 保存＝`getMarkdown()` 全链（防抖/切走/卸载），辅助面 getHTML→getMarkdown。③ 预览＝`renderMarkdownForEditor(getMarkdown())`（marked 链同源）。④ 检索＝剥 md 标记（单源 `@/composables/markdownText`，调用侧压平）。⑤ 导出＝`resolveContent` 双源分流（notebook=md 直出/零转换；manuscript=HTML 现状）：txt 剥标记、docx 走 md→HTML→IR + **图片宽度扩展**（IR 透传 width/height、映射层优先——修复既有缺口）。⑥ 测试：contentNormalize.spec 重写（8 例）· editorPersistence 数据 md 化 · 新增 markdownText.spec（7 例）+ IR 尺寸用例。**门禁**：notebook 130+1skip · manuscript 44 · vue-tsc 0。**待**：真机走查。
