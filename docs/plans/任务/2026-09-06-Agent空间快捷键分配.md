# Agent 空间快捷键分配

status: 执行中

> 2026-09-06 调研落档。Agent 空间（`apps/tauri/src/space/`，非群聊模式为主）目前零快捷键注册；本文给出机制前提、键位分配方案与实施批次。
> **拍板结果（2026-09-06）**：Q1 切壳键=Ctrl+Tab；Q2 右栏 Tab=单键 1-5；Q3 顺手修=全修。

## 1. 调研结论（现状）

- `space/` 目录无任何 `useShortcuts` 注册；App.vue:108-114 在 `currentShell==='space'` 时 `setActiveViewId(null)`，view 层在 Agent 空间整体失效——Agent 空间事实上没有自己的快捷键层。
- 现存键盘监听（均为组件局部层，语义自洽保留）：ChatInput textarea 的 Enter 发送/Shift+Enter 换行/召唤菜单导航、三处 capture 抢跑 Esc（ChatInput 权限菜单 / ModelSwitcher / CreationPanel 浮窗）、各输入框 enter/esc、role=button 的 Enter/Space 触发。
- **现存问题 ①**：global 层 `?`（help.shortcuts）/ `Ctrl+,`（settings.open）的 handler 打开 Shell.vue 内的弹窗（Shell.vue:170/173），Agent 空间按键时弹窗开在 `v-show` 隐藏的壳里 = 按了没反应。Agent 空间自己的设置按钮走 AgentSpace.vue:113 的独立 SettingsDialog。
- **现存问题 ②**：global 数字键 1-9（AppMenu.vue:102，切前九个插件视图）在 Agent 空间照常触发——隐形切换被隐藏的 workbench 视图。
- **现存问题 ③**（调研顺带发现）：分发器 `advanceSequences` 无上下文过滤——导图连击序列（view scope 的 `n c` 等）在 Agent 空间也会推进并触发 handler。

## 2. 机制前提：新增 `space` scope

AgentSpace 是 `v-show` 常驻挂载（与 Shell 并存），不能直接用 view scope（会污染 workbench）。新增与 view 平行的 scope，按壳生效：

```
packages/ui-kit/src/composables/useShortcuts.ts
├─ ShortcutScope 加 'space'
├─ SCOPE_ORDER = ['modal', 'editor', 'view', 'space', 'global']（两壳互斥不同屏，序仅影响遮蔽检测语义）
├─ 新增 setAgentSpaceActive(active: boolean)（App.vue watch 注入，与 setActiveViewId 并列）
├─ 分发循环：if (scope === 'space' && !agentSpaceActive) continue
├─ advanceSequences 补上下文过滤（view 需 activeViewId 非 null；space 需 agentSpaceActive）→ 顺手修问题 ③
└─ setShortcut 对 space 开放改键（同 view）
```

- App.vue watch：`setAgentSpaceActive(shell === 'space')`（setActiveViewId 注入保持不变）。
- ShortcutsPanel 按 SCOPE_ORDER 自动分组；`utils.ts` 的 `scopeLabel()` 补 'space' → "Agent 空间"；SHORTCUT_CATALOG 加 Agent 空间组。帮助弹窗动态读 registry 免维护。

## 3. 键位分配（space 层，id 前缀 `space.`）

注册处：AgentSpace.vue setup（参照 Shell.vue 模式，组件常驻、onBeforeUnmount 注销兜底）。

| 键 | id | 命令 | 备注 |
|---|---|---|---|
| `Ctrl+N` | space.session.new | 新建会话 | PREVENT_DEFAULT 已兜底；经模板 ref 调 SessionSidebar 的 newDraftSession |
| `Ctrl+F` | space.session.search | 聚焦会话搜索 | 左栏关闭则先开；SessionSidebar expose focusSearch() |
| `Ctrl+Shift+B` | space.sidebar.toggle | 左栏开合 | sessionOpen + spaceStore.setSessionSidebarOpen；群聊模式无左栏 → handler 判 mode 空转 |
| `Ctrl+J` | space.right.toggle | 右栏开合 | 复用 AgentSpace.vue:241-244 onToggleRightPanel |
| `1-5` | space.tab.exec / config / creation / preview / usage | 右栏五 Tab 切换 | setRightTab(:234-238)；space 层优先于 global → 1-5 被 space 消费，不再隐形切 workbench 视图 |

输入焦点保护由注册表统一处理：聊天框打字时按 1-5 / Ctrl+F 均为正常输入（isInput 跳过非 modal 层）。Enter 发送保留 ChatInput 组件局部层（规范 §3），不收编。

壳通用键（global 层，拍板后加）：`shell.toggle` 切换两壳，键位待选（§4-Q1）。

## 6. 风险点

- `Ctrl+Tab` 在 WebView2 的边缘行为需真机验证（若被吞则换 `Alt+S`）。
- global 层其余键（Ctrl+Z 撤销、Ctrl+K 搜索等）在 Agent 空间的"隐形生效"现状不在本次范围，行为未变；后续如要审视另行立项。
- SessionSidebar 的搜索/新建需跨组件调用（expose 或事件），注意与既有 `sidebarView`（组件本地态）联动——聚焦搜索前确保处于 sessions 视图。
