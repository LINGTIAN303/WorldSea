# 批 2 · overlay 贡献位 + 数据面板迁移（双 Cordis「一切皆插件」L2 首批）

> **来源**：批 1 完成后进入 L2 存量迁移；2026-10-14 用户确认范围（overlay 贡献位 + ui/data 面板组 A 方案 + files 死代码清理）。
> **盘点修正**（推翻批 1 清单两处）：① components/files 非独立文件面板——FilePreview/FileTreeBrowser/CodeEditor/五类预览器的真实消费方是 notebook 芽（实质已插件化，仅物理位置未搬）；ProjectFilesPanel 零外部引用 = 死代码链。② 工作台窗 [Shell.vue](../../apps/tauri/src/ui/layout/Shell.vue) 固定挂载 15 个全局弹窗/面板（`ws-open-*` 事件触发），其中 ui/data 三面板在 apps 内——它们**不是侧栏视图**，`registerView` 覆盖不了。

## 一、口径

| 项 | 定稿 |
|---|---|
| overlay 贡献位 | `PluginAPI.registerOverlay({ id, label, component })`（entity-core 真源，对齐 view 同款：变更事件 + 卸载自动撤登记）；`WorldPluginApi.registerOverlay` 经 `withPluginScope` 锁插件身份 |
| 显隐契约 | **打开 = `ws-open-<id>` 全局事件**（OverlayHost 统一监听已登记集，登记/卸载增删 listener）；**关闭 = 面板组件 emit `close`**。现有事件名 `ws-open-trash / ws-open-artifacts / ws-open-consistency` 与 id 恰好对齐，事件契约零变动 |
| 面板组件契约 | 沿用现有 `{ show }` props + `@close` emit——**迁移组件零改动**（只搬目录 + 登记） |
| 插件身份 | `official.data-tools`（存量官方功能迁移走 official 域；`ws.*` 留给用户新增） |
| 启停 | `DEFAULT_SPROUTS` 加 `official.data-tools`（category: system，active: true）——关 = 三 overlay 撤登记，`ws-open-*` 静默 no-op（与无插件时一致） |
| 卸载语义 | overlay 撤登记（实体/关系类型不注销口径沿用） |
| 设置页豁免 | StorageManagementTab（含其内部 KvViewerDialog）属设置页，随设置页最后迁批；本批不动 |

## 二、施工面（文件级）

1. **entity-core 真源**：[PluginAPI.ts](../../packages/entity-core/src/core/PluginAPI.ts)——`registerOverlay / unregisterOverlay / clearOverlays + onOverlayChange`（`OverlayChange = { kind, overlay }`，对齐 view 三处派发 + 监听器隔离）；types 补 `PluginOverlay`（id/label/component）。
2. **插件 API 面**：[world/api.ts](../../apps/tauri/src/world/api.ts)——`WorldPluginApi.registerOverlay`（withPluginScope + registerPluginCleanup 撤登记）。
3. **OverlayHost（L0 骨架）**：`apps/tauri/src/shell/OverlayHost.vue`（新）——订阅 `onOverlayChange` 镜像登记集；v-for 渲染（`:show` / `@close`）；按登记集增删 `ws-open-<id>` listener（try/catch 隔离）。
4. **数据工具插件**：`world/plugins/data-tools/`（新，`official.data-tools`）——manifest + apply 登记三个 overlay（TrashPanel/ArtifactsPanel/ConsistencyReportPanel）。
5. **面板搬家**：`ui/data/TrashPanel.vue` / `ArtifactsPanel.vue` / `ConsistencyReportPanel.vue` → `world/plugins/data-tools/`（组件内部不动）。
6. **Shell 接线**：[Shell.vue](../../apps/tauri/src/ui/layout/Shell.vue) 删三面板挂载与三个 handler（`ws-open-*` 全局事件改由 OverlayHost 消费），挂 `<OverlayHost />`；[settingsStore.ts](../../packages/entity-core/src/stores/settingsStore.ts) DEFAULT_SPROUTS 加条目。
7. **files 死代码清理**：删 `components/files/ProjectFilesPanel.vue` + `FileTabBar.vue`（施工时精确核 FileTabBar 活引用；[fileTabsStore](../../apps/tauri/src/components/files/fileTabsStore.ts) 被 FilePreview 消费=活，仅注释同步）。
8. **测试**：entity-core overlay 生命周期 spec（登记/撤/clear/事件/隔离）；OverlayHost open/close 契约 spec；data-tools 登记 spec（三 overlay 进真源、ws-open-* 可达）。
