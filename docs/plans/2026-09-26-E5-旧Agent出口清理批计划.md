## 一、B 修：空间路由改指现役 dsh 面

**缺陷**：工作台窗的「Agent 空间 ⇄ 工作台」有两条路径——窗口栏按钮走壳桥 `__WORLDSEA_SPACE_SWITCH__`（D1-b：双窗互斥切换，正确）；**Ctrl+Tab 快捷键与托盘「打开 Agent 对话」仍走页内 `uiStore.setShell('space')`** → 工作台页内渲染被构建期桩空的 `AgentSpace`（空页）。

**修法**：新增 `apps/tauri/src/composables/shellSwitch.ts`（**桥优先**：有壳桥则调 `cmd_shell_space_switch` 做窗口互斥切换；无桥——浏览器预览/旧壳——回退页内壳切换），三处收敛到同一入口：`TitleBar.vue` 切换钮 · `Shell.vue` 的 `shell.toggle`（Ctrl+Tab）· `useSystemBridge.openAgentView()`（托盘）。配单测锁定「有桥不落页内 / 无桥回退」两条。
