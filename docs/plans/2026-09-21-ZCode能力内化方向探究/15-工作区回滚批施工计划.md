## 二、设计（草案）

**写前快照（before-image，内容寻址）**
- 挂点 = `fs_tools.rs` 三处写入点（与 `sink.file_change` 同处，已有 path/kind）；
- 写入**成功前**：读目标文件现内容 → `raw_store.put`（零重复）→ 记 `workspace_file_ops` 行：
  `(session_id, request_seq, path, before_hash: Option<String>（None=当时不存在）, after_hash: Option<String>, op: 'write'|'edit'|'edit_diff', at_ms)`；
- **失败降级**：快照失败不阻断写入（记 warn）——但**并行 in-flight 标记**？不引入；`F-1` 语义见 §四 Q4。

**回滚执行链**：`rewind_workspace(session_id, request_seq)`（自由函数 + 事务括号，同 S3 家族）
- 取 `request_seq > target` 的 ops **倒序** → 逐条：`before_hash=Some` 写回内容；`None`（当时不存在）→ 删除文件；
- **只触碰 ops 记录过的文件**（不扫描、不臆测）；重复回滚同边界 → 无 op → no-op（幂等）；
- 结果明细报告：`{ restored: n, removed: n, failed: [{path, reason}] }`——失败**不静默**；
- 前置：运行中拒绝（同 `rewind_session` 守卫）。

**命令面**：`rewind_workspace(session_id, request_seq)` → 明细 DTO；`list_workspace_ops(session_id, limit?)`（面板可选：显示某边界的文件变更数）。

**前端**：回滚确认弹窗加「同时回滚文件」复选框（Q2）→ 勾选则先 `rewind_workspace` 再 `rewind_session`（顺序：先文件后会话——会话回滚成功后才切换视图；文件失败则以明细提示，会话不阻断）；历史抽屉边界行显示「N 处文件变更」徽标。

## 四、裁定表——**拍板记录（2026-09-23，全按建议）**

| # | 裁定点 | 拍板 |
|---|---|---|
| Q1 | 快照范围与时机 | **(a) 仅 Agent 写入工具触碰的文件 + 写前 before-image（内容寻址）**——全工作区快照体积不可控；写后 after-image 拿不到改写前状态 |
| Q2 | 回滚入口 | **(a) 现有回滚弹窗内加「同时回滚文件」复选框（默认勾选）**——心智 = 回到那个点，一次操作；独立按钮易造成只回一边的分裂态 |
| Q3 | 新建文件回滚 | **(a) 删除该文件**——回滚语义 = 恢复当时状态（当时不存在 ⇒ 删除） |
| Q4 | 快照失败 / 回滚冲突 | **(a) 快照失败仅 warn 不阻断写入**（回滚时该条缺 before → 明细报「不可回滚」）——增强项不得反噬主操作 |

**自主项（不拍板）**：agent-tmp 分区**纳入**回滚（临时区文件也是 Agent 写的，回滚应一并恢复；登记）；边界行徽标形态；明细提示文案。

## 四之二、Wa 落地记录（2026-09-23）

**内核契约（复用 `tool_stream` / `raw_context_sink` 注入模式）**
- `tool_context.rs`：新增 `FileOpRecorder` trait（`async fn record_before(path, before, op)`——契约：**不得阻断写入**、`before=None` 为新建语义）+
  `ToolContext.file_op_recorder: Option<Arc<dyn FileOpRecorder>>`（默认 None = 行为逐字不变）；
- `agent/mod.rs`：`AgentLoop.file_op_recorder` + `with_file_op_recorder(...)`；`agent/tools.rs` 构造 ctx 时随 `is_sub_agent` 一并注入。

**存储与执行链**
- `session_store.rs`：`workspace_file_ops` 表（`ensure_schema` 幂等建表 + 索引）+ trait 三方法（`record_workspace_op` 归属 = `MAX(request_seq)`（无快照归 0）/ `workspace_ops_from`（`>= target`，**id 降序**）/ `recent_workspace_ops`）+ SQLite 实现；
- 新模块 `workspace_rewind.rs`：`WorkspaceFileOpRecorder`（Q4：快照失败仅 warn）+ `rewind_workspace`（**倒序逐条撤销**：before 写回 / 新建删除（NotFound 幂等） / 越界拒绝 / 失败进明细）+ `list_workspace_ops` + DTO/报告（camelCase）；
- `fs_tools.rs` 三处写入点挂接（write_file / edit_file / edit_diff——落盘**前** `record_before`）；
- 装配（`lib.rs::new_agent`）：与 `raw_context_sink` 同段注入（同一 `RawStore`；未配置会话存储时不注入）；
- service 两方法（`rewind_workspace` 运行中拒绝 = 复用 `rewind_guard`；workdir 取自 `agent.workdir()`）+ Tauri 命令两件 + 注册。
