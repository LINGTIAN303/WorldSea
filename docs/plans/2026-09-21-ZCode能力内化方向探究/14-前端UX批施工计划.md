## 二、设计（三子批）

### UX-a 会话分支（分叉 / 回滚 / 检查点）

**Rust（唯一新增命令面）**
- `list_request_boundaries(session_id, limit?) -> Vec<RequestBoundaryDto>`：
  - 数据源 = `request_snapshots`（`load_request_snapshots` 既有 trait 方法）+ `session_checkpoints` 匹配标注；
  - DTO 字段（轻量，**不传 snapshot_json 本体**）：`seq / capturedAtMs / purpose / modelId / messageCount / userText`（快照视图内最后一条 User 消息文本前 120 字，**供消息行匹配**）/ `checkpointId: Option<String>`；
  - 排序 seq 降序；`limit<=0` 不截断。
- 服务层方法 + Tauri 命令 + `invoke_handler` 注册（命令数 +1，登记）。

**前端**
- 新 composable `useSessionBranch.ts`：`loadBoundaries / forkAt(seq) / rewindAt(seq) / createCheckpoint / loadCheckpoints`；监听 `agent:event:session_branch:{sid}`（**当前无监听器，事件被丢弃**）→ `forked`：toast + 刷新会话列表 + **自动切到子会话**；`rewound`：重拉消息视图（沿用既有回源）+ toast；`checkpoint_created`：刷新检查点 + toast。
- 入口 1（消息行）：turn 行悬浮「⋯」→「从此处分叉 / 回滚到此处」；**匹配口径** = `userText` 前 120 字 + 时间就近；**匹配不到则该行不显示入口**（fail-visible，不猜锚点）。
- 入口 2（历史抽屉）：新组件 `SessionBranchPanel.vue`——边界时间轴（时间 + 用户消息摘要 + 检查点标记）+ 任务断点段（`CheckpointRef.anchor=TaskProgress`）+「打点」按钮；侧栏 `SessionSidebar` 加一行入口（不增长余量内）。
- 回滚前置：运行中拒绝（后端已拒）→ 前端按钮态随 `RunningDuration`/busy 状态禁用 + 失败 toast 原文。

### UX-b 权限与规则（会话授权 + 元数据呈现 + 项目规则）

**B1 会话授权按钮**
- 确认弹窗 `extraActions` 增「本会话总是允许」（粒度见 Q2）→ `grant_session_permission(sessionId, [{toolName, content, once}])` → 返回 >0 则按放行（`confirmed`）。
- 现有「添加白名单并放行」（全局白名单）保留并列——两者语义差异在按钮文案与说明行明示（「全局」vs「本会话」）。

**B2 工具元数据呈现（若 Q3 做）**
- 契约扩展：`InteractionRequest::Permission` 增 `risk_level: Option<String>` / `side_effect_scope: Option<String>` / `display_name: Option<String>`（`#[serde(default)]`，wire 兼容）；
- 填充点：kernel 构造 Permission 请求处（`maybe_require_confirmation` 已取证声明，直接带上）；
- 前端：`RustInteractionPayload` 镜像 + 确认弹窗展示（风险徽章 + 副作用范围 + `getToolLabel` 兜底显示名）；
- 守卫：engine 单测（字段 roundtrip + default 兼容）+ 前端 vitest（载荷镜像含三字段 + 弹窗渲染断言）。

**B3 项目规则编辑/重载**
- 新子组件 `ProjectRulesSection.vue` 挂 `AgentSettingsPanel` 的 `safety` 子面板：
  - 显示 `{workdir}/.worldsea/permissions.json` 路径（workdir 取自 `SessionInfo.workdir`；无工作区 → 只读提示）；
  - 编辑模式见 Q4；保存走 `cmd_fs_write(createDirs:true)`；「重载」→ `reload_project_rules(session_id)` → bool 三态提示（true=已加载 / false=未声明或坏 JSON）。

### UX-c 大结果呈现（artifact + 查看原文）与收口

- 新组件 `ArtifactCard.vue`（shared-ui）：识别工具结果 JSON 的 `{artifact: "raw/<hash>", bytes, note, preview}` 信封 → 显示「结果过大（N 字节），已外置」+ preview + 「查看全文」；
- 识别截断标注中的 `原文已外置：raw/<hash>`（`raw_context::EXTERNALIZED_MARKER` 同串）→ 可点 chip（增量外置路径）；
- 新组件 `ArtifactViewer.vue`：`memory_read_raw(hash, from, maxChars)` 分片 + 「加载更多」（`nextFrom` 游标）+ 总字符数进度；错误（坐标非法 / 不存在）→ 明确提示不静默；
- `ToolRow.vue` 只加检测分支（余量 30 行内）；
- 收口：全口径基线 + 反证 + 真机走查清单 6-8 项。
