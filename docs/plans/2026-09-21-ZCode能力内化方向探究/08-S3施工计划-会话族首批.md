## 一、S3-a（骨架批）

- **立项理由**：S2 冻结的四契约必须有落地的**单一定义处**；新 crate 是「逐族切换」的载体（D4）。
- **内容**：
  1. `crates/agent-engine`：零业务依赖（不依赖任何 worldsea crate——依赖方向单向，防环）；
  2. `contracts` 模块定义四契约类型（对齐 [07](07-内核契约冻结.md) §一/三/四；serde `snake_case` 与旧 kernel 口径一致）；
  3. `architecture-policy.json` 登记模块（**治理规则首演**：未登记即检查报红 → 登记后零违规）。
- **验收（反证）**：① 建 crate 未登记时 `arch:check` 报红（留证）；登记后零违规；② `cargo test` 全绿；③ 类型口径与旧 kernel 逐条对照（InputKind 三值 / ConfirmationOutcome 四值语义一致）。
- **不做项**：不搬 59 个事件 key 表（S3-b 一次性迁移，避免双份事实源漂移）；不搬 `ToolDescriptor`（归属工具族批次）；不接任何前端/命令层改动。

**落地记录（2026-09-21）**：① 未登记时 `arch:check` 报红（`[registry] 模块目录未登记：crates/agent-engine`）→ 登记后零违规（**治理规则首演**）；② `cargo test`（MSVC + offline）**5/5 通过**（fail-closed / serde snake_case 往返 / 五模式声明面 / 三语义 / 键形态）；③ 枚举口径与旧 kernel 逐条对照一致（`#[serde(rename_all = "snake_case")]`）；④ 零业务依赖（`requires: []`，依赖方向单向，防环）。

## 二、S3-b（事件与存储）

- **内容**：`keys` 表 + `mode_of` 迁入 `agent-engine::contracts`（**旧 kernel 改为只读引用**——单一定义处；涉及 agent-kernel 的依赖登记与 policy 更新）；会话存储新表：`session_forks`（`forked_from = { session_id, request_seq }`）· `session_checkpoints`（锚点集合 + 保留策略）· 操作 mark（fork/rewind/checkpoint 三类，**事务括号 + 装载期收敛**，沿用压缩锁范式）。
- **验收（反证）**：key 表穷尽 match 保留（新增变体**编译期强制登记**）；存储往返 / 幂等 / 崩溃点注入各一例；B6（请求快照重建）不回归。
- **不做项**：不动 `session_log` / `session_live` 既有格式（只加表）。

**落地记录（2026-09-21，b1）**：keys 表（**59 项**）+ `mode_of` + `DispatchMode` 迁入 `agent-engine::contracts`；旧 kernel 经 `pub use` **只读引用**（`agent_kernel::event::{keys, mode_of, EventKey}` 与 `event_bus::DispatchMode` 路径兼容，下游 `agent_runtime::event::keys::*` 调用点**零改动**）；`agent-kernel` 增依赖并 policy 登记（反证：注销登记 → `rust-edge` 红 → 恢复零违规）；验证：engine **6/6** · kernel **311/311（零行为变更）** · **全链** `cargo check` 通过（runtime / memory / index / commands / patterns / src-tauri）。**b2（会话存储新表）下一片。**
