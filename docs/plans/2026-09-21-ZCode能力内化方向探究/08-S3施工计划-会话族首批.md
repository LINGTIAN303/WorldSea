## 一、S3-a（骨架批）

- **立项理由**：S2 冻结的四契约必须有落地的**单一定义处**；新 crate 是「逐族切换」的载体（D4）。
- **内容**：
  1. `crates/agent-engine`：零业务依赖（不依赖任何 worldsea crate——依赖方向单向，防环）；
  2. `contracts` 模块定义四契约类型（对齐 [07](07-内核契约冻结.md) §一/三/四；serde `snake_case` 与旧 kernel 口径一致）；
  3. `architecture-policy.json` 登记模块（**治理规则首演**：未登记即检查报红 → 登记后零违规）。
- **验收（反证）**：① 建 crate 未登记时 `arch:check` 报红（留证）；登记后零违规；② `cargo test` 全绿；③ 类型口径与旧 kernel 逐条对照（InputKind 三值 / ConfirmationOutcome 四值语义一致）。
- **不做项**：不搬 59 个事件 key 表（S3-b 一次性迁移，避免双份事实源漂移）；不搬 `ToolDescriptor`（归属工具族批次）；不接任何前端/命令层改动。

**落地记录（2026-09-21）**：① 未登记时 `arch:check` 报红（`[registry] 模块目录未登记：crates/agent-engine`）→ 登记后零违规（**治理规则首演**）；② `cargo test`（MSVC + offline）**5/5 通过**（fail-closed / serde snake_case 往返 / 五模式声明面 / 三语义 / 键形态）；③ 枚举口径与旧 kernel 逐条对照一致（`#[serde(rename_all = "snake_case")]`）；④ 零业务依赖（`requires: []`，依赖方向单向，防环）。

## 三、S3-c（分叉）

- **内容**：fork 会话（从**请求边界**派生、父会话零影响、新会话记录 `forked_from`）；事件 `conversation/forked` 登记（key + mode）；崩溃冷修复接线。
- **验收（反证）**：分叉后父会话日志哈希不变（对照断言）；子会话独立追写；注入崩溃点（分叉中途）→ 装载期检出收敛。

**落地记录（2026-09-21）**：
- **执行链**（新文件 `session_fork.rs`，95 行）：`fork_session(parent_id, request_seq)` —— ① 父会话头 + 请求快照链读入；② `reconstruct_request_view` 重建边界视图（**链缺失/不完整即拒绝**，拒绝发生在落 mark 之前 ⇒ 零残留；复用 08 重建链，零新游标）；③ 子会话头复制装配面（提示词/场景/工作区/项目，不携带工具会话与长任务状态——ZD1-5）；④ 事务括号：落 mark（payload 携 `child_session_id`）→ `save_session` → `replace_messages`（子会话日志坐标独立从 0 起）→ `record_fork` → 清 mark。**失败路径故意保留 mark**（mark 未清 ⇔ 未提交）。
- **冷修复**（`session_branch.rs` 增 `reconcile_residue`，315→377 行）：全量收敛装载期残留——`fork` 残留 ⇒ 撤销半成品子会话（内容可由父快照重放，删除无信息损失；行不存在则只清 mark）；其余 op 只清 mark（S3-d 按需补撤销动作）。经 `SessionRepository::reconcile_branch_residue`（trait 默认无操作 + SQLite 实现委托）接入 `restore_sessions`（**先于会话装载**——避免半成品被重建为内存幽灵会话；失败不阻断恢复，warn 留档）。
- **事件登记**：`agent-engine::contracts::keys::CONVERSATION_FORKED = "conversation_forked"`（snake_case 单词式）+ `mode_of` 显式登记（Emit）。发射点（命令层）随首族切换批（S3-e 裁定后）。
- **验收证据**（反证式，各留双份）：① 父会话三面指纹（日志行 / 视图游标 / 事件流）逐字不变（强于哈希——无碰撞空间）——**变异注入「视图错写父会话」→ 断言红**；② 子会话独立追写 + 同边界多子会话互不影响（兄弟隔离断言）；③ 崩溃点注入（mark 未清 + 子会话行/视图已写、来源未写）→ 文件库重开后 `reconcile` 检出并撤销，且**已提交分叉不被误撤**（commit 后无 mark ⇒ 检出空）；④ 装载期接线由 `restore_sessions` 测试覆盖（半成品含活跃视图，purge 不命中 ⇒ 只有收敛路径可回收）——**变异注入「摘除接线」→ 3 例恢复测试全红（含装载期 2≠1）**。
- **验证**：engine **7/7** · kernel **311/311（零行为变更）** · commands **250/250**（新增 6 例：边界重建/父零影响/拒绝零残留/独立追写/重启收敛/装载期收敛）；全链 `cargo check` 通过（runtime/memory/index/patterns/src-tauri）；`arch:check` 零违规（基线显式复核 3 处：lib.rs 4571→4590 / lib_tests.rs 1898→1952 / session_store.rs 2988→3002，逐条可解释）。
- **顺带修正**：3 处既有文档断链（P 线两文档相对路径深度写错），`check-doc-links` 断链 0。
- **不做项（随批声明）**：命令层/Tauri 接线与事件发射（随 S3-e 切换批）；`forked_from` 前端展示。
