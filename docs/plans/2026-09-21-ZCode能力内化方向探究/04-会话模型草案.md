## 一、立项理由

新内核需要统一的「会话面」契约。本项目现状**已具备**：不可变日志（`session_log`）+ 活跃视图（`session_live`，游标可重写）+ replace 遮蔽（折叠/锚点实现形态）+ 压缩事务括号/孤儿锁 + 请求头快照（任一请求可结构级重建）。**缺的是**：

1. **分叉**（fork）与**回滚**（rewind）——写作场景「试写一版 → 不满意 → 回到分叉点」是真实高频需求（比编程场景更贴产品）；
2. **检查点**的统一模型——现状仅长任务域有 `CheckpointProvider`（心跳 5s / stale 30s），会话边界无检查点概念；
3. 崩溃冷修复仅覆盖压缩锁——fork/rewind 两类操作无事务保护。

## 二、设计要点

### 2.1 唯一模型（归一，不二选一）

```
仅追加日志（session_log，不可变原文）
  + 活跃视图（session_live：position → log_offset 游标，可重写 = replace 遮蔽）
  + 请求头快照（request_snapshots：每请求的日志纯函数）
```

- 折叠/锚点 = replace 遮蔽的**实现形态**，保留（承接 04-§一 A2 修正：两者语义同构，已裁定非二选一）。
- **模型可见 ⟺ 已记录**（不变量，与 08 快照链一致）：fork/rewind 必须产生可见事件，不得静默改写。

### 2.2 锚点 = 请求边界（复用既有坐标）

分叉与回滚都以**请求边界**为锚（`request_seq` 已存在且可重建），不新造第二套游标（避免 08-§七 已修的「在途消息」类缺口重演）。

### 2.3 分叉（fork）

- 从会话的某请求边界派生新会话：新会话记录 `forked_from = { session_id, request_seq }`；父会话**零影响**。
- 写路径走**事务括号**（沿用压缩锁范式：操作前落 mark → 成功清 → 装载期孤儿收敛）。
- 分叉后两端独立追写；分叉不复制无关状态（工具会话、长任务心跳按裁定处理，见 ZD1-5）。

### 2.4 回滚（rewind）——三域分层

ZCode 的三域 = `conversation | workspace | both`。本项目分层落地：

| 域 | 归属 | 落地方式 |
|---|---|---|
| conversation | **内核** | 向活跃视图追加一条 replace（回退到指定分叉锚的视图），日志不删 |
| workspace | **领域层**（写作数据 = entity store） | 内核只提供「锚点坐标 + 事件流」；实际数据回滚由领域层以自身机制实现（本批是否纳入见 ZD1-3） |
| both | 组合操作 | conversation 由内核执行 + 领域回滚由领域层执行；**协调协议**（两段提交或尽力而为+回执）在细则阶段定 |

### 2.5 检查点（checkpoint）

- 两类：**会话检查点**（内核：每 N 个请求边界自动 + 手动打点）/ **工作区检查点**（领域层：与回滚同源）。
- 检查点 = 锚点集合 + 保留策略（数量/成本裁定，见 ZD1-4）；与长任务 `CheckpointProvider` 合并为同一接口（不新建第二套）。
- 打点产生会话事件（前端可见）：`checkpoint/created`、`conversation/forked`、`conversation/rewound`。

### 2.6 崩溃冷修复

沿用孤儿锁范式：fork / rewind / checkpoint 三类操作**先落 mark、成功清 mark**；装载期 reconcile（检出即收敛 + warn 留档）。与既有 `reconcile_orphan_compact_lock` 同一代码路径族。

### 2.7 输入准入

保持 A3 现状（三语义 `followup/steer/inject` + waterfall 准入），**不引入第二套 inbox**——ZCode 的 CommandInbox「串行 admission」语义本项目已等价具备（裁定点：是否借用其六态命名做统一文档术语，见 ZD1-6）。

## 四、不做项

- 不做多端 replayable 投影（C9 低优先，另行立项）。
- 不做跨设备同步与共享。
- 不引入第二套日志或第二套游标。
- 不动 `session_log/session_live` 的既有格式（只**加表**：fork 记录 / 检查点 / 操作 mark）。

## 五、验收口径（施工时）

- 反证：分叉后父会话零变化（对照会话日志哈希）；回滚后视图与目标边界结构级等值（复用 08 重建链断言）；注入崩溃点（三类操作各一）验证装载期收敛。
- 回归底线：B5（压缩四件套）/ B6（请求快照）/ B9（长任务）全绿；kernel / commands 基线不降。
