## 一、现状盘点（2026-10-08 探查）

**机制**（GEV 系 16 芽）：`resolvedTabs` 自动拼装＝`信息 + 封面(schema 含 coverImage) + customTabs(芽声明)
+ 关系 tabs(detailTabs=RelationTabDef[]) + 关联`；五载体共用 `DetailShell`（`tabs.length>1` 才渲标签条、
`overflow-x:auto` 横滚）+ `useDetailChrome`（切页状态/失效回首页）；内容按 `activeTab` 动态槽分发。
**TimelineView 手写全量**（info/cover/causal）——两套组织方式并存。

| 面 | 现状 |
|---|---|
| 自定义 tabs | 仅 3 芽：characters 6、organizations 4、regions 4（内容经芽 `#tab-xxx` 槽） |
| 关系 tabs | ≈34 条 `RelationTabDef`（conflict 6 / items 4 / 多数 2-3）——每个=一条关系类型的列表+添加器 |
| 峰值 tab 数 | characters 9、conflict ≈12——248px 抽屉全靠横滚、无溢出提示 |
| 切页能力 | `switchTab` 仅 characters 消费（家谱→信息）；**无键盘切页**；标签条**无 aria**（无 role/aria-selected/方向键） |
| 静默坏面 | tab 图标名写错静默渲空（无守卫）；customTab 无内容槽时**空白页无告警** |

**外部参考**（2026-10-08）：>7-8 个 tab 阻碍扫读，横滚必须配视觉线索（渐变边缘/箭头）
（[UX Patterns](https://uxpatterns.dev/patterns/navigation/tabs)）；tab 使用准则（[NN/g](https://www.nngroup.com/articles/tabs-used-right/)）。

## 二、四裁定（用户 2026-10-08 拍板）

1. **关系去重＝合并进「关联」**：关系 tabs 收编为关联面板内的类型分组，按类型的「＋ 添加」并入分组头。
2. **溢出＝渐隐 + 滚轮横滚 + 激活项自动滚入视野**。
3. **置换＝设置面「Tab 管理」卡**（按类型排序/隐藏，草稿制；详情内不拖拽）。
4. **加固＝图标守卫 + 空槽 fallback + 计数徽标 + 键盘与无障碍**；切页快捷键＝**ALT+←/→**（用户指定键位；
   已查全仓无占用）。

## 三、设计定稿

### 3.1 组装单点（工程底座）

新件 `packages/plugin-sdk/src/detail/detailTabs.ts`（纯函数）：

```ts
resolveDetailTabs({ hasCover, customTabs?, extras?, override? }): DetailTab[]
// 序：info → cover(hasCover) → customTabs → extras → relations（恒尾）
// override：hidden（info/relations 钉底不可隐）→ order（列出者按序前置，其余按默认序尾随）
```

- `DetailTab` 增可选 `count?: number`（标签徽标用）。
- **覆写并入 `detailLayoutStore`**（entity-core，121 行、未冻结）：新增 `DetailTabOverride { order?, hidden? }`
  + `worldsea_detail_tabs` 分键 + setter/clear——与 carriers/backdrop 同构（「用户明确选过的才存」）。
- GEV 与 TimelineView 都改调此函数（TimelineView 的 causal 作 `extras`；其 info 标签「详情」归一为
  「信息」——微小文案归一，走查留意）。

### 3.2 合并（关系 tabs → 关联面板）

- GEV：`resolvedTabs` 不再含关系 tabs；删 `#rt.id` 默认渲染块；`#relations` 槽给
  `UniversalRelationPanel` 增传 `:tab-defs="props.detailTabs"`；「关联」tab 注入 `count`（选中实体关系总数）。
- `UniversalRelationPanel` 增强（**923 行 / 基线 924 余 1 ⇒ 先减压再改**——落地时抽出
  `RelationGroupList.vue`（内嵌/浮出两份同构模板各 40+ 行 + 拖拽与“＋”在子件一处），面板降到 ~713 行）：
  ① 吃 `tabDefs`：类型分组按芽声明的 label/icon 呈现（tabDefs 序前置，未覆盖类型尾随）；
  ② 分组头加「＋」（`EntityRelationSelector` 定向 relationType/reverseDirection——反向语义保住）；
  ③ 行图标：**面板行本就是目标实体类型图标**（动态），tab 旧版是固定 `targetIcon`——合并即升级。
- **芽侧零改声明**（34 条 `RelationTabDef` 保留为面板元数据）；**concepts 三个自定义槽**
  （`#detail-backlinks/forwardLinks/contradictions`）删除——迁移到面板默认渲染
  （explanation 走 `showProperty` ✓ 已声明；references 双向归一为「引用」一条声明，方向由行内 ←/→ 表达）。
- **顺带归一（登记）**：面板 `navigateTo` 原手写 6 类视图映射直调 store（非映射类型不切视图、同视图无
  即时选中）——改走 `ws-navigate` 契约事件（Shell 统一处理）。

### 3.3 溢出与键盘（DetailShell / 载体层，69 行未冻结）

- `.dp-tabs`：两端渐隐（仅可横滚时显示）+ `@wheel` 横滚 + activeTab 变化 `scrollIntoView({inline:'nearest'})`。
- 无障碍：`role=tablist/tab`、`aria-selected`、`aria-controls`/`role=tabpanel` + 方向键在标签条内移动并激活。
- 切页快捷键 **ALT+←/→**：GEV（per-type id）与 TimelineView（`timeline.*`）各注册一段（与既有 ctrl+←/→
  分页同款约定）；**`SHORTCUT_CATALOG`（ui-kit/settings/utils.ts）双登记**（守卫锁双向一致）；详情未开时 no-op。

### 3.4 加固细则

- **图标守卫**（静态 spec）：扫芽的 `customTabs`/`RelationTabDef`/TimelineView tabs 的 icon 名 →
  `hasLucideIcon` 断言（空串允许）。
- **空槽 fallback**：GEV 的 `#ct.id` 透传槽内写 `<WsEmpty title="该页暂无内容" />`（父未提供即显示）。
- **计数徽标**：「关联」tab 显示关系总数（`DetailShell` 渲 `.dp-tab-count`）。

## 五、风险点

1. `UniversalRelationPanel` 余量 1 行——**先减压**（抽 `RelationGroupList` 子件）再增强：✅ 已落
   （面板 923→713 行）；`GEV` 与 `TimelineView` 余量充足。
2. 合并后「按类型浏览」多一次展开（用户已接受）；关联面板分组顺序按 tabDefs 前置（习惯变化）。
3. concepts 行渲染迁移：行图标**升级**为动态类型图标（原 tab 版固定 link）；TimelineView 的「详情」标签
   归一为「信息」（微小文案）。
4. 「关联」计数徽标给 resolvedTabs 引入实体上下文依赖（computed 响应链要证：改关系数 → 徽标即时变）。
5. **测试教训（本批实录）**：面板语义名用例首版取样用了「与注册表同值」的 label，label 覆盖被摘的
   变异**恒绿**——断言样本必须与被测路径可区分（已改为可辨识样本并复验报红）。

## 六、验收与走查清单（分三批）

**批 A**：① tab 条显著变短（conflict ≈12→3、weapons 8→5）；② 关联面板内类型分组带芽语义名
（如 magic「前置/进阶」）；③ 分组头「＋」可定向添加（含反向关系，如 weapons「持有者」）；
④ 概念芽的引用/矛盾三页迁移后内容完整（含 explanation）；⑤ 关系建/删后关联面板即时刷新。
**批 B**：① 多 tab 时两端渐隐、滚轮横滚、切隐藏 tab 自动滚入视野；② ALT+←/→ 切页（含循环）；
③ 方向键在标签条内可达可切；读屏语义（role/aria-selected）。
**批 C**：① 设置面「Tab 管理」排序/隐藏落盘，详情即时生效；② info/关联钉底禁隐；③ 图标名守卫 &
空槽 fallback（人为声明空槽 tab 见说明文案）；④「关联」徽标计数与关系数同步。

## 七、登记项

- 自定义 tab 的计数徽标（无通用计数来源）与 cover tab 增强，不做。
- 「铺开」（给更多芽加自定义/关系 tabs 内容）随合并后的实况另议——合并使「铺开关系 tabs」成本趋零
