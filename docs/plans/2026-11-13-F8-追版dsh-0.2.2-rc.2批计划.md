### 8.2 实际遇到的偏差与处置

| # | 偏差 | 处置 |
|---|---|---|
| D1 | `robocopy` 因 symlink 报 `Access denied` 并 30s 重试挂住 | 改用 `tar` 打包 + 解压（167MB，秒级） |
| D2 | `git apply --3way` 全部失败（旧 blob 路径已不在 index） | 逐文件单独试，5 个纯新增可 apply，其余 15 个手工重放 |
| D3 | 首次单跑 `tsc -b tsconfig.host.json` 在 `src/` 落下 `.d.ts`/`.js` 污染 | 定位 20 个污染文件并删除；lint 错误从 653 降到 2 再到 0 |
| D4 | `web-app/tsconfig.json` 缺 `api/gateway` 项目引用 → host 编译 6059/6307 报错 | 补 `references`（即我方原差异项） |
| D5 | `dispatch` 由 `void` 改 `async` 后两处调用未处理 Promise → lint 报错 | 加 `void` 显式忽略（载体自持生命周期，与原设计一致） |
| D6 | `dispatch` 缺 socket 模式的 400 保护 → 我方测试超时 | 补 try/catch（载体调用不经过 `listener` 的 catch），这是**真实缺陷** |
| D7 | `server.port` 在 external 模式返回 `undefined` | 改为返回声明端口（与 `getOrigin` 同因） |
| D8 | 台账文件被 `WriteAllLines` 写入 CRLF，fork 门禁的正则（要求 `\n`）读不到代码块 | 归一化为 LF |
