# 项目备份功能批计划（D 项立项）

> **立项（2026-10-02）**：存储 Tab 审计（本日批计划见 git f6395f4）中裁定的独立项。
> 动机：整项目备份目前只有「导出到文件夹」（手动、覆盖式），作者缺少一键、带版本滚动的安全副本。

## 目标

一键「备份项目」：把当前项目目录复制为 `备份/项目名-YYYYMMDD-HHmm/` 时间戳副本，保留最近 N 份自动滚动清理（N 默认 5，可配）。

## 方案要点

1. **Rust 新命令 `cmd_fs_copy_dir(src, dest)`**：递归复制目录（现 `cmd_fs_copy` 明确不支持目录）。std 递归实现，无新依赖；走 `ensure_write_allowed` 写守卫。
2. **滚动清理**：备份后列 `备份/` 下同前缀目录按时间排序，超出 N 份删除最旧（复用 `cmd_fs_delete` 或新命令内一并处理）。
3. **前端入口**：存储 Tab 概览卡加「备份项目」按钮（确认弹窗走统一 useConfirm，展示预计体积——可复用 `cmd_fs_usage`）。
4. **进度反馈**：大体量项目复制耗时，最小可用 = toast「备份中…/完成」；增强项 = 后端事件报进度（不在本期）。

## 验收点

- 备份副本内容与源目录一致（文件数/字节对账）。
- 超限滚动删除正确（N+1 份时删最旧）。
- 写守卫生效（目标在项目目录外的拒绝路径按既有策略）。
- 真机：备份 → 修改数据 → 恢复副本 → 数据回滚。

## 不做项

- 增量/dedupe 备份（本地桌面场景全量副本足够）。
- 云端/异地备份。
- 备份加密。

## 实施记录（2026-10-04，走查通过）

- **Rust**：`cmd_fs_copy_dir`（递归复制，返回文件数/字节；源+目标双写守卫，目标已存在即拒）+ lib.rs 装配 + `worldsea-product.toml` 白名单补登（toml 内注明 D 项立项裁定放行；`cmd_fs_copy` 仍在有意排除清单）。
- **前端**：存储概览卡「备份项目」——确认弹窗（目标路径+体积）→ `worlddata-backups/backup-<YYYYMMDD-HHmmss>` → 滚动清理保留 5 份（`cmd_fs_list` 列举 + `cmd_fs_delete` 删目录，清理失败不影响备份本体）→ toast 报告文件数/体积。
- **门禁**：cargo build 干净 · arch 0 · typecheck 0；真机走查通过（备份/滚动清理/恢复可用）。
- **备份位置口径**：数据目录（worlddata）的同级 `worlddata-backups/`——在数据目录之外，不自我包含，也不计入「数据目录占用」统计。
