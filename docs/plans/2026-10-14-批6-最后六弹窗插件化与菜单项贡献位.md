## 一、口径

| 项 | 定稿 |
|---|---|
| utility 语义定型 | `manifest.kind: 'utility'` = **常驻装载、无启停、无侧栏入口**（对齐 dsh 内置语义）；`sprout` 为默认（侧栏芽视图） |
| 装载真源 | [tree.ts](../../apps/tauri/src/world/tree.ts) `forceLoad(id) = kind === 'utility'`：内置 + 外部两条装载路径均 `isEnabled \|\| forceLoad`，utility 无视 sprouts 状态强制装载，并从 skipped 剔除 |
| 菜单项贡献位 | `PluginOverlay.menu?: PluginOverlayMenu`（label/icon/order/shortcutId）——AppMenu 消费真源自动渲染贡献项（三段式排序），点击 dispatch `ws-open-<id>`；不声明 = 无菜单入口 |
| 六登记壳插件 | `official.search / import-export / batch-edit / templates / version-history / doc-export`——**纯登记壳**：组件留 ui-kit/plugin-sdk，插件 index 仅 manifest + overlay 登记（defineAsyncComponent 经 barrel 引出） |
| DEFAULT_SPROUTS 清理 | 批 2/3/5 曾加入的 4 条 utility 死条目（data-tools / theme-editor / entity-tools / settings）删除——常驻化后启停无效；现存条目全为芽类 |
| 留 L0 | ShortcutHelpModal / UndoHistoryPanel（快捷键系统耦合，不插件化） |

## 四、边界与已知语义

- 外部插件声明 `kind: 'utility'` 同样常驻（forceLoad 两路径一致）——外部插件卡对其展示常驻态；声明与否由插件作者决定。
- 内置插件无启停为**有意设计**（用户定性），非缺接线；如需临时禁用某内置插件，属未来能力桥/ACL 范畴，不在本批。
