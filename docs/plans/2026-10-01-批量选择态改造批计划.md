# 批量选择态改造批计划

status: 执行中

> 用户提案（2026-10-01）：去掉常驻复选框 → 工具条增加「批量」按钮 → 点击进入批量态 → 卡片直接点选、边缘高亮表示选中。
> 三裁定（AskUserQuestion，均取推荐项）：**范围＝全部批量面** · **批量态下必须先退出才能看详情** · **清空 ≠ 退出**。

## 一、动机

常驻复选框把「浏览模式」与「选择模式」两种语义挤在同一界面：卡片左上角永远挂着一个勾选框，
既占位又与「点击卡片＝打开详情」的默认语义冲突。改为显式批量态后，默认态干净，选择态明确。

**既有可复用之基建**（不新造状态）：
- `useBatchDelete` 已有**未被使用**的 `selecting` ref 与 `enterSelectMode()` —— 正是批量态本体；`selectAll` 亦未被使用。
- `useShortcuts` 支持 `scope:'view'` + `keys:['escape']`；GEV 已注册 `${entityType}.close`（Esc 关详情）→ **在其 handler 内串接**（有详情先关详情，否则退批量态），不新增 Esc 注册，避免与视图层其它 escape 冲突。
- GEV 的 `#list` 插槽已有 `selected-ids` / `toggle-select` 通道 → 批量态经**同一通道**下传（新增 `batch-mode`）。

## 三、设计

**状态机**：`selecting=false`（浏览：点击＝开详情）↔ `selecting=true`（批量：点击＝选中切换）。
进入＝工具条「批量」按钮；退出＝同按钮再点 / Esc；`clearSelection` **只清空选中、不改态**（含批量删除后）。

**可见性三件**（防「点了没反应」）：① 按钮 active 高亮 + `aria-pressed`；② 批量态卡片/树行 hover 显**虚线 accent 描边**；③ 选中项沿用既有 `.batch-selected`（accent 实描边 + 浅底）。

**无障碍**：卡片/树行 `aria-label` 在批量态改述为「选择 X」；`aria-pressed` 表达选中；移除 checkbox 不再丢语义。

**不做**：批量态下的拖拽、跨页选择、全选（`selectAll` 仍留作后续）。

## 四、施工面

1. `useBatchDelete.ts`：`clearSelection` 不再置 false；`enterSelectMode` → `toggleSelectMode`。
2. `GenericEntityView.vue`：批量按钮 + 点击路由 + 槽属性 `batch-mode` + Esc 串接 + 撤两处复选框与 `.batch-check` 样式 + hover 描边。
3. `GenericTreeView.vue`：删 `showCheckbox` 与其复选框/样式；`batchSelected` 去 gate；新增 `batchMode` 与点击路由（含递归下传）。
4. `OrgTreeNode.vue`：去 `:show-checkbox`，接 `batch-mode` 下传。
5. `regions/TreeNode.vue`：**删除**（死件）。
6. `RegionList.vue`：树行与卡片两分支去复选框、接 `batch-mode` 路由；同步撤 `.batch-check*` 样式。
7. `TimelineView.vue` + `TimelineChart.vue` + `components/TreeNode.vue` + `EventCard.vue`：批量按钮 + `batch-mode` 下传 + 去复选框 + 选中视觉。

## 六、风险点

- GEV 冻结基线行数增长（删复选框减行、加按钮与路由增行）→ 以 `arch:check` 实况为准登记。
- 时间线事件卡原先**没有**选中视觉（全靠复选框），移除后补 `.batch-selected` 属新增视觉，需走查确认观感。
- 区域「树视图」与「卡片模式」共用一份 `viewMode`，批量态下切换视图模式仍可进行（不阻断）。
