## 二、第 0 步取证（2026-09-30，全部源码级）

1. **对齐目标**（工作台窗 `apps/tauri/src/ui/layout/TitleBar.vue:139-149`）：四键 = Ctrl+M 最小化 / F10 最大化还原 / F11 全屏 / Ctrl+W 关闭；守卫 = IME（`isComposing || keyCode===229`）+ 逐键修饰判据（`m`/`w`：mod 且无 alt/shift；`f10`：无任何修饰）；相位 = window 冒泡。
2. **冲突面（dsh 侧）**：快捷键 runtime = **web**（`dsh/packages/client/shortcuts/src/client/dom.ts:19`：`documentElement.dataset.platform` 缺席 → web）→ dsh 的 `page.close` 在 web 档默认 **Ctrl+Alt+W**（`ui-sidebar-right/src/client/shortcuts.ts:65-97`），**裸 Ctrl+W 无绑定**；全树 src 无 F10 / Ctrl+M / Ctrl+Tab 默认绑定。终端局部语义：web 档终端保留 Ctrl+W/R 为局部输入（`shortcuts/README.zh.md:54`；xterm 的 cancel 行为随 `cancelEvents` 配置而异，故**不依赖上游中止**、自行让行）——Ctrl+M＝回车、Ctrl+W＝删词（shell）、F10 是 TUI 功能键，全部让行。
3. **G1-c 落点**：工作台窗 `decorations(false)`（`workspace_window.rs:208`）、全屏由页面 `TitleBar.vue` 的 F11 自管（`appWindow.setFullscreen`）——形态改动在页内，壳零改动；`.shell` flex 纵向 + `.shell-body flex:1` → 隐栏后内容区自然接管全高。
4. **★ 取证时发现的隐藏雷（G1-b 护栏）**：空间切换的几何转移未考虑全屏窗——「工作台（非全屏）→ 切回 Agent（仍全屏）」方向会给全屏主窗写 `set_position`/`set_size`（可能顶掉全屏/成怪态）；反向也会把全屏的屏尺寸当几何转移。处置 = 纯判据 `geometry_transfer_skipped`（来源最小化 / 来源全屏 / 目标全屏 → 跳过），全屏态**不随切换转移**（每窗各自保有，切回仍是全屏）。
