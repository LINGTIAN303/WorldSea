## 范围

1. **布局与可达性**：地图舞台压到约 2:1；区域标签/状态绝对定位，窄宽状态收成颜色点；大背景卡片固定缩略条，选中后编辑区出现 16:9 预览；选中目标/切地图/选大背景后自动滚到编辑区（尊重减弱动效）。
2. **亮/暗预览**：地图标题右侧「亮 / 暗」切换，只影响地图、大背景卡片与编辑区预览，不改全局主题；`BackgroundLayer` 增加 `previewTheme`。
3. **工具条形态提示**：读取当前工作台视图的 toolbar 模式（bar/overlay/none/unavailable），地图工具条区域非 bar 时显示徽标；编辑区显示当前形态与是否生效。
4. 测试、typecheck、产品域 `workspace-dist` 构建，并同步安装目录/便携 release 副本。
