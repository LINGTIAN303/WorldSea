## 五、陷阱备忘（血泪，勿踩）

1. **改前端后必须重建 workspace-dist**：工作台窗口加载静态产物（`apps/tauri/workspace-dist/`），dev 不热更新。命令：`cd apps/tauri && node node_modules/vite/bin/vite.js build --config workspace/vite.config.ts`，构建后重启页面（Rust 无需重编）。
2. **多 suggestion 并存**：斜杠/mention/`[[` 双链各自必须独立 `pluginKey`（默认同 key `suggestion$` → 编辑器创建崩溃）。
3. **ProseMirror depth**：顶层段落 `depth=1`（doc>paragraph>text）——手敲表格转换曾因 `depth < 2` 误拒全部输入（2026-10-12 图证修复）。
4. **jsdom 无 `:has()`**：parseHTML 兼容规则用 `getAttrs` 函数式匹配。
5. **v-html 前先转义**：任何正文摘录（如搜索摘要 snippetOf）必须 escapeHtml 后再注入 mark。
6. **聊天渲染内核不能直接喂 TipTap**：代码块外壳（语言标签/复制按钮）会被 schema 过滤留文字污染，用 `renderMarkdownForEditor`。
7. **真机走查门禁顺序**：typecheck → vitest 全套 → 重建 workspace-dist → 重启实例 → 走查。
