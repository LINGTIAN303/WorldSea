# 界面背景机制 v2 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans，按任务逐项执行。步骤用 checkbox（`- [ ]`）跟踪。

**Goal:** 把 v1 的全局单画布壁纸升级为五目标、亮暗双图、全局默认 + 项目整目标覆盖，并支持项目导出/导入；设置界面仍是单张背景卡。

**Architecture:** `style-kit` 持有五目标配置、迁移、生效合并与根变量；`entity-core` 负责图片导入、项目配置读写/路径校验/导出导入；`ui-kit` 提供通用 `BackgroundLayer` 与背景卡；`apps` 在 Shell/TitleBar/Sidebar/ViewContainer/Home 挂载五层并接启动/项目切换。任务按垂直切片推进，每个任务保持应用可运行；v1 画布兼容层在 Task 6 移除。

**Tech Stack:** Vue 3 + TypeScript、Tauri 2、Vitest + @vue/test-utils、CSS 变量/`backdrop-filter`、现有 `cmd_fs_*` 命令。

**Spec:** `docs/details/架构/界面背景机制-v2.md`

## Global Constraints

- 五目标：`canvas` / `home` / `titlebar` / `sidebar` / `content`；目标 key 与 spec 一致。
- 每目标亮/暗两图共用 `enabled/fit/focusX/focusY/dim/blur`；分区目标 `fit` 固定 `cover`、焦点固定 `50/50`。
- 全局键 `worldsea_background_v2`；v1 键 `worldsea_workspace_background` 只读迁移、不删除。
- 项目配置 `{projectDir}/.worldsea/background.json`；图片 `{projectDir}/.worldsea/backgrounds/`；相对路径必须以 `.worldsea/backgrounds/` 开头，拒绝绝对路径、`..`、反斜杠。
- `data-ws-bg-<target>` 只在目标 `enabled && (lightSrc || darkSrc)` 时存在；任何一张图可用时两个主题变量都要回填。
- 背景层祖先不得新增 `isolation` / `filter` / `contrast()` / `opacity < 1`；图片模糊只作用图片元素自身。
- 不新增裸色值；使用 `--sf-*` / 现有令牌；`style:check` 不新增失败（预存 `rgba 166/164` 由引入方处理）。
- 模块边界：`style-kit` 不依赖 Tauri；`entity-core` 不新增 `@worldsea/style-kit` 依赖；`ui-kit` 不依赖 `apps`。
- 每个任务先写失败测试再实现；目标测试必须绿。Task 1–5 保留 v1 画布兼容，Task 6 清理。
- 提交逐路径 `git add`，禁止 `-A`；不触碰其他 Agent 的未提交文件；UTF-8 无 BOM，代码标识符英文、注释中文。

```ts
  dim: number
  blur: number

}
export interface BackgroundProjectConfig {
  version: 1
  targets: Partial<Record<BackgroundTarget, BackgroundTargetConfig>>
}

export const BACKGROUND_KEY = 'worldsea_background_v2'
export const BACKGROUND_V1_KEY = 'worldsea_workspace_background'
export const BACKGROUND_TARGETS: readonly BackgroundTarget[] = ['canvas', 'home', 'titlebar', 'sidebar', 'content']
export const BACKGROUND_THEMES: readonly BackgroundTheme[] = ['light', 'dark']
export const BACKGROUND_TARGET_CAPS: Record<BackgroundTarget, { fit: boolean; focus: boolean }> = {
  canvas: { fit: true, focus: true },
  home: { fit: true, focus: true },
  titlebar: { fit: false, focus: false },
  sidebar: { fit: false, focus: false },
  content: { fit: false, focus: false },
}
```

`defaultTarget()` / `normalizeTargetConfig(raw, target)`：

- 所有字段按 v1 归一化；分区目标强制 `fit:'cover'`、`focusX:50`、`focusY:50`。
- `paths` 只接受对象上的字符串 `light` / `dark`。

`normalizeGlobalConfig(raw)`：五个目标逐个归一化，未知字段忽略；缺失目标用默认值。

`normalizeProjectConfig(raw)`：对象且 `targets` 为对象时逐目标归一化；只保留已知目标；无有效目标返回 `null`。

`migrateV1Config()`：读 `BACKGROUND_V1_KEY`；合法 JSON 时把 v1 字段写入 `canvas`（`paths.light = path`，`paths.dark = ''`，`src` 丢弃）；否则返回 `null`。

- [ ] **Step 4: 实现运行时与 API**

运行时：

```ts
const globalConfig = ref<BackgroundGlobalConfig>(cloneDefaults())
const projectConfig = ref<BackgroundProjectConfig | null>(null)
const globalSrcs = ref<SrcMap>(emptySrcs())
const projectSrcs = ref<SrcMap>(emptySrcs())
const missing = ref<MissingMap>(emptyMissing())

const effective = computed(() => {
  const out = {} as Record<BackgroundTarget, BackgroundTargetConfig>
  for (const target of BACKGROUND_TARGETS) {
    out[target] = projectConfig.value?.targets[target] ?? globalConfig.value.targets[target]
  }
  return out
})

const srcs = computed(() => {
  const out = {} as Record<BackgroundTarget, { light: string; dark: string }>
  for (const target of BACKGROUND_TARGETS) {
    out[target] = projectConfig.value?.targets[target] ? projectSrcs.value[target] : globalSrcs.value[target]
  }
  return out
})
```

`apply()`：

- 对每个目标：`const s = srcs.value[target]`；`const light = s.light || s.dark`；`const dark = s.dark || s.light`。
- 有图时写 `--ws-bg-<target>-image-light/dark`、`-size/-repeat/-position/-dim/-blur`；无图时移除。
- `cfg.enabled && (light || dark)` 时写 `data-ws-bg-<target>='on'`，否则删除。
- v1 兼容：canvas 有图且未双缺失时写 `--ws-bg-image`（light 回填）、`--ws-bg-size/repeat/position/dim/blur`；`canvas.enabled && 有图` 时写 `data-workspace-bg='on'`，否则删除。

API：

```ts
function setProjectConfig(config: BackgroundProjectConfig | null) {
  projectConfig.value = config
  projectSrcs.value = emptySrcs()
  projectMissing.value = emptyMissing()
  apply()
}

function setTargetSrcs(target: BackgroundTarget, next: { light?: string; dark?: string }, scope: BackgroundScope) {
  const bucket = scope === 'project' ? projectSrcs : globalSrcs
  bucket.value = { ...bucket.value, [target]: { light: next.light ?? '', dark: next.dark ?? '' } }
  for (const theme of BACKGROUND_THEMES) {
    if (bucket.value[target][theme]) missing.value[target][theme] = false
  }
  apply()
}

function setTargetSrc(target: BackgroundTarget, theme: BackgroundTheme, src: string, scope: BackgroundScope) {
  const bucket = scope === 'project' ? projectSrcs : globalSrcs
  bucket.value = { ...bucket.value, [target]: { ...bucket.value[target], [theme]: src } }
  if (src) missing.value[target][theme] = false
  apply()
}
```

```ts
export type BackgroundTargetKey = 'canvas' | 'home' | 'titlebar' | 'sidebar' | 'content'
export type BackgroundThemeKey = 'light' | 'dark'

export interface BackgroundSaveRequest {
  scope: 'global' | 'project'
  projectDir?: string
  target: BackgroundTargetKey
  theme: BackgroundThemeKey
}

export function backgroundFileName(target: string, theme: string, ext: string, now = Date.now()): string {
  const safe = (value: string) => value.toLowerCase().replace(/[^a-z0-9-]/g, '')
  return `background-${safe(target)}-${safe(theme)}-${now}.${ALLOWED_EXTS.has(ext.toLowerCase()) ? ext.toLowerCase() : 'webp'}`
}

export async function pickAndSaveBackground(req: BackgroundSaveRequest): Promise<BackgroundImportResult | null> {
  if (!isTauri()) return { ok: false, reason: '当前环境不支持选择文件' }
  if (req.scope === 'project' && !req.projectDir) return { ok: false, reason: '未打开项目' }
  const picked = await pickLocalFiles({
    multiple: false,
    title: '选择背景图',
    filters: [{ name: '图片', extensions: ['png', 'jpg', 'jpeg', 'webp'] }],
    maxBytes: BACKGROUND_MAX_BYTES,
  })
  if (picked.cancelled) return null
  const file = picked.items[0]
  if (!file) return { ok: false, reason: picked.reasons[0] ?? '没有可用的图片' }
  const encoded = await encodeBackground(file).catch(() => null)
  if (!encoded) return { ok: false, reason: '图片解码失败，请换一张 PNG/JPG/WebP' }
  const dir = req.scope === 'project'
    ? await join(req.projectDir!, '.worldsea', 'backgrounds')
    : await join(await appDataDir(), 'worldsea', 'backgrounds')
  await invoke('cmd_fs_mkdir', { path: dir })
  const name = backgroundFileName(req.target, req.theme, encoded.ext)
  const path = await join(dir, name)
  await invoke('cmd_fs_write', { path, content: bytesToBase64(encoded.bytes), createDirs: true, encoding: 'base64' })
  return {
    ok: true,
    path,
```

```ts
export const PROJECT_BACKGROUND_PREFIX = '.worldsea/backgrounds/'

export function normalizeProjectBackgroundPath(raw: string): string | null {
  if (!raw || raw.includes('\\')) return null
  const value = raw.replace(/^\.\//, '')
  if (value.startsWith('/') || /^[a-zA-Z]:/.test(value)) return null
  if (value.split('/').some(seg => !seg || seg === '.' || seg === '..')) return null
  return value.startsWith(PROJECT_BACKGROUND_PREFIX) ? value : null
}
```

```ts
import { convertFileSrc } from '@tauri-apps/api/core'
import { getFileStorageBackend } from '@worldsea/entity-core/core'
import {
  readProjectBackground, resolveProjectBackgroundAssets, cleanupGlobalBackgroundOrphans,
  resolveBackgroundSrc,
} from '@worldsea/entity-core/core'
import {
  useBackground, normalizeProjectConfig, BACKGROUND_TARGETS, BACKGROUND_THEMES,
  type BackgroundTheme, type BackgroundTarget,
} from '@worldsea/style-kit'

let generation = 0

export function hydrateGlobalBackground() {
  const api = useBackground()
  for (const target of BACKGROUND_TARGETS) {
    const paths = api.globalConfig.value.targets[target].paths
    api.setTargetSrcs(target, {
      light: paths.light ? convertFileSrc(paths.light) : '',
      dark: paths.dark ? convertFileSrc(paths.dark) : '',
    }, 'global')
  }
}

export async function validateGlobalBackground() {
  const api = useBackground()
  for (const target of BACKGROUND_TARGETS) {
    for (const theme of BACKGROUND_THEMES) {
      const path = api.globalConfig.value.targets[target].paths[theme]
      if (!path) continue
      const src = await resolveBackgroundSrc(path)
      if (src) api.setTargetSrc(target, theme, src, 'global')
      else api.markMissing(target, theme, 'global')
    }
  }
  await cleanupGlobalBackgroundOrphans(() => BACKGROUND_TARGETS.flatMap(target =>
    BACKGROUND_THEMES.map(theme => api.globalConfig.value.targets[target].paths[theme])
  ).filter(Boolean))
}

export async function loadProjectBackgroundForCurrentProject() {
  const token = ++generation
  const dir = getFileStorageBackend().projectDir
  const api = useBackground()
  if (!dir) { api.setProjectConfig(null); return }
  const raw = await readProjectBackground(dir)
  if (token !== generation) return
  const config = normalizeProjectConfig(raw)
  if (!config) { api.setProjectConfig(null); return }
  const refs = []
  for (const target of BACKGROUND_TARGETS) {
    const t = config.targets[target]
    if (!t) continue
    for (const theme of BACKGROUND_THEMES) {
      if (t.paths[theme]) refs.push({ target, theme, path: t.paths[theme] })
    }
  }
  const { srcs, missing } = await resolveProjectBackgroundAssets(dir, refs)
  if (token !== generation) return
  api.setProjectConfig(config)
  for (const target of BACKGROUND_TARGETS) {
    if (!config.targets[target]) continue
    api.setTargetSrcs(target, srcs[target], 'project')
    for (const theme of BACKGROUND_THEMES) if (missing[target][theme]) api.markMissing(target, theme, 'project')
  }
}

export function clearProjectBackground() {
  generation++
  useBackground().setProjectConfig(null)
}
```
