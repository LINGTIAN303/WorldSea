## 一、已拍板结论（2026-09-28）

### 1.1 为什么做（用户确认的五条理由）

1. 交界配置在积累但无家可归（环境变量 / 硬编码 / patch 文件三处散落）；
2. 设置页 = 交界行为的一等公民管理面（可发现 / 可开关 / 可扩展）；
3. 放 dsh 侧设置路径最短（行为多发生在 Agent 面；延续「产品跟随 dsh」哲学）；
4. 为后续工具面配置（分页上限、ACL 调整等）预留入口；
5. **隔离**：产品域配置与 dsh 通用设置互不污染（用户补充）。

### 1.2 载体拆分（拍板：拆两插件）

| | `dsh-plugin-worldsea`（现状保留） | `dsh-plugin-worldsea-console`（新增） |
|---|---|---|
| 职责 | Agent 工具面：12 条 world_* 工具 + 指引段 | 产品域管理面：设置页客户端半侧 + 交界配置桥 |
| 半侧 | 纯宿主侧 | 客户端半侧为主（宿主侧空 apply 占 Loader 行，对齐 `ui-settings-shell` 先例） |
| 装配 | dsh 全局插件（不动） | dsh 全局插件（link: + bundle insert + junction 三坑先例） |

### 1.3 首期范围与真相源（四组全选）

| 配置组 | 真相源 | 桥 |
|---|---|---|
| 说明书与指针（WORLDSEA.md 生成开关 / AGENTS.md 薄指针开关） | **壳侧偏好**（app_prefs 扩展） | console 页 ↔ 壳命令 get/set；壳启动按偏好生成 |
| 快照策略（schema 快照导出开关） | **壳侧偏好**（同上，单一真源同时服务壳与工作台） | 同上；工作台 boot.ts 直读 |
| 插件数据面（dshHome 覆盖 / dataRoot 兜底） | **dsh profile 插件 config 行**（cordis 原生口径） | configForms 跨插件绑定；不可行则降级只读 + 指引 |

### 1.4 待验证项核实（2026-09-28，全部实锤）

- **客户端行收录规则** ✓：包须声明 `dsh.client.platform: 'web'` + client export（`client-modules/src/index.ts` parseDshClient）。
- **configForms 跨插件** ✓：设计内模式（ui-settings-shell 注释原话 "Cross-plugin collaboration"；`ctx.configForms.get(NS)` + `whileServed` 注册卡片进 `plugins.item` slot）。

- **壳偏好持久化** ✓：app_prefs 已有 JSON prefs（read/write_prefs）+ 先例字段（theme/zoom）。
- **留待 D3-b 装配时验证**：link: 插件 bundle 的客户端产物实际收录（裸 specifier 行规则）。

## 二、施工批拆分

### D3-a 壳侧偏好与命令面（Rust）

- app_prefs 扩展 `product_domain` 节：`manual_generation: bool`（缺省 true）、`agents_pointer: bool`（缺省 false——首版保守，用户可在页面打开）、`snapshot_export: "auto" | "off"`（缺省 auto）。
- 新命令 `cmd_product_prefs_get` / `cmd_product_prefs_set`（对齐 `cmd_theme_*` 先例）；worldsea-shell.toml 白名单逐条加两条。
- `worldsea_manual.rs`：`ensure_manual` 读偏好；新增 `ensure_agents_pointer`——幂等薄指针 `AGENTS.md`（数行：本项目为 WorldSea 产品域工作区，先读 WORLDSEA.md；cwd 即项目根，创作数据在 worlddata/；由壳管理，可删可改），已有 AGENTS.md **绝不覆盖**。
- boot.ts 快照导出前读偏好（off 时跳过导出；插件侧 `WORLDSEA_NO_SCHEMA_SNAPSHOT` fail loud 语义自然兜底）。

### D3-b console 插件骨架（新包 + 装配）

- `apps/dsh-plugin-worldsea-console/`：package.json（`dsh.client.platform: 'web'` + client export + bundle patch 行）；宿主半 `lib/index.js`（空 apply 占行）；客户端半（构建口径施工时定：对齐 dsh client 产物形态，倾向最小 tsdown/esbuild 或手写 js）。
- 装配三件：profile package.json `dependencies` link + `dsh.profile.bundles` 加行 + junction（勿手动 install 坑先例）；cordis.patch.yml insert 条目。
- 注册 `settings.plugins.tab`（id: `worldsea-console`，本地化 label「WorldSea 产品域」）→ 设置「内置插件」分区出现第二个标签页。
- **验证锚**：dsh 页面调壳命令通道实锤（cmd_capability_invoke / cmd_theme 先例）——D3-b 装配时先证，不通则 D3-c 桥降级路径另议。

### D3-c 三组配置 UI + 桥

- 说明书与指针组：两个开关 ↔ `cmd_product_prefs_*`；语义登记——关「生成」只停新生成不删既有文件；开「薄指针」下次壳启动时补生成（或提供立即生成按钮，施工时定）。
- 快照策略：枚举选择 ↔ 壳偏好；off 时 boot.ts 跳过导出，页面提示影响（插件写校验依赖快照）。
- 插件数据面：configForms 绑定 worldsea 插件 config NS → dshHome/dataRoot 表单；绑定不可行则降级为只读展示 + 「到插件页编辑」指引。

## 三、风险与边界

- dsh 页调壳命令通道是**假设**（有先例未在本链路实测）——D3-b 首个验证锚。
- ACL 文件两窗共用：加命令即可被任一窗调用，逐条登记控制面。
- 薄指针写入用户工作区根：已有 AGENTS.md 绝不覆盖；内容声明「由壳管理可删」。
- 快照 off 属行为降级：页面文案须说明对 Agent 写校验的影响。
- Mimosa：commit 闸门对既有测试/诊断文件有存量标注（9-24~27 批次），本批提交可能再被拦——处置走「用户终端提交」或逐条核实，不自动改既有文件。
