## 当前推荐配方（C）

完整参数见研究文档 §15.4。要点：

- 深色：本体 `rgba(8,12,20,.34)` + 6px 模糊；边带 18px / 饱和度 1.9 / 亮度 1.14；白边 .92/.55；暗焦散 `.6 × .55`；眩光 .38/.30。
- 浅色：本体 `rgba(255,255,255,.12)` + 3px 模糊；边带 12px / 饱和度 1.5 / 亮度 1.05；边框 `rgba(20,30,50,.22)`；暗焦散 `.45 × .50`。
- 性能模式：去边带与眩光，本体模糊 2px。

## 实现约束

1. 玻璃容器禁止 `isolation: isolate`：会创建 backdrop root，嵌套的 body 层只能采样到 edge 层，中心重模糊。
2. edge 层必须 `mask-composite: exclude` 裁成环；否则半透明 body 会让重模糊透到中心。
3. 祖先 `filter` / `contrast()` 同样会创建 backdrop root，不能照搬参考实现的 `contrast(3)` 包裹层。
4. 给 backdrop 层加 `transform: scale()` 不产生可见折射位移，已移除。
