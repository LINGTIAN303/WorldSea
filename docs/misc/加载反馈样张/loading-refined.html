Common常见做法
转圈只说明「在转」，扫光只说明「在闪」。用户仍然不知道系统在做什么。

四个小铆钉

精致的来源不是更复杂的动画，而是四个克制的小决定。

光环只在头部

轨道保持 24% 透明的 1px 虚线；只有星点带 7px 光晕。整圈发光会让它重新变回「转圈」。

尾巴是渐隐的

78° 尾迹从 accent 渐隐到透明，不是整圈等亮。速度感来自尾巴，不来自转速。

节点会变成星

已完成节点实心，当前节点带光环并放大 2px；不给每个节点都加动画。

完成时收束

到达 100% 时星点放大到 2.6 倍并淡出，航线保持 300ms 再退场，不是瞬间消失。

这套语言的三条纪律

精致不是加装饰，而是让每个动作都有理由。

1一个移动的点，不做整圈旋转。 点给方向，尾迹给速度，轨道只给参照。
2文字说阶段，星点说位置。 不再用「加载中…」四个字包打天下；项目切换说「装载实体」，导入说「备份」。
3只在终点收束。 完成时星点放大淡出、航线保留 300ms；失败时星点停在原地并转为 warning 色。
4背景态只给一颗星。 不是整条进度条常驻；任务结束，测线立即消失。

Refined token 草案

在现有加载 token 上补 8 个「星轨」参数；仍然只落 theme.css + packages/ui-kit。

Token值用途
--loading-orbit-duration1.15s星点绕行周期
--loading-trail-angle78deg尾迹角度
--loading-head-size4.5px星点尺寸
--loading-head-glow7px星点光晕
--loading-track-opacity24%虚线轨道透明度
--loading-route-trackaccent 22%未完成航段（虚线）
--loading-route-fillvar(--accent)已完成航段
--loading-settle-duration0.6s阶段移动/收束
