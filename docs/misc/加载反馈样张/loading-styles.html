这套机制的边界

不是“到处加转圈”，而是先判断该不该出现。

1延迟出现、最短展示。 200ms 内完成不显示；一旦显示，至少 400ms，避免闪屏。
2一个任务一个指示器。 按钮已是 R1 时，不再叠加全局遮罩；升级时替换，不并存。
3只有真实进度才显示百分比。 拿不到进度就用不确定态，禁止模拟。
4阻断型必须有出口。 成功、空、失败三态；失败可重试，不能把用户关在遮罩里。
5减弱动态时保留语义。 减速/去微光，但不隐藏加载指示器。
6无障碍是默认项。 role="status"、aria-busy、读屏标签；遮罩拦截指针与焦点。

Token 草案

只落产品域 theme.css + packages/ui-kit；dsh 不加载，不动 --dsw-*。
