B 的四个修正

只改可读性与进度语义，不改弧线语言。

14 节点上限。 项目切换固定「数据源 / 实体 / 芽 / 关联」；超过 5 段折叠成阶段组，不滚动。
2双层文本。 上方 12px 完整阶段文案，下方 11px 短标签；不再用 9px 承担主信息。
3阶段式进度。 星点停在当前节点，显示 2/4；不显示假的 46% 连续填充。
4完成与失败。 完成星点放大淡出、航线保留 300ms；失败停住转 warning，显示重试/关闭。
真实进度只在能拿到「已处理 / 总数」时使用（导入、导出、扫描）；项目切换没有真实子进度，所以保持阶段式。
