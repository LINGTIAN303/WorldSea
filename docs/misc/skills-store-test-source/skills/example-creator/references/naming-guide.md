# 角色命名指南

## 一、东方玄幻风格

- 双字名为主：苏砚、林溪、萧玦
- 姓氏取自然意象：风、云、霜、月
- 名字含字义：砚（文采）、溪（灵动）、玦（决断）

## 二、西方奇幻风格

- 名+姓结构：Aldric Blackwood、Elara Moonwhisper
- 名字取古语根源：Aldric（高贵统治者）、Elara（闪耀）
- 姓氏取自然或职业：Blackwood（黑木林）、Moonwhisper（月语）

## 三、科幻风格

- 简短代号：K-7、Nova、Vex
- 含编号或序列：Unit-023、Dr. Chen-V4
- 融合文化：中英混排（Lin "Echo" Zhang）

## 四、现代风格

- 常见名+姓：陈默、林晚晴、周衍
- 避免过度中二，保持生活感
- 可含小名或昵称

## 注意事项

1. 避免与已有角色重名（调用 `entity_list` 核对）
2. 名字应易读易记，避免生僻字
3. 名字风格须与世界观一致
