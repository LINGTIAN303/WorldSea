WorldSea 安装向导

八个界面的初版视觉设计：安装流程五屏（欢迎 → 许可 → 位置 → 过程 → 完成） 与卸载流程三屏（确认 → 过程 → 完成）。设计目标为「与 WorldSea 主界面 一致的深色现代风」，对齐 dsh 设计令牌体系。

重要前提：本稿的视觉目标（深色主题、圆角、现代质感）NSIS 安装器无法实现—— NSIS 向导是 Windows 原生对话框，配色与控件风格不可改。本稿对应的是 「改用 Tauri 小壳承载安装器」这条路线。若最终仍走 NSIS，本稿仅可作为 素材图与文案的参考。详见下方对照表。

一、页面清单

点击卡片进入对应页面。所有页面支持深浅主题切换（右上角按钮）。

01 / 08 欢迎页 第一屏。品牌展示 + 三条核心卖点 + 主动作按钮。 安装流程 02 / 08 许可协议页 真实协议全文 + 独立滚动区 + 接受后才解锁下一步。 安装流程 03 / 08 安装位置页 目录选择 + 安装范围 + 快捷方式，分组收纳避免决策过载。 安装流程 04 / 08 安装过程页 滚动日志为主、进度条为辅；逐条打勾比百分比更让人安心。 安装流程 05 / 08 安装完成页 成功徽章 + 安装摘要 + 默认勾选「立即启动」。 安装流程 06 / 08 卸载确认页 危险操作警告 + 作品数据去留决策；危险按钮不自动聚焦。 卸载流程 07 / 08 卸载过程页 与安装过程页同构；不提供取消，避免留下半残状态。 卸载流程 08 / 08 卸载完成页 中性徽章（不庆祝）+ 明确告知数据保留位置。 卸载流程

四、与 NSIS 方案的落地对照

若最终仍走 NSIS，下表说明本稿各元素的可落地程度。对照依据为 NSIS 向导的 原生控件约束（配色、控件风格、窗口底色不可改）。

本稿元素 NSIS 可落地性 落地后的实际形态
文案全部 可落地 标题、描述、按钮文字通过语言文件完全可改。
左栏侧图 可落地 替换 sidebar.bmp（164×314）。但只能放静态位图，
页头横幅 可落地 替换 header.bmp（150×57）。当前项目已有这两个文件。
左栏步骤指示器 不可落地 NSIS 无此控件。只能把步骤文字画进侧栏位图，无法反映实时进度。
深色主题 不可落地 NSIS 向导为 Windows 原生对话框，跟随系统浅色，不可改窗口底色。
圆角与现代质感 不可落地 原生控件为方角系统样式，不支持自定义描边与阴影。
许可页滚动区 部分可落地 可用 nsDialogs 自绘 RichEdit 控件，但样式受限。
过程页滚动日志 部分可落地 文字内容可定制（如「正在部署世界观引擎」），但滚动区样式与进度条为原生。
进度条 不可落地 原生控件，粗细、颜色、圆角均不可改。
分段选项卡片 部分可落地 可用 nsDialogs 自绘单选/复选组，但为系统控件外观。
完成页成功徽章 部分可落地 可自绘静态位图，或改用原生图标控件。
结论：本稿的视觉目标与 NSIS 路线存在根本冲突——深色主题、圆角、 步骤指示器、自定义进度条四项均无法在 NSIS 中实现。若要完整落地本稿， 需改用 Tauri 小壳承载安装器，这是一项独立工作量。

五、关键设计决策

以下为需要评审时重点确认的判断点，每条都给出了理由。

决策点 选择 理由
过程页主信息 滚动日志为主，进度条为辅 安装步骤可枚举（解压 / 依赖 / 快捷方式 / 校验），逐条打勾比一个 会卡在 90% 的百分比更让人安心；进度条降为细条，不给数字，避免 「为什么卡住不动」的焦虑。
卸载过程页可否取消 不提供取消按钮 卸载中途取消会给系统留下半残状态（部分文件已删、注册表项已清）。 按钮区改为状态说明文字，是刻意取舍而非遗漏。
卸载完成页配色 中性徽章，不用绿色 卸载成功不需要庆祝，绿色成功色会造成情绪错位。改用中性层底色， 只保留对勾符号传达「操作已完成」。
危险按钮聚焦 自动聚焦落在「取消」 卸载确认页的危险按钮不做默认聚焦，避免用户习惯性回车造成误卸载。
安装位置页决策数 分组收纳（目录 / 范围 / 附加） 一次性抛出目录、范围、三个快捷方式共五个决策点会造成决策过载。 按语义分三组，每组一个视觉区块。
卸载是否保留数据 独立成显式决策，默认保留 世界观数据是用户的核心资产，默认「保留」符合最小惊讶原则； 选择删除时提示条升级为危险色，明确告知不可撤销。
图标形式 线性 SVG，无 emoji 遵循项目约束（禁用 emoji 当图标），全部图标为内联 SVG。
