## 为什么不继续

- 需要「截图 → 纹理 → WebGL」异步链路，弹层打开时有一次截图成本与闪烁风险。
- 参数与背景强耦合，产品里滚动、动画、主题切换都要处理重截。
- CSS 分层方案在观感上已能覆盖大部分场景，且零依赖、零异步。

## 终版参数（CSS px）

| 参数 | 值 | 说明 |
|---|---|---|
| 圆角 | 57 | squircle 指数 `n = clamp(6 − (r−12)/60×2, 4, 6)` ≈ 4.5 |
| 折射 | 24 | `uRefract = 24 × dpr`，Snell 偏移缩放 |
| 色散 | 12 | `uDisp = 12 × dpr`，只作用于弯折带 |
| 边缘模糊 | 30 | `uBlurMix = 30 / 60 = 0.50` |
| 中心清晰 | 0.12 | 中心模糊系数（0 = 全清晰） |
| 内暗线 | 0.34 | 内圈暗焦散强度 |
| 角眩光 | 0.30 | 对角白角强度 |
| 镜面 | 1.30 | Blinn-Phong 强度 |
| 染色 | 0.10 | 向 `vec3(0.36,0.39,0.46)` 混合 |
| 光位 | X 0.24 / Y 0.08 | 右上偏上光源 |
| 预模糊纹理 | 22px | 离线模糊纹理 |

固定常量：IOR `1.505 / 1.520 / 1.535`，Fresnel `F0 = 0.04`，斜面带 56px，边缘带 96px，外阴影衰减 46px，输出对比 1.05，颗粒 0.02。

## uniform 映射

- `uUvOffset` / `uUvScale`：画布只覆盖右半屏时为 `(0.5, 0)` / `(0.5, 1)`；产品全屏画布用 `(0, 0)` / `(1, 1)`。
- `uCenter`：GL 坐标（y 向上），`(rect.x + rect.w/2) × dpr`、`(innerHeight − (rect.y + rect.h/2)) × dpr`。
- `uHalf`：`rect.w × dpr / 2`、`rect.h × dpr / 2`。
- 纹理上传：`UNPACK_FLIP_Y_WEBGL = true`，`CLAMP_TO_EDGE` + `LINEAR`。

## 停止前修掉的两个物理错误

1. 斜面法线 `nz` 上限只到 0.92，中心残留倾斜；SDF 中心梯度为零、归一化产生假方向 → 整块玻璃变凸透镜、中心重影。改为 `nz` 到 1.0。
2. 额外 RGB 色散按单位法线全表面偏移 → 平直中心被撕成三份。改为乘 `(1 − nz)`，只留在弯折带。
